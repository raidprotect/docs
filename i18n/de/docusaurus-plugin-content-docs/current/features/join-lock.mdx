Die Funktion **Beitrittssperre** von RaidProtect ermöglicht es, den Zugang für neue Mitglieder auf dem Server dauerhaft zu schließen, und übertrifft damit die native Einschränkung von Discord, die diese Blockierung über die Sicherheitsaktion "Beitritte pausieren" nur für 24 Stunden erlaubt.

## 🚦 Anwendungsfälle und Empfehlungen {#recommendations}

- **Private und geschlossene Server:** Die Beitrittssperre wird besonders für Server empfohlen, die privat bleiben müssen und keine neuen Mitglieder wünschen (Unternehmensserver, kleine Teams, private Gruppen).
- **Staff-Server:** Für Server, die dem Moderations- oder Administrationsteam gewidmet sind, bei denen nur autorisierte Mitglieder Zugang haben sollen.
- **Unternehmens- oder professionelle Server:** Für Organisationen, die Discord intern nutzen und sicherstellen möchten, dass nur aktuelle Mitarbeiter auf den Server zugreifen können.
- **Communities mit begrenzter Größe:** Für Server, die ihre gewünschte Maximalgröße erreicht haben und dauerhaft keine neuen Mitglieder mehr aufnehmen möchten.

## ❓ Funktionsweise der Beitrittssperre {#working}

RaidProtect schließt die Beitritte auf Ihrem Server endgültig. Im Gegensatz zur nativen Funktion von Discord, die alle 24 Stunden eine manuelle Erneuerung erfordert, ermöglicht diese Methode eine dauerhafte Blockierung ohne Eingriff.

:::info
Mitglieder, die bereits auf dem Server sind, bleiben aktiv und können den Server weiterhin normal nutzen.
:::
:::warning
Die Community-Funktionen von Discord sind für die ordnungsgemäße Funktion der Beitrittssperre unerlässlich. [Folgen Sie unserer Anleitung, um die Aktivierung der Community auf Ihrem Server zu überprüfen.](../guides/community.md)
:::

## 🚩 Konfiguration der Beitrittssperre {#config}

1. Führen Sie den Befehl `/joinlock` aus.
2. Klicken Sie auf die Schaltfläche "**Aktivieren**" oder "**Deaktivieren**".
