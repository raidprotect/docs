RaidProtect ermöglicht es Ihnen, die vom Bot verwendete Sprache zu wählen, um sich bestmöglich an Ihre Discord-Community anzupassen.

:::note
Wenn Ihr Server als Community-Server definiert ist (Discord-Einstellung), verwendet RaidProtect standardmäßig die in den **Community-Einstellungen** des Servers konfigurierte Sprache.
:::

**Öffentliche Nachrichten:** Die konfigurierte Sprache betrifft nur die öffentlichen Nachrichten, die RaidProtect auf Ihrem Server sendet (Logs, Captcha-Nachrichten, Meldungen usw.).

**Ephemere Nachrichten:** Diese privaten oder temporären Nachrichten werden weiterhin in der Sprache des Nutzers angezeigt, der mit dem Bot interagiert.

## 🌐 Liste der unterstützten Sprachen  {#supported}

- **Französisch**
- **Englisch**
- **Deutsch**
- **Spanisch**
- **Brasilianisches Portugiesisch**

## ⚙️ Die Sprache des Bots ändern {#change}

- Führen Sie den [Befehl `/settings`](./setup.md#settings) aus.
- Wählen Sie die Schaltfläche "**Sprache**".
- Wählen Sie die gewünschte Sprache aus.

<LanguageSettingsMockup />

Sobald die Sprache ausgewählt ist, passt der Bot automatisch alle seine Nachrichten, Benachrichtigungen und Befehle an die für Ihren Server gewählte Sprache an.

:::info
Die Sprachunterstützung von RaidProtect entwickelt sich ständig weiter! [Schlagen Sie](https://suggestions.raidprotect.bot) die Sprachen vor, die Sie auf dem Bot sehen möchten, oder [stimmen Sie](https://suggestions.raidprotect.bot) für die vorgeschlagenen Sprachen ab, damit sie hinzugefügt werden.
:::
