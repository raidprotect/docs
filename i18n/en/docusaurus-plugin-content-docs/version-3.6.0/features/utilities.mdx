Extra features to simplify the management of your server. 🔧

In addition to core features like the captcha, anti-spam or anti-raid, RaidProtect offers several secondary tools that can make managing your server even smoother.

## 📋 Duplicate a channel {#channel-duplicate}

The `/channel duplicate` command allows you to fully duplicate a channel, including all its settings, permissions and configurations. It goes beyond Discord's native feature, which cannot duplicate **categories** and **certain specific settings** such as forum channel tags.

Use the command: ```/channel duplicate (#channel)```

Replace `(#channel)` with the mention or the [ID](../guides/id.mdx) of the channel to duplicate.

### 🎯 Features {#duplicate-features}

This command duplicates all of the following elements:

- **Channel name**
- **Permissions** (roles and users)
- **Channel type** (text, voice, forum, etc.)
- **Specific settings** depending on the channel type
- **Position** within the category (if applicable)

### ⚙️ RaidProtect configurations {#duplicate-config}

When you duplicate a channel that has internal RaidProtect configurations, the bot automatically offers you the option to:

- **Replace** the existing configuration to use the new channel
- **Duplicate** the configuration to keep both channels configured

**Example**: If you duplicate the logs channel, RaidProtect will offer to update its configuration so that the new channel becomes the logs channel, or to keep both channels configured, according to your preference.

## 🗑️ Delete and re-create a channel {#channel-clear}

The `/channel clear` command allows you to delete a channel and re-create it identically, keeping its settings, permissions and RaidProtect configurations.

Use the command: ```/channel clear (#channel)```

Replace `(#channel)` with the mention or the [ID](../guides/id.mdx) of the channel to re-create.

:::warning
The channel's messages and webhooks will be permanently deleted. A confirmation will be requested before execution.
:::

## 🧹 Prune members {#prune}

The `/prune` command allows you to kick inactive members from your server via an interactive menu.

Use the command: ```/prune [duration]```

Replace `[duration]` with the desired number of days of inactivity, from 1 to 30. The bot displays an interactive menu allowing you to:
- Select the inactivity duration
- Include or exclude specific roles
- See the number of affected members before confirmation

The confirmation text shows who will really leave:

| Mode | No role selected | Roles selected |
|---|---|---|
| **Include** | Only inactive members with **no role at all** | Inactive members who have **no role other than** the selected ones |
| **Exclude** | All inactive members, **whatever their roles** | Inactive members who have **none of the** selected roles |

:::info
The `/prune` command is reserved for administrators. Only the 100 lowest roles are offered; members who have a higher role are excluded outright.
:::

## 🚫 Block users {#block}

The `/block` command allows you to prevent a user from using certain RaidProtect features on your server (for example, sending reports or receiving the tag role).

When blocking or unblocking, RaidProtect lets you choose which features are affected:

| Type | Effect |
|---|---|
| **All interactions** | Blocks every interaction with the bot |
| **Reports** | The user will no longer be able to send a [report](./reports.md) |
| **Tag Role** | The user will no longer be able to receive the [tag role](./tag-role.md) |

### Block a user {#block-add}

Use the command: ```/block add [@user] [reason]```

### Unblock a user {#block-remove}

Use the command: ```/block remove [@user] [reason]```

### List blocked users {#block-list}

Use the command: ```/block list```

## 🔗 Invite information {#inviteinfo}

The `/inviteinfo` command analyzes a Discord invite before you click on it: useful to check a partnership, an advertisement or a link received in DMs.

Use the command: ```/inviteinfo (invite)```

Replace `(invite)` with the invite's code or link (e.g., `discord.gg/raidprotect`).

For a server invite, we display in particular:

- **The server**: name, badge and tag, ID, number of members and online members, verification level, tier and boosts.
- **The invite**: destination channel (text, voice or stage), creator, number of uses, expiration date, roles assigned on arrival.
- **The themes and games** highlighted by the server (games are clickable).
- **An activity profile**: peak and low hours, regularity.
- A "**Join the server**" button.

Friend, private group, activity and live invites are also recognized.

:::info
On a server, the response is ephemeral and the command requires the "**Manage Messages**" permission by default. If you add RaidProtect to your Discord account, you can also use `/inviteinfo` in DMs and private groups: the response is then visible in the conversation. The `inviteinfo` command is [usable via prefix](../guides/prefix.md) (alias `ii`).
:::

## 🔐 Your data on this server {#privacy}

The `/privacy` command shows what RaidProtect stores about your server. It is open to all members and the response is only visible to you.

Use the command: ```/privacy```

- **Always**: the configuration chosen in `/settings` (kept as long as RaidProtect is on the server) and sanctions (member, moderator, reason and dates) for the moderation history.
- **Depending on your settings**: messages (one hour per channel, in memory, never written to the database) if the anti-spam, reports or [message caching](#message-cache) are active; reports (author, reason and copy of the reported message) if they are enabled.

The response links to our privacy policy, which details durations, sharing and your rights.

## 🗂️ Message caching {#message-cache}

Caching keeps **one hour of messages per channel in memory**, never written to the database. It feeds the [`/snipe`](./moderation.mdx#snipe) command and the snipe part of `/modview`. Without it, these commands find no deleted message.

1. Run the [`/settings` command](../setup.md#settings).
2. Open the "**Utilities**" tab.
3. Click "**Enable**" next to "**Message caching**".

<Settings start="home:utilities" />

:::info
Caching is **disabled by default**. It is enabled automatically, and cannot be turned off, when the [anti-spam](./anti-spam.mdx) or [reports](./reports.md) are active: these features need to read messages. The button then appears grayed out.
:::

## 💬 Share feedback {#feedback}

The `/feedback` command lets you **share feedback, a suggestion or a bug report** directly from Discord, without having to join the support server. On a server, it requires the "**Manage Messages**" permission by default; it also works in DMs with RaidProtect.

Use the command: ```/feedback```

Choose the type of feedback, then fill in the window that opens:

- **Suggestion**: we redirect you to the suggestions page.
- **Report a bug**: choose the category (anti-spam, anti-raid, captcha, sanctions, Authentification Manager, configuration, commands, logs, other); your report is passed on to our team.
- **General feedback**: rate your experience from 1 to 5.
- **Compliment**.

## 🎮 RaidProtect home {#activity-home}

RaidProtect's "**Launch**" button opens the **RaidProtect home** in the Discord Activity. It works on your server, in DMs with the bot, and from RaidProtect added to your Discord account. Nothing is posted in the channel.

- **Demos**: our protections in action in a miniature Discord channel (anti-spam, anti-raid, captcha and the [HoneyPot](./honeypot.md) trap channel).
- **Mini-games**: Firewall, where you defend your server's icon against waves of robots, Snek, Ban Hammer and Quick sort.
- **Leaderboards**: for each game, the top ten players of your server and of all servers, with your rank.

## 🎨 Role information {#roleinfo}

:::info Experiment: Logging Update
`/roleinfo` is part of the **Logging Update**, planned for version 3.8.0. Until its release, the command is an experiment, in public beta for [Premium](/en/premium) servers.
:::

The `/roleinfo` command shows the profile of a server role.

Use the command: ```/roleinfo [role]```

- **Name**, mention and ID
- **Color** or gradient, **icon** or emoji
- **Creation date** and **position** in the role list
- **Displayed separately** and **mentionable**
- **Origin**: role of a bot, an integration, boosts, a subscription, or a linked role
- **Member count** (for `@everyone`, all the server's members)
- **Sensitive permissions**: yes or no for everyone, the details only for moderators

[Server logs](./logs.md) related to a role (role created or edited, role added to or removed from a member) have a "**Role**" button that opens this profile.

:::info
The `roleinfo` command is [usable via prefix](../guides/prefix.md) (alias `ri`), on a server only.
:::

## Frequently asked questions {#faq}

### Why does `/snipe` find no message?

`/snipe` reads the messages kept in memory for one hour. Enable [message caching](#message-cache) in the Utilities tab of `/settings`, or enable the anti-spam or reports, which enable it automatically.

### How do I check a Discord invite before joining a server?

Use `/inviteinfo` with the invite's code or link: we display the server, its creator, its activity and the roles assigned on arrival.

### What does RaidProtect store about my server?

The `/privacy` command details it: the configuration and sanctions permanently, and depending on your settings an hour of messages in memory and reports.

### Who can use `/prune`?

Only administrators, by default. A preview shows the number of members concerned before any kick.
