Questa documentazione ha lo scopo di spiegarti il funzionamento di RaidProtect. Non esitare a farci avere i tuoi commenti perché possiamo migliorarla.
Non dimenticare di [unirti al nostro server Discord](https://raidprotect.bot/discord) per essere informato delle novità sul progetto. Potrai anche contattare il nostro team di supporto che risponderà alle tue domande sull'utilizzo del bot. 😄

## 🚀 Iniziare con RaidProtect {#start}

Per iniziare a usare RaidProtect, ti basta invitarlo sul tuo server usando il link seguente.

<DocCard item={{ type: 'link', href: 'https://raidprotect.bot/invite', label: 'Invita RaidProtect' }} />
<br />

:::danger
Attenzione, circolano **copie del bot** che **usano il nome di RaidProtect**, invitalo solo dal nostro sito ufficiale.
:::

### Prerequisiti {#requirement}

Per garantire il buon funzionamento di RaidProtect:
1. **Concedi il permesso Amministratore** a RaidProtect. Questo gli permette di moderare automaticamente tutti i tuoi canali.
2. **Posiziona il suo ruolo al livello di quello degli amministratori** del tuo server. Il sistema di permessi non permette a RaidProtect di sanzionare gli utenti che hanno un ruolo sopra il suo.

### Installazione {#install}

Una volta aggiunto RaidProtect al tuo server, esegui il comando [`/setup`](./setup.md#install).
