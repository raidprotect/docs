2018 年に [Baptiste](https://baptiste.lol/) によって生み出されて以来、RaidProtect は Discord サーバーのセキュリティに欠かせないフランス語圏のボットのひとつとしての地位を築いてきました。4 年以上にわたる進化と開発を経て、プロジェクトは今、大きな転換期を迎えています。**RaidProtect は、[S*l*ash FR](https://slash.fr.community/) と DFR.gg を手がけるチームに引き継がれました**。この引き継ぎの目的は、ボットの将来を確かなものにし、新たな展望を開き、開発をさらに充実させることです。

<!--truncate-->

## なぜ引き継ぐのか？ {#why}

時が経つにつれ、RaidProtect のようなボットを維持することはますます難しくなっていきました。Discord の変化、API のアップデート、増え続ける負荷により、Baptiste にとって、RaidProtect の安定性と有効性を保ちながら最新の状態を維持することは、ますます困難になっていました。RaidProtect の終了を選ぶのではなく、彼はこのプロジェクトを私たちに託すことを選んだのです。

こうしてチームがバトンを受け継ぎ、RaidProtect にまつわる技術面・運営面の課題に見合ったリソースとスキルを持ち込みました。私たちの目標はシンプルです。これまでの RaidProtect らしさを大切にしながら、ボットを改善し、現代化することです。

## 変わること（そして変わらないこと！） {#changing}

#### ✅ RaidProtect は、あなたが知っているボットのままです {#same}
あなたが使っている機能がなくなることはありません。**同じ理念**を守り、あなたの使い慣れたやり方を壊すことなく改善したいと考えています。セキュリティと信頼性は、これからもプロジェクトの中心にあります。

#### 🔄 より良いパフォーマンスのための技術的な刷新 {#technical-overhaul}
ボットは、より速く、より安定し、Discord の変化により適応できるよう、完全に書き直されました。この刷新は単なる改善ではなく、必要不可欠なものでした。新しいバージョンの Discord API では、旧バージョンのボットはもはや動作しなくなっていたのです。このアップデートにより、新しい機能をより簡単に追加できるようにもなりました。

#### 🛠️ アップデートと新機能の予定 {#updates}
今回の引き継ぎの大きな利点のひとつは、RaidProtect をさらに効果的なものにするために、ようやく時間と資金を投じられるようになったことです。準備中の新機能の一部をご紹介します。
- Discord の標準により沿うための **スラッシュコマンド** への対応。
- 各サーバーのニーズに合わせるための、より多くの **設定オプション**。
- RaidProtect の活躍の場を広げるための **多言語システム**。

#### 🔐 セキュリティへの取り組みを強化 {#safety}
RaidProtect はサーバーを守るために作られたボットであり、それは今も私たちの最優先事項です。Discord の進化を注意深く追い、プラットフォームが提供する新しいツールにボットを適応させていきます。

## あなたの質問に、私たちが答えます（FAQ） {#faq}

RaidProtect の引き継ぎを発表した際、コミュニティから多くの質問をいただきました。サポートサーバーでも、引き継ぎに関するイベントでも、ボットの将来への強い関心を感じました。疑問を解消し、正確にお答えするため、よくある質問をここにまとめました。

#### あなたたちは誰で、なぜあなたたちなのですか？ {#faq-1}

私たちはチームというより友人同士のグループで、2017 年から情熱と専門知識を結集してオンラインコミュニティを築いてきました。また、Discord とそのベストプラクティスに特化したフランス語圏のコミュニティ、S*l*ash FR も立ち上げました。RaidProtect は、このエコシステムに自然に加わることになります。

プロジェクトの背後に企業がいることを不安に思う方もいるでしょう。正直に言えば、はい、RaidProtect の資金を確保する必要があります。これほどの規模のボットを運用するには多くの費用がかかるからです。しかし、ボットの機能を制限したり、すべてを有料にしたりするつもりはありません。現在のすべての機能は無料のままで、有料オプションは高度なツールを求める方のために用意されます。

#### なぜあなたたちのエージェンシーが RaidProtect を引き継ぐのですか？ {#faq-2}
私たちのエージェンシーは、Discord サーバーの運営とボットの開発を専門としています。チームは大規模なプロジェクトに力を注ぎたいと考えており、RaidProtect はその目標にぴったりでした。

#### S*l*ash FR とはどのような関係ですか？ {#faq-3}
S*l*ash FR は、Discord の愛好家が集まるために私たちが作ったコミュニティです。RaidProtect は自然とそこに居場所を見つけますが、あくまで独立したプロジェクトです。

#### RaidProtect の現在のチームは変わりますか？ {#faq-4}
いいえ。コミュニティチームの多くが引き続き活動し、S*l*ash FR からの新メンバーがそれを支えます。Baptiste 本人も、時折プロジェクトをサポートしてくれます。

#### ボットは有料になりますか？ {#faq-5}
現在のすべての機能は **無料のまま** です。ただし、保守と開発の費用をまかなうため、一部の新しい高度な機能はプレミアムサブスクリプションとして提供される場合があります。

#### RaidProtect のデザインやイメージは変わりますか？ {#faq-6}
いいえ、RaidProtect のビジュアルアイデンティティは **変わりません**。ただし、プロジェクトの進化をより反映するため、ウェブサイトは更新されます。

#### あなたたちのチームは、ほかのボットも開発しますか？ {#faq-7}
RaidProtect の取得は、将来的に Discord サーバー向けのほかのツールも提供していきたいという考えの一環です。ただし、現在の優先事項は RaidProtect を最適化し、磨き上げることです。

---

RaidProtect は進化しますが、その精神は変わりません。このボットが多くのサーバーにとってどれほど大切かを私たちは知っています。だからこそ、より信頼でき、より高性能で、あなたのニーズに合ったツールにしていきたいと考えています。

皆さんの信頼に感謝します。冒険はまだ始まったばかりです！🚀
