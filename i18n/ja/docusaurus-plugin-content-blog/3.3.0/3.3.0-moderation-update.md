バージョン 3.3.0 は、処罰の履歴の導入により、Discord サーバーでの処罰の管理を一新します。すべてのモデレーション操作を追跡、管理、分析するための包括的なシステムです。

![RaidProtect Moderation Update のブログ記事ソーシャルカード](./assets/rp-moderation-update.webp)

<!--truncate-->

## 📋 すべての処罰を記録する完全な履歴 {#new}

新しい[処罰の履歴](/docs/features/sanctions)で、すべてのモデレーション操作を記録しましょう。誰が、いつ、なぜ処罰されたのか、もう迷うことはありません。

- **自動で一元管理**：BAN、キック、タイムアウト、AutoMod による処罰が自動で記録されます。
- **[`/sanctions search`](/docs/features/sanctions#search) による高度な検索**：メンバーの履歴を瞬時に見つけられます。
- **[`/sanctions info`](/docs/features/sanctions#info) による詳細表示**：特定の処罰の詳細をすべて確認できます。
- **[`/sanctions edit`](/docs/features/sanctions#edit) による柔軟な編集**：理由を修正したり、既存の処罰を調整したりできます。
- **[`/sanctions delete`](/docs/features/sanctions#delete) による削除または取り消し**：必要に応じて、処罰を取り消したり履歴から消去したりできます。
- **[処罰の状態のスマートな管理](/docs/features/sanctions#status)**

処罰のたびに、メンバーが DM で通知を受け取ったかどうかを確認する受信確認が作成されるようになりました。

---

## ⚡ 新しいモデレーションツール {#moderation}

このアップデートでは、欠かせない 3 つの新コマンドで、モデレーションの手段もさらに充実しました。

- **[`/tempban`](/docs/features/moderation#tempban)**：メンバーを指定した期間だけ一時的に BAN します。
- **[`/warn`](/docs/features/moderation#warn)**：履歴に完全に記録したうえで、メンバーに警告します。
- **[`/untimeout`](/docs/features/moderation#untimeout)**：予定の期限より前にタイムアウトを解除します。

---

## 🛡️ レイドモードと参加ロックの改善 {#raid}

アンチレイドのシステムが、より賢く、より柔軟になりました。

- **自動での無効化**：[レイドモード](/docs/features/raid-mode#raid-mode)と[オート RaidMode](/docs/features/raid-mode#duration)は、一定時間が経過すると自動で無効になります。切り忘れはもうありません！
- **期間の指定**：[`/raidmode`](/docs/features/raid-mode#raid-mode) で有効にする際に、期間を直接指定できます。
- **新しい [`/joinlock`](/docs/features/join-lock) コマンド**：招待を無期限に閉じ、新規参加者を完全にコントロールできます。
- **[アカウントの最低作成日数](/docs/features/raid-mode#minage)の受信確認**：メンバーが説明メッセージを受け取ったかどうかを確認する受信確認が届きます。

---

## ✨ 3.3.0 のそのほかの新機能 {#changelog}

- **処罰専用のログ**：すべての処罰のログを一か所にまとめる専用チャンネルを設定できます。
- **[`/channel duplicate`](/docs/features/utilities#channel-duplicate)**：チャンネルをすべての設定ごとそのまま複製します。
- **`/changelog` コマンド**：Discord から直接変更履歴を確認できます。`/settings` や `/about` からもアクセスできます。
