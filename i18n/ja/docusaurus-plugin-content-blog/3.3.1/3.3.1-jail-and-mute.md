バージョン 3.3.1 では、**Jail**、**ロールによるミュート**、メンバーが自分の処罰を確認できる機能、そして **3 つの新しい言語** の追加により、モデレーションをよりきめ細かく行えるようになりました。

<!--truncate-->

## 🔒 新しい処罰「Jail」 {#jail}

新しい[監禁システム「Jail」](/docs/features/sanctions#jail)で、迷惑なメンバーを BAN せずに隔離できます。メンバーは専用のチャンネルに閉じ込められ、サーバーのほかの場所にはアクセスできなくなります。

- **[`/jail`](/docs/features/moderation#jail)**：メンバーを直ちに監禁します。
- **[`/tempjail`](/docs/features/moderation#tempjail)**：メンバーを指定した期間だけ一時的に監禁します。
- **[`/unjail`](/docs/features/moderation#unjail)**：いつでもメンバーを解放できます。
- **柔軟な設定**：Jail ロールと案内用チャンネルを `/settings` から直接設定できます。

Jail を使えば、最終的な判断を下す前に当該メンバーとやり取りする余地を残しながら、難しい状況に対処できます。

## 🔇 ロールによるミュート：Discord のタイムアウトを超えて {#mute}

Discord のタイムアウトは便利ですが、制約もあります。ボタンやメニューを含め、メンバーの **あらゆる操作をブロック** してしまうのです。タイムアウト中のメンバーは、自分の処罰を確認することも、チケットを開くことも、サーバーの要素に触れることもできません。しかも、その期間は最大 28 日に限られています。

新しい[ロールによるミュート](/docs/features/sanctions#mute)は、これらの問題を解決します。

- [設定可能なしきい値](/docs/features/sanctions#mute-threshold)を超えると、ボットは Discord のタイムアウトの代わりに **ミュートロール** を自動で付与します。メンバーは書き込みができなくなりますが、ボタンやメニューは引き続き使えます。
- `/timeout` と `/untimeout` コマンドは、[`/mute`](/docs/features/moderation#timeout) と [`/unmute`](/docs/features/moderation#untimeout) に変わり、賢く動作します。**しきい値を下回る場合は、通常の Discord のタイムアウトが使われます**。
- 期間に関係なく Discord のタイムアウトを強制する、新しいパラメーター `[force_timeout]` を追加しました。

## ⚡ より充実したモデレーション {#moderation}

このアップデートでは、モデレーターとメンバーの日々を支える新しいツールが加わりました。

- **[コンテキストメニュー](/docs/features/moderation#context-menu)**：コマンドを入力しなくても、プロフィールを右クリックするだけでメンバーを処罰できます。
- **[`/my-sanctions`](/docs/features/utilities#my-sanctions)**：メンバーが自分の処罰を確認できるようにします。アクセスを管理する[公開範囲の設定](/docs/features/sanctions#sanctions-privacy)も用意しています。
- 処罰の理由での **[メディアの表示](/docs/features/sanctions#show-medias)**：画像などの証拠を直接確認できます。
- [`/sanctions search`](/docs/features/sanctions#search) の **フィルターを刷新** し、[モデレーターの種類](/docs/features/sanctions#search)による新しいフィルターを追加しました。
- サポートボットによる処罰の **[インポート／エクスポート](/docs/features/sanctions#import-export)**。

---

## 🌍 RaidProtect が 3 つの新しい言語に対応 {#i18n}

ボットとそのドキュメントが **[5 つの言語](/docs/language)** で利用できるようになりました。

- ドイツ語
- スペイン語
- ポルトガル語

これらの言語が、すでに利用可能だったフランス語と英語に加わります。

## ✨ 3.3.1 のそのほかの新機能 {#changelog}

- **[情報パネル](/docs/features/display)**：`/display public` で、チャンネルに情報パネルを表示できます。RaidProtect は、Discord が対応するすべての言語に翻訳されたメッセージを生成し、通報、処罰の確認、監禁など、その仕組みをメンバーに説明します。
- **[メンバーのブロック](/docs/features/utilities#block)**：[`/block add`](/docs/features/utilities#block-add)、[`/block remove`](/docs/features/utilities#block-remove)、[`/block list`](/docs/features/utilities#block-list) で、特定のメンバーが RaidProtect の特定の機能を使えないようにできます。
- **[`/prune`](/docs/features/utilities#prune)**：より細かい条件で、アクティブでないメンバーを退出させられます。
- **[`/channel clear`](/docs/features/utilities#channel-clear)**：ひとつのコマンドでチャンネルを削除して再作成できます。
- **`/bypass` のログ**：`/bypass` コマンドを完全に追跡できます。
- **詐欺対策**：詐欺の試みを検出する新しいモジュールです。
