バージョン 3.3.3 で、**モデレーターのツールボックス** がさらに充実しました。新しい **集約モデレーションビュー**、強化された処罰（ソフト BAN、silent オプション、Jail ロール）、そしてアンチレイドとスパム対策のいくつかの調整です。

![RaidProtect 3.3.3 ModView のブログ記事ソーシャルカード](./assets/rp-modview.webp)

<!--truncate-->

## 🔍 ModView：メンバーのすべてを、ひとつのコマンドで {#modview}

メンバーの状況を把握するために、複数のコマンドを使い分ける必要はもうありません。新しい [`/modview`](/docs/features/moderation#modview) コマンドは、**集約モデレーションビュー** を開きます。メンバーの情報を完全にまとめて表示し、あらゆるクイックアクションに直接アクセスできます。

- 最新の状態を反映した **[処罰の履歴](/docs/features/sanctions)**。
- スタッフで共有する **[内部のモデレーションメモ](/docs/features/moderation#note)**。
- 直近 1 時間に **[最後に削除されたメッセージ](/docs/features/moderation#snipe)**（ある場合）。

そして何より **クイックアクション** です。コマンドを入力し直したりウィンドウを切り替えたりすることなく、ビューから直接メンバーを処罰（BAN、キック、ミュート、Jail、警告など）したり、メモを編集したりできます。

ModView とあわせて、2 つのコマンドも追加されました。

- **[`/note`](/docs/features/moderation#note)**：スタッフだけが見られる非公開のメモをメンバーに追加します。処罰の履歴を散らかすことなく、モデレーター同士で状況を共有するのに最適です。
- **[`/snipe`](/docs/features/moderation#snipe)**：チャンネルまたはメンバーの、直近 1 時間に削除された最新のメッセージを取得します。

:::tip
ModView はコンテキストメニューからも開けます。プロフィールを右クリック →「**アプリ**」→「**Modview を開く**」。
:::

## ⚖️ 強化された処罰 {#sanctions}

日々の処罰の管理をより細かく行えるよう、いくつかの機能を追加しました。

- **新しい [`/softban`](/docs/features/moderation#softban) コマンド**：メンバーを BAN してから BAN を解除します。メッセージは削除されますが、メンバーは戻ってくることができます。乗っ取られたアカウントの後始末に最適です。
- すべての処罰コマンドに **[`silent` オプション](/docs/features/moderation)**：状況を別途対応したいときに、RaidProtect が対象者に DM を送らないようにします。
- `/ban` と `/tempban` に **[`delete-messages` パラメーター](/docs/features/moderation#ban)**：BAN の時点で、削除するメッセージ履歴の期間を直接選べます。
- **[「Jail ロールで置き換える」モード](/docs/features/sanctions#jail-roles)**：Jail の処罰で、監禁中はメンバーのロールをすべて外し、解放時に自動で元に戻せるようになりました。
- **AutoMod のタイムアウトからロールによるミュートへの変換** *（Premium の公開ベータ）*：Discord の AutoMod が[設定したしきい値](/docs/features/sanctions#mute-threshold)を超えて適用したタイムアウトは、自動で[ロールによるミュート](/docs/features/sanctions#mute)に変換され、RaidProtect のシステムと完全に一貫した運用ができます。

そのほかの細かな改善：処罰の DM の **受信確認の追跡** を改善（受信済み、DM が閉じている、期限切れ、silent）、キック、ソフト BAN、一時 BAN の後に送られる通知 DM に **サーバーへの招待ボタン** を追加、**`/sanctions delete` に理由を追加** できるように、そしてサーバーで **[処罰を完全に無効にする](/docs/features/sanctions#disable)** ことも可能になりました。

## ✨ そのほかの新機能 {#other}

- **RaidProtect のプロフィールのカスタマイズ** *（Premium）*：アバター、バナー、ニックネームの表記スタイルを変更し、ボットをサーバーのビジュアルアイデンティティになじませられます。
- **[スパム対策の処罰の期間](/docs/features/anti-spam#duration)**：スパム対策が適用するすべての処罰の期間を選べます。
- **メッセージコマンドの新しい解析方式**：より厳密に、スラッシュコマンドと一貫した形で解釈します。
- **[DM の自動遮断](/docs/features/raid-mode#close-dm)**：オート RaidMode の有効化と同時に DM を遮断し、レイド中に押し寄せる悪意ある DM を断ち切ります。
- スラッシュコマンドの **`duration` パラメーターでの入力補完**。
- [`/lock`](/docs/features/channel-lock#lock-duration) と [`/slowmode`](/docs/features/moderation#slowmode) に **`[duration]` パラメーター**：変更を一時的に適用でき、後から手動で元に戻す必要がありません。
