ユーザーがメッセージを送れないよう、チャンネルを一時的にロックしたい場面があります。ロックコマンドを使えば、とても簡単です。

## 🔒 チャンネルをロックする {#lock}

次のコマンドを使用します：```/lock [#channel] [duration] [reason]```

このコマンドは、対象チャンネルで **@everyone** ロールからメッセージの送信とスレッドでのメッセージ送信の権限を外し、すべてのユーザーが投稿できないようにします。

- `[#channel]` には、ロックしたいチャンネルのメンションまたは[ID](../guides/id.mdx)を指定します。指定しない場合は、コマンドを実行したチャンネルをロックします。テキスト、アナウンス、ボイス、フォーラム、メディア、ステージのチャンネルとカテゴリーを指定できます。スレッドは指定できません。
- `[reason]` には、チャンネルをロックする理由を入力します（例：*チャットの整理*、*重要なお知らせ*など）。

:::info
同じチャンネルをロックできるのは、10 分に 1 回までです。
:::

### 一時的なロック {#lock-duration}

`[duration]` パラメーターを指定すると、指定した時間が経過した後に**チャンネルが自動でロック解除**されます（例：`15m`、`1h`、`2d`）。手動でロックを解除し忘れる心配なく、手早く場を落ち着かせたいときに便利です。期間の上限は、処罰の最長期間です。

## 🔓 チャンネルのロックを解除する {#unlock}

次のコマンドを使用します：```/unlock [#channel] [reason]```

このコマンドは、**@everyone** ロールのメッセージ送信権限をロック前の状態に戻し、ユーザーが再び投稿できるようにします。`[reason]` には、ロックを解除する理由を入力します（例：*議論の再開*、*お知らせの終了*など）。

:::warning
ロックが正しく機能するには、全員が持つロールのいずれにも、このチャンネルへの書き込み権限が明示的に付与されていない必要があります。付与されている場合、そのロールを持つメンバーは引き続き発言できます。一方、運営チームのロールに設定した許可は有用です。`/lock` の間もスタッフが発言できるようにし、[監査](./audit.md)でも冗長として報告されなくなります。
:::
:::info
`lock` と `unlock` コマンドは[プレフィックスでも使えます](../guides/prefix.md)。「**メッセージの管理**」権限が必要です。RaidProtect がチャンネルの権限を変更するには、「**チャンネルの管理**」と「**ロールの管理**」の権限が必要です。
:::

## ✏️ 鍵マークの設定 {#config}

ロックしたチャンネルの名前に鍵マークを付けるかどうかを選べます。有効にすると、`/lock` はチャンネル名を `🔒-チャンネル名` に変更し、`/unlock` はその接頭辞を外します。チャンネル一覧で、チャンネルの状態が一目で分かります。このオプションは**既定では無効**です。

鍵マークを有効または無効にするには：
1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**ユーティリティ**」タブを開きます。
3. 「**チャンネルロック**」の横にある「**有効化**」（または「**無効化**」）をクリックします。ボタンはスイッチのように機能し、1 回クリックするだけです。

## よくある質問 {#faq}

### 今いるチャンネル以外もロックできますか？

はい、最初の引数でチャンネルを指定します：`/lock #general 30m レイド対応中`。

### ロックされたチャンネルで、なぜ一部のメンバーは書き込めるのですか？

ロックが発言権を外すのは @everyone ロールだけです。このチャンネルへの書き込み権限が明示的に付与されているロールは、その権限を保持します。

### ロックしたチャンネル名に鍵マークを付けるには？

`/settings` の「ユーティリティ」タブで、「チャンネルロック」を有効にします。このオプションは既定では無効です。
