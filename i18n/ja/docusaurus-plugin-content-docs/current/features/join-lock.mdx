RaidProtect の**参加ロック**（ジョインロック）機能は、無効にするまでサーバーへの新規参加を締め出します。Discord 標準のセキュリティ操作「招待を一時停止」は 24 時間しかブロックできませんが、その制限を超えることができます。

## 🚦 利用シーンとおすすめ {#recommendations}

- **非公開・クローズドなサーバー：** 非公開のままにしたく、新規参加を一切望まないサーバー（企業のサーバー、少人数のチーム、プライベートなグループ）に特におすすめです。
- **運営用サーバー：** モデレーションチームや管理チーム専用で、許可されたメンバーだけがアクセスできるべきサーバー向けです。
- **企業・業務用のサーバー：** Discord を社内で使い、現在の従業員だけがサーバーにアクセスできるようにしたい組織向けです。
- **規模を限定したコミュニティ：** 望ましい最大規模に達し、今後は新規メンバーを受け入れたくないサーバー向けです。

## ❓ 参加ロックの仕組み {#working}

参加ロックが有効な間、RaidProtect は、オート RaidMode で選んだ[レイド中の対応](./raid-mode.md#action)を新規参加者に適用します。24 時間ごとに手動で更新する必要がある Discord 標準の機能とは異なり、ブロックは無効にするまで、操作なしで続きます。

| レイド中の対応 | 参加ロックの効果 |
|---|---|
| 「**招待をブロック**」（既定） | サーバーの招待が無効になり、新たに入れる人はいません。 |
| 「**参加者をキック**」（[Premium](/ja/premium)） | 新規参加者は全員キックされ、参加が閉鎖されていることを知らせる DM が届きます。 |
| 「**キャプチャに送る**」 | 新規参加者は**[キャプチャ](./captcha.md)を解けば入室できます**。そのため、サーバーは閉鎖されません。 |
| 「**レイド中はキャプチャを凍結**」 | 参加ロックが有効な間、新規参加者はキャプチャの先で待機します。 |

:::warning
本当に閉鎖しておきたいサーバーでは、「**招待をブロック**」「**参加者をキック**」または「**レイド中はキャプチャを凍結**」を選んでください。「**キャプチャに送る**」では、参加ロックは新規参加者にキャプチャを課すだけになります。
:::
:::info
すでにサーバーにいるメンバーはそのまま活動でき、通常どおりサーバーを利用し続けられます。参加ロックが有効な間、[ようこそメッセージ](./onboarding.md#welcome-message)は送信されません。
:::
:::warning
「**招待をブロック**」の対応では、参加ロックに Discord のコミュニティ機能が不可欠です。[ガイドに従って、サーバーでコミュニティが有効になっているか確認してください。](../guides/community.md)その他の対応は、コミュニティなしで動作します。
:::

## 🚩 参加ロックの設定 {#config}

次のコマンドを使用します：```/joinlock [status]```

- オプションなしの場合、コマンドは参加ロックの状態を、「**有効化**」または「**無効化**」ボタンとともに表示します。
- `[status]` を **True** にすると有効化、**False** にすると無効化が直接行われます。

![/joinlock コマンドのスクリーンショット](../../../../en/docusaurus-plugin-content-docs/current/assets/rp-join-lock.webp)

このコマンドには**サーバー管理**権限が必要で、状態が変わるたびにログチャンネルにメッセージが投稿されます。

:::info
`joinlock` コマンドは[プレフィックスでも使えます](../guides/prefix.md)。参加ロックが有効な間は、[`/raidmode` コマンド](./raid-mode.md#enable)は使用できません。先に参加ロックを無効にしてください。
:::

## よくある質問 {#faq}

### レイドモードとの違いは？

[レイドモード](./raid-mode.md)は一時的（最長 24 時間）で、大量参加の波が来ると自動で有効になることもあります。参加ロックは手動で有効にし、無効にするまで維持されます。

### Discord のコミュニティを有効にする必要はありますか？

オート RaidMode のレイド中の対応が「**招待をブロック**」の場合のみ必要です。その他の対応では、参加ロックはコミュニティなしで動作します。

### 新規メンバーはまだ入室できますか？

「**招待をブロック**」「**参加者をキック**」「**レイド中はキャプチャを凍結**」では入室できません。「**キャプチャに送る**」では、キャプチャを解けば入室できます。
