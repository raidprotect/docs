**サーバーログ**は、サーバーで起きたことを記録します。誰がチャンネルを作成したか、ロールを変更したか、メッセージを削除したか、メンバーをボイスチャンネルから切断したかがわかります。各ログは実行者から始まり（「@モデレーター が #一般 チャンネルを作成しました。」）、変更の前後を表示します。

:::info 実験中：Logging Update
サーバーログは、バージョン 3.8.0 で予定されている **Logging Update** の一部です。リリースまでは実験中で、[Premium](/ja/premium) サーバー向けの公開ベータとして提供されています。
:::

## ⚙️ ログを設定する {#config}

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**モデレーション**」タブを開きます。
3. 「**ログ**」の横にある「**設定**」をクリックします。
4. 「**サーバーログ**」を開き、ファミリーごとにチャンネルを選びます。

各ファミリーには 2 つのリストがあります。

- **送信する種類**：種類のチェックを外すと、その種類はどこにも送信されなくなります。
- **別チャンネルに送る種類**：種類ごとに専用のチャンネルを指定します。専用のチャンネルがない種類は、ファミリーのチャンネルに送信されます。

**上限**：異なるログチャンネルは、無料版で 3 つ、[Premium](/ja/premium) で 15 個まで使えます。Premium でない場合、ログを受け取るのは最初の 3 つのチャンネルだけです。他のチャンネルは一時停止され、設定は保持されます。

[モデレーションログ](./moderation.mdx#logs)の「**全般**」「**モデレーション**」「**キャプチャ**」チャンネルは変わりません。

## 📚 ログのファミリー {#families}

| ファミリー | 記録される内容 |
| --- | --- |
| **チャンネルとロール** | カテゴリ、チャンネル、ボイスチャンネル、スレッドの作成、変更、削除、参加、退出、メンバーの削除（権限を含む）。ロール（とその並べ替え）と Webhook。 |
| **サーバー** | 追加または削除されたボットとそのロール、連携サービス、Discord の AutoMod のルール（追加または削除された単語と表現を含む）、スケジュールイベント。イベントに興味ありのメンバーは [Premium](/ja/premium) 限定です。 |
| **メンバー** | 参加（アカウントの作成からの日数付き）と退出（参加日とロール付き）、作成または削除された招待、ルールへの同意、ロールの付与と削除、ニックネーム、サーバーアバター、非アクティブで削除されたメンバー、ブースト。 |
| **メッセージ** | 削除されたメッセージ（削除した人を含む）、編集されたメッセージ、一括削除、ピン留めとピン留め解除。 |
| **ボイス** <span className="badge-premium">Premium</span> | 参加、退出（セッションの長さ付き）、チャンネルの移動、マイク、スピーカー、カメラ、画面共有。運営チームの操作（ミュート、スピーカーミュート、移動、切断）は実行者とともに別に記録されます。ステージの開始、変更、終了と、発言を始めたメンバーや手を挙げたメンバー。 |
| **絵文字とリアクション** | 絵文字、スタンプ、サウンドボードのサウンドの作成、変更、削除。リアクションの追加と削除は [Premium](/ja/premium) 限定で、既定ではチェックが外れています。 |

編集されたメッセージは、変更の前後を表示します。長いメッセージでは、変更された行だけが表示されます。

操作の実行者が**理由**を入力した場合（Discord の監査ログに表示されます）、その理由がログに表示されます。ロールに関するログには、[`/roleinfo`](./utilities.mdx#roleinfo) の情報を開く「**ロール**」ボタンが付きます。

RaidProtect 自身が削除したメッセージ（スパム対策、ハニーポット、詐欺対策、`/clear`）は、該当するモジュールのログに残り、重複しません。

## 🎨 ログの形式 {#format}

同じ画面の「**ログの形式**」で形式を選びます。

| 形式 | 表示 |
| --- | --- |
| **標準** | 時刻、アイコン、名前付きのメンション、続いて詳細。 |
| **枠付き** | ログごとに色付きの枠と、タイトルと詳細。 |
| **コンパクト** <span className="badge-premium">Premium</span> | ログごとに 1 行：時刻、アイコン、メンション。 |

Premium を失ったサーバーは標準の形式に戻ります。選んだ形式は、Premium に戻ったときのために保持されます。

## 🔘 ログのボタン {#buttons}

ログの種類に応じて、ボタンが付きます：「**チャンネルを見る**」「**メッセージを見る**」「**イベントを見る**」「**絵文字を見る**」（リンク）と「**メンバー情報**」です。「**メンバー情報**」は、メンバーのモデレーションシート（[`/modview`](./moderation.mdx)）を、そのテキストを再現したウィンドウで開きます。ウィンドウ下部の「**完全なシートをアクション付きで自分に送る**」にチェックを入れると、シート全体がボタン付きでチャットに送られます。`/modview` コマンドを使える必要があります。

## 💾 メッセージの保持 {#cache}

削除されたメッセージの内容を表示するため、RaidProtect は最近のメッセージを保持します。無料版では **30 分**、[Premium](/ja/premium) では **24 時間**です。それを過ぎると、ログには内容が保持されていなかったことが表示されます。同じ期間が `/snipe` と `/modview` の snipe の部分にも適用されます。Logging Update では、1 時間ではなくこの期間のメッセージが表示されます。

Premium では、削除されたメッセージの添付ファイルもログにコピーされます（1 ファイルあたり 10 MB、サーバーあたり 100 MB、古いものから順に置き換えられます）。
