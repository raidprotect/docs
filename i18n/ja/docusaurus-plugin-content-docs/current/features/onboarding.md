RaidProtect の**ウェルカム**機能は、Discord サーバーの新規メンバーを参加直後からサポートします。名前入りのカードが付いた**ようこそメッセージ**、**自動ロール**、そして[レイド](/ja/learn/discord-raid)でよく使われる、その場しのぎで作られたアカウントを遠ざける**アカウントの最低作成日数**です。この 3 つの設定は、`/settings` の「**参加**」タブにあり、[キャプチャ](./captcha.md)や[オート RaidMode](./raid-mode.md) と並んでいます。

## ❓ 仕組み {#working}

ユーザーがサーバーに参加すると、入室が認められる前に、[レイドモード](./raid-mode.md#action)、[アカウントの最低作成日数](#minage)、[キャプチャ](./captcha.md)の順に適用されます。入室が認められると、[自動ロール](#autorole)と[ようこそメッセージ](#welcome-message)が届きます。

## 👋 ようこそメッセージ {#welcome-message}

ようこそメッセージは、メンバーがサーバーへの入室を認められたときに、選んだチャンネルに送信されます。あなたのテキストと、メンバーごとに生成される**ウェルカムカード**（アバター、「ようこそ」に続けてサーバー名、メンバー番号）が含まれます。

<Settings start="welcome" />

### ようこそメッセージを有効にする {#welcome-config}

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**参加**」タブを開きます。
3. 「**ようこそメッセージ**」の横にある「**設定**」をクリックします。
4. 「**ようこそチャンネル**」で、メッセージを送信するテキストチャンネルを選びます。チャンネルを選ぶとメッセージが有効になります。

画面右上のスイッチで、ようこそメッセージを有効または無効にできます。メッセージのプレビューが画面の下に表示され、変更のたびに更新されます。

:::info
ようこそチャンネルには、キャプチャ、Jail、ハニーポット、DISCON のチャンネルは指定できません。チャンネルが削除されると、設定は空になります。
:::

### テキストと変数 {#welcome-text}

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**参加**」タブを開きます。
3. 「**ようこそメッセージ**」の横にある「**設定**」をクリックします。
4. 「**メッセージの内容**」で「**テキスト**」をクリックします。
5. メッセージを入力し（最大 1,200 文字）、確定します。空欄にすると、既定のメッセージに戻ります。

<SettingsModal name="welcomeText" />

既定のテキストは「`{user.mention}` さん、**`{server.name}`** へようこそ！ 🎉」で、サーバーの言語で表示されます。次の変数を使えます。

| 変数 | 置き換えられる内容 |
|---|---|
| `{user.mention}` | メンバーのメンション |
| `{user.name}` | ユーザー名 |
| `{user.displayname}` | 表示名 |
| `{user.id}` | [ID](../guides/id.mdx) |
| `{server.name}` | サーバー名 |
| `{server.member_count}` | サーバーのメンバー数 |
| `{server.id}` | サーバー ID |

### メンバーをメンション {#welcome-mention}

「**メンバーをメンション**」オプション（既定で有効）は、ようこそメッセージが投稿されたときに新規メンバーへ通知します。メンションするのは参加者だけで、@everyone やロールをメンションすることはありません。

### ボタン {#welcome-buttons}

メッセージの下に、サーバー内のチャンネルへ誘導するボタン（例：「ルールを読む」）を追加できます。

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**参加**」タブを開きます。
3. 「**ようこそメッセージ**」の横にある「**設定**」をクリックします。
4. 「**ボタンを管理**」で「**ボタンを追加**」を選びます。
5. ボタンに名前を付け、リンク先のチャンネルと、必要に応じて**絵文字**を選びます。標準の絵文字か、このサーバーの絵文字（`<:nom:id>`、`:nom:`、またはその ID）です。無効な絵文字でも保存はでき、ボタンは絵文字なしで作成されます。

ボタンを編集または削除するには、同じ一覧からボタンを選びます。

**上限：** 無料版は 2 個、[Premium](/ja/premium) 版は 4 個。Premium が終了した場合は、最初の 2 個だけが表示されます。

### 色 <span className="badge-premium">Premium</span> {#welcome-color}

[Premium](/ja/premium) では、「**メッセージの内容**」の「**色**」をクリックして、メッセージ左側のバーの色を選べます。一覧にある RaidProtect の色か、16 進コード（例：`#D35F5F`）を指定できます。選ばなかった場合、ボットのニックネームの色を[カスタマイズ](/ja/premium)していればその色、そうでなければ既定の色になります。ウェルカムカードも同じ色で彩られます。

### 大量参加とレイド {#welcome-raid}

- **まとめ表示：** 多くのメンバーが同時に参加した場合、チャンネルが埋め尽くされないよう、参加がまとめて表示されます。
- **レイド中は一時停止：** RaidProtect の[レイドモード](./raid-mode.md)または[参加ロック](./join-lock.mdx)が有効な間は、ようこそメッセージは送信されません。

## 🏷️ 自動ロール {#autorole}

自動ロールは、新規メンバーが参加した時点で、キャプチャが有効な場合は[キャプチャ](./captcha.md)に成功した後で付与されます。以前のキャプチャの自動ロールに代わるもので、その設定は自動で引き継がれています。

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**参加**」タブを開きます。
3. 「**自動ロール**」の横にある「**設定**」をクリックします。
4. 1 つまたは複数のロールを選びます。

すべての自動ロールを外すには、「**リセット**」をクリックします。

<Settings start="autorole" />

**上限：** 無料版は 3 ロール、[Premium](/ja/premium) 版は 10 ロール。

:::warning
権限を持つロールは避けてください。自動で付与されるロールは、何の権限も与えないようにするべきです。RaidProtect は、連携サービスが管理するロール、RaidProtect またはあなたより上位のロール、モデレーション権限を持つロール、キャプチャの未認証ロール（キャプチャの直後に付与されると、メンバーが再びブロックされてしまうため）を拒否します。選択したロールのうち問題のないものは保持され、ほかのロールが拒否される理由は別のメッセージで説明されます（すべて拒否された場合、現在の設定は変更されません）。選んだロールが後から権限を得た場合は、警告します。
:::
:::info
サーバーが自動ロールに別のボットを使っている場合、キャプチャより前にロールが付与されてしまう可能性があります。RaidProtect の自動ロールに置き換えてください。
:::

## 🤖 ボットの参加 {#bots}

既定では、サーバーに追加されたボットは、メンバーと同じように[自動ロール](#autorole)を受け取ります。「**参加**」タブの「**ボット**」セクションで、これを変更できます。

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**参加**」タブを開きます。
3. 「**ボット**」の横にある「**設定**」をクリックします。

- **ボットのロール**：参加するボットごとに、自動ロールの**代わりに**付与されます。ロールを選んでいない場合、ボットは自動ロールを受け取ります。**上限：** 無料版は 1 ロール、[Premium](/ja/premium) では 15 ロールです。RaidProtect は、連携サービスが管理するロール、あなたまたは RaidProtect より上位のロール、**管理者**権限を与えるロールを拒否します。モデレーション権限を与えるロールは警告付きで受け付けられます。信頼できるボットにだけ使ってください。ボットはキャプチャを通らず、参加した時点でロールを受け取ります。
- **許可されていないボットをキック**：追加されたボットはすぐにキックされます。ただし、オーナーが事前に `/bypass bot` コマンドで許可したボットは除きます。既定では無効です。このオプションの有効化・無効化とボットの許可は、**サーバーのオーナーだけ**が行えます。

### ボットを許可する {#bypass-bot}

次のコマンドを使用します：```/bypass bot [bot]```

`[bot]` には、許可するボットを指定します。そのボットは、その後 10 分以内に**1 回だけ**、キックされずにサーバーへ参加できます。ボットを指定しない場合、現在許可されているボットの一覧が表示されます。許可はすべてログに記録されます。

:::info
ボットをキックするには、RaidProtect に「**メンバーをキック**」権限と、そのボットより上位のロールが必要です。ない場合はログにその旨が記録され、ボットは残ります。
:::

## 🎂 アカウントの最低作成日数 {#minage}

セキュリティを強化するため、新規メンバーの Discord アカウントに最低限の作成日数を求められます。レイドの直前に作られたアカウントは入室できません。このフィルターは、参加のたびに適用されます。

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**参加**」タブを開きます。
3. 「**アカウントの最低作成日数**」の横にある「**設定**」をクリックします。
4. 「**アカウントの最低作成日数**」で、2 時間、12 時間、1 日、2 日のいずれか、または「**カスタム値**」（例：`0y 3d 1h`、最大 10 年）を選びます。
5. 「**アクション**」で、新しすぎるアカウントをどう扱うかを選びます。

フィルターを無効にするには、「**リセット**」をクリックします。RaidProtect には `KICK_MEMBERS` 権限が必要です。

<Settings start="minage" />

### アクション {#minage-action}

| アクション | 新しすぎるアカウントへの効果 |
|---|---|
| 「**キック**」（既定） | アカウントが新しすぎる間は、参加を試みるたびにキックされます。 |
| 「**条件を満たすまで隔離**」 | サーバーの中身を何も見られない状態で入り（[Jail ロール](./sanctions.mdx#jail)による）、必要な日数を満たすと、記載された日付に隔離から出られます。 |
| 「**入口で足止め**」 | [キャプチャ](./captcha.md)で止められ、必要な日数に達するまで解答できません。 |

アカウントには、サーバーにアクセスできるようになる日付を記載した DM が届きます。キック、隔離、BAN は、ログチャンネルに記録されます。

:::info
- 「**条件を満たすまで隔離**」には Jail ロールが必要で、「**モデレーション**」タブ > 「**処罰**」で設定します。ない場合、RaidProtect は設定するか、「**条件を満たすまで BAN**」に切り替えるかを提案します。後者では、アカウントはサーバーから出され、BAN は適切な日付に自動で解除されます。
- 「**入口で足止め**」には、**パネル（インタラクティブ）**モードで有効なキャプチャが必要です。
:::

### 🎫 アカウントの最低作成日数のバイパス {#bypass-minage}

次のコマンドを使用します：```/bypass minage [user]```

`[user]` には、対象の[ID](../guides/id.mdx)を指定します。そのユーザーは 10 分間、必要な作成日数に妨げられずにサーバーへ参加できます。ユーザーを指定せずにコマンドを使うと、現在のバイパス対象ユーザーの一覧が表示されます。このコマンドは、新しすぎるアカウントの隔離も解除します。`/unjail` では解除されず、使うべきコマンドが示されます。

## よくある質問 {#faq}

### ようこそメッセージはいつ送信されますか？

メンバーの入室が認められたときです。キャプチャが適用されない場合は参加直後に、適用される場合はキャプチャに成功した後に送信されます。レイド中や参加ロック中は送信されません。

### ウェルカムカードを外せますか？

いいえ、ウェルカムカードはすべてのようこそメッセージに添付されます。Premium では色を変更できます。

### 自動ロールはいくつ付与できますか？

無料版は 3 ロール、Premium では 10 ロールです。モデレーション権限を持つロールは拒否されます。

### 自動ロールはキャプチャの前に付与されますか？

いいえ。メンバーにキャプチャが適用される場合、自動ロールはキャプチャに成功した後に付与されます。

### 最低作成日数はどれくらいにすべきですか？

数時間から 1 日程度で、レイド用に作られたアカウントの大半を排除でき、本物のメンバーの邪魔にもなりません。[`/setup` コマンド](../setup.md)は、既定で 6 時間に設定します。

### 新しすぎるアカウントは BAN されますか？

いいえ、既定では BAN されません。参加を試みるたびにキックされます。必要な作成日数まで隔離したり、キャプチャで足止めしたりすることもできます。一時的な BAN は、Jail ロールが設定されていない場合の代替手段にすぎません。
