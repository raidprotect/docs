RaidProtect では、Discord コミュニティに合わせてボットが使用する言語を選べます。

**公開メッセージ：** 設定した言語は、RaidProtect がサーバーに送信する公開メッセージ（ログ、キャプチャ、通報など）に適用されます。

**エフェメラルメッセージ：** 非公開または一時的なメッセージは、ボットを操作したユーザーの言語で表示されます。

## 🌐 対応言語一覧 {#supported}

- **フランス語**
- **英語**
- **スペイン語**
- **ドイツ語**
- **ブラジルポルトガル語**
- **イタリア語**
- **トルコ語**
- **ベトナム語**
- **日本語**
- **簡体字中国語**
- **繁体字中国語**

完全に翻訳された言語のみが選択肢として表示されます。別の言語で Discord を使っているメンバーへのエフェメラルな返信は、英語で表示されます。

## ⚙️ ボットの言語を変更する {#change}

1. [`/settings` コマンド](./setup.md#settings)を実行します。
2. 「**全般**」タブで、「**言語**」の横にある「**編集**」をクリックします。
3. 一覧から希望の言語を選び、確定します。

<SettingsModal name="lang" />

変更は即座に反映され、サーバーのログにも記録されます。

### サーバーの言語に合わせる {#follow}

最初の選択肢「**サーバーの言語に合わせる**」は、Discord のコミュニティ設定で定義された主要言語を使用します。これが既定の設定です。その言語が対応言語に含まれていない場合、RaidProtect は英語で応答します。

:::info
RaidProtect の言語対応は常に進化しています。ボットに追加してほしい言語を[提案](https://suggestions.raidprotect.bot)するか、提案されている言語に[投票](https://suggestions.raidprotect.bot)して、追加を後押ししてください。
:::
