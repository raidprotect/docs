RaidProtect のすべてのコマンドを、カテゴリー別にまとめています。コマンド名をクリックすると、詳しいドキュメントに移動します。

## プロトタイプの凡例 {#legend}

- `(arg)`：**必須**の引数。
- `[arg]`：**任意**の引数。
- `[--flag]`：任意の真偽値フラグ（スラッシュ：`flag: true`、メッセージ：`--flag`）。
- `[--flag=value]`：値を取る任意のフラグ。
- `(@member)` / `(#channel)` / `(@&role)`：想定される型を示す接頭辞。

## ⚙️ コマンドの 2 つの使い方 {#usage}

よく使うモデレーションコマンドには、2 つの形式があります。スラッシュと、プレフィックス付きのメッセージです。`/sanctions`、`/snipe`、`/audit` など、その他のコマンドはスラッシュでのみ使えます。プレフィックスに対応するコマンドは、[メッセージコマンドの一覧](./guides/prefix.md#activated)で確認できます。

### スラッシュコマンド：いちばん簡単 {#slash}

チャンネルで `/` を入力してコマンドを選ぶと、**Discord が各パラメーターを専用のインターフェースで提示します**（ユーザーセレクター、チャンネルセレクター、期間のオートコンプリートなど）。既定ではこの方法をおすすめします。何も覚える必要がありません。

```
/ban @member reason: 詐欺スパム
```

### メッセージコマンド：いちばん複雑 {#prefix}

[`/settings` でメッセージコマンドを有効](./guides/prefix.md)にすると、通常のメッセージとしてコマンドを書くこともできます（`?ban …`、`?kick …` など）。グラフィカルなインターフェースはなく、**構文を知っている**必要があります（位置引数、名前付きフラグ、行末の自由引数）。その代わり、コマンドに慣れたモデレーターにとっては、キーボードで素早く操作できます。

#### 位置引数

プロトタイプの順に、名前なしで指定します。コマンドの主な引数です。

```
?ban 123456789012345678
?slowmode 10s
```

#### 名前付きフラグ（`--name=value`）

補助的なオプション用です。フラグは、コマンドの**どこにでも**、どんな順序でも置けます。

- `--silent`（真偽値）：オプションを有効にするだけです。
- `--delete-messages=7d`：オプションに値を渡します。

```
?ban @member --delete-messages=7d --silent BANの理由
?tempban @member 1d --silent また同じことをした
```

#### 「rest」引数（自由テキスト）

一部のコマンドの最後の引数（通常は `[reason]`）は、**その後に書いたすべて**を、スペースも含めて、引用符なしで取り込みます。

```
?warn @member またサーバーのルール3に違反しました
```
