**複数アカウント**機能では、複数の Discord アカウントが同一人物のものであることを、運営チームが宣言できます。一方への[処罰](./sanctions.mdx)は他方にも及ぶため、BAN されたメンバーが 2 つ目のアカウントで戻ってきて処罰を回避することはできなくなります。

:::info 実験中：Identity Update
複数アカウントは、バージョン 3.7.0 に予定されている **Identity Update** の一部です。リリースまでは実験中で、[Premium](/ja/premium) サーバー向けに公開ベータとして提供されています。
:::

## ❓ 仕組み {#working}

- **1 人につき 1 グループ**：グループは、運営チームが同一人物と判断したアカウントをまとめたものです。グループはサーバーごとに独立しており、他のサーバーと共有されることはありません。
- **処罰の共有**（[Premium](/ja/premium)）：BAN、キック、ミュート、監禁、タイムアウトは、処罰ごとに選んだ[モード](#modes)に従って、グループの他のアカウントにも及びます。処罰は対象アカウントの名義のままで、他のアカウントはその状態を引き継ぎます。Premium でない場合、アカウントの連携と確認はできますが、処罰は及びません。その場合、処罰のログにそのメンバーの他のアカウントが記載されます。
- **共通の解除**：いずれかのアカウントの処罰を解除すると、Premium の有無にかかわらず全員の処罰が解除されます。
- **まとめて検索**：あるアカウントの[処罰を検索](./sanctions.mdx#search)すると、グループの他のアカウントの処罰も表示されます。
- **Discord の AutoMod**：Discord の AutoMod によるタイムアウトやミュートも、連携したアカウントに及びます。
- **キャプチャによる検知**：[キャプチャの Activity](./captcha.md#activity-alts) は、同一人物と確実に判断できる 2 つのアカウントを自動で連携したり、運営チームに連携を提案したりできます。
- **ログ**：連携、解除、主アカウントの変更は、[モデレーションログ](./moderation.mdx#logs)に記録されます。

**上限：** なし。グループあたりのアカウント数にも、グループ数にも制限はありません。

## 🔗 /alt でアカウントを連携する {#alt}

次のコマンドを使用します：```/alt [user] [other]```

- オプションなし：サーバーの連携アカウントのグループ一覧を表示します。「**2つのアカウントを連携**」ボタンで、サーバーの 2 人のメンバー、またはサーバーにいない 2 つのアカウントを ID で連携できます。
- `[user]` を指定：そのアカウントのグループを表示します。他に連携がなければ、そのアカウントだけを表示します。各アカウントは状態（サーバーでBAN済み、サーバーに参加中、サーバーに不在、隔離）とともに表示され、主アカウントが先頭に来ます。
- `[user]` と `[other]` を指定：2 つのアカウントを同一人物として直接連携します。

`[user]` と `[other]` には、対象アカウントのメンションまたは[ID](../guides/id.mdx)を指定します。ボットは連携できません。

グループのパネルでは、次の操作ができます。

- 「**メンバーを連携**」：グループにアカウントを追加します。サーバーのメンバー、またはサーバーにいないアカウントの Discord ID を指定できます。
- 「**グループのアカウントを編集**」セレクターでは、ウィンドウが開き、そのアカウントを「**グループの主アカウント**」にしたり、「**このアカウントをグループから外す**」ことができます。外したアカウントは同一人物として扱われなくなりますが、グループとともに BAN されていた場合は、BAN されたままです。

メンバーの連携アカウントは、「**管理**」ボタンから、[モデレーションビュー `/modview`](./moderation.mdx#modview)でも確認できます。

:::info
`/alt` コマンドとそのボタンには、**メンバーをBAN**の権限が必要です。
:::

## 🛠️ 複数アカウントの設定 {#config}

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**モデレーション**」タブを開きます。
3. 「**複数アカウント**」の横にある「**設定**」をクリックします。

<Settings start="alts" />

### 連携アカウントの処罰 <span className="badge-premium">Premium</span> {#modes}

処罰ごとに、グループへどのように及ぼすかを選びます。

1. 複数アカウントの画面で、「**連携アカウントの処罰**」の横にある「**編集**」をクリックします。
2. ウィンドウで、処罰ごとにモードを選びます。

画面の「**すべてを次に設定…**」セレクターを使うと、すべての処罰に同じモードを一度に適用できます。

<SettingsModal name="altsModes" />

| モード | 効果 | 対象の処罰 |
|---|---|---|
| 「**即時**」（既定） | BAN：連携したすべてのアカウントが、参加中かどうかにかかわらず直ちに BAN されます。キック：サーバーに参加中の連携アカウントもキックされます。ミュート、監禁、タイムアウト：参加中のアカウントは直ちに処罰され、それ以外は参加時に処罰されます。 | すべて |
| 「**参加中は即時、それ以外は参加時**」 | 参加中のアカウントは直ちに BAN され、不在のアカウントは、BAN 期間中にサーバーに参加した場合に BAN されます。 | BAN |
| 「**罠**」 | 対象のアカウントだけが処罰されます。処罰期間中に、グループの別のアカウントが参加したり書き込んだりすると、回避とみなされ、[回避への処罰](#evasion)を受けます。 | キック以外すべて |
| 「**無効**」 | 処罰は選んだアカウントにのみ適用されます。 | すべて |

### グループ処罰 {#group-sanction}

処罰が複数のアカウントに及ぶと、履歴（[`/sanctions`](./sanctions.mdx#search)、`/modview`）には**1 件のグループ処罰**（たとえば「**グループBAN**」）として表示され、対象のアカウント（「**アカウント**」）とそれぞれの状態が一覧になります。各アカウントには専用の行があり、「グループ処罰 `ID` の一部です。」と表示されます。グループ処罰を取り消す、削除する、または変更する（理由、期間）と、すべてのアカウントに同時に反映されます。アカウントが確認できるのは、`/my-sanctions` で自分の行だけです。

### 回避への処罰 {#evasion}

回避への処罰は、「**罠**」モードで検知された連携アカウントに適用されます。グループが処罰を受けている間に、サーバーに参加したり書き込んだりしたアカウントが対象です。

1. 複数アカウントの画面で、「**回避への処罰**」の横にある「**編集**」をクリックします。
2. ウィンドウで「**処罰**」と、必要に応じて「**期間**」を選びます。

<SettingsModal name="altsEvasion" />

- 「**処罰の残り期間**」（既定）：そのアカウントは、グループの処罰が終わるまでそれを共有し、自身の名義の処罰は受けません。
- **特定の処罰**（BAN、キック、ミュート、監禁、タイムアウト）：そのアカウント名義で、独自の期間で科され、グループの解除では解除されません。期間を空欄にすると無期限の処罰になります（例：`1h`、`3d`、`2w`）。

:::info
タイムアウトには必ず期間が必要で、最長 28 日です。ミュートと監禁には、それぞれの[ロール](./sanctions.mdx#config)の設定が必要です。
:::

### 1人1アカウント {#single-account}

この設定では、各グループの**主アカウント**だけがサーバーで活動できます。その他のアカウントは、[Jail ロール](./sanctions.mdx#jail)で**隔離**されます（履歴では処罰「**隔離**」）。主アカウントになったり、グループから外されたりすると、自動で隔離が解除されます。

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**モデレーション**」タブを開きます。
3. 「**複数アカウント**」の横にある「**設定**」をクリックします。
4. 「**1人1アカウント**」の横にある「**有効化**」をクリックします。

:::warning
この設定には [Jail ロール](./sanctions.mdx#jail)が必要です。ない場合、RaidProtect は有効化を拒否します。
:::

グループの主アカウントを変更するには、いずれかのアカウントで `/alt` を使い、「**グループのアカウントを編集**」セレクターを使います。

## よくある質問 {#faq}

### 複数アカウントはサーバー間で共有されますか？

いいえ。グループはサーバーごとに独立しており、他のサーバーと共有されることはありません。

### アカウントの 1 つの BAN を解除するとどうなりますか？

いずれかのアカウントの処罰を解除すると、グループのすべてのアカウントで解除されます。

### サーバーにいないアカウントも連携できますか？

はい。`/alt` のパネルで「**メンバーを連携**」をクリックし、Discord ID を入力します。

### /alt を使えるのは誰ですか？

**メンバーをBAN**の権限を持つメンバーです。Identity Update が実験中の間は、[Premium](/ja/premium) サーバーに限ります。
