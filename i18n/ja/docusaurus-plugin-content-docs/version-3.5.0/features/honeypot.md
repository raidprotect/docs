RaidProtect の**ハニーポット**（罠チャンネル）は、スパム対策の機能です。**[誰も書き込んではいけない](/ja/learn/honeypot-warming)**チャンネルを設置します。本物のメンバーはこのチャンネルを避けるべきだと知っているため、ここに投稿するのは**[乗っ取られたアカウント](/ja/learn/token-grabber)**かスパムボットだけです。RaidProtect は、それらを自動で処罰します。

:::info
**ScamLens はすでに既定で有効です。** 詐欺対策の [ScamLens](./scam-images.md) は、設定なしでサーバーで有効になっています。**詐欺画像**に特化しており、検出、削除、乗っ取られたアカウントの処罰を非常に高い信頼性で行います。そのため、画像による詐欺には ScamLens で十分です。ハニーポットは、最大限のセキュリティを求める場合や、**その他の種類のスパム**（リンクのスパム、テキストによるレイド、ボット）をブロックしたい場合に特に役立ちます。
:::

## ❓ 仕組み {#working}

ハニーポットを有効にすると、RaidProtect はサーバーの**一番上**に、分かりやすい名前をランダムに付けたテキストチャンネルを作成します。このチャンネルには 3 つの特徴があります。
- **誰でも書き込めます。** キャプチャをまだ通過していないメンバーや、[Jail ロール](./sanctions.mdx#jail)を持つメンバーも含みます。意図的な設計です。乗っ取られたアカウントやボットが、罠を避けられてはいけません。
- チャンネルの作成時に**警告メッセージ**（「ここにメッセージを送信しないでください」）が投稿され、誰でも自分の言語で読めるよう「**Translate**」ボタンが付きます。
- 最初のアカウントが捕まった時点から、「**Translate**」の横に**報告されたアカウント数のカウンター**がボタンとして表示されます。

メンバーがこのチャンネルに投稿すると、次のように処理されます。
- RaidProtect は、**選んだ処罰**（BAN、ソフトBAN、キック、タイムアウト、Jail、ミュート）を適用します。本人に DM は送りません。
- そのメンバーが**過去 10 分間に送信したメッセージ**が、スパムがすでに他のチャンネルに広がっている場合に備えて、サーバー全体で削除されます。
- 操作は自動モデレーションのログに追加されます（理由：*乗っ取られたアカウントによるスパム*）。

[処罰までの猶予](#grace)を選んだ場合は、まずメンバーに「誤りでした」と伝える機会が与えられます。

## 🛠️ ハニーポットの設置 {#config}

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**保護**」タブを開きます。
3. 「**ハニーポット**」の横にある「**設定**」をクリックします。
4. 右上の「**有効化**」をクリックします。RaidProtect がチャンネルを作成し、権限を設定して、警告メッセージを投稿します。

<Settings start="honeypot" />

チャンネルを作成した後は、次の操作ができます。
- **チャンネルを再生成**（「**ハニーポットのチャンネル**」の横のボタン）：古いチャンネルを削除し、新しい名前で新しいチャンネルを作成します。メンバーが罠チャンネルの名前を共有して、他のアカウントが避けられるようにしたと思われる場合に役立ちます。
- **無効化**（右上のスイッチ）：チャンネルを削除し、機能を停止します。

:::warning 必要な権限
RaidProtect には `チャンネルの管理` と `メンバーをBAN` の権限が必要です。ない場合はエラーの案内が表示され、ボタンはグレーアウトされます。
:::

### 処罰を選ぶ {#sanction}

既定では、ハニーポットは**ソフトBAN**を適用します。「**適用する処罰**」セレクターから、複数の[処罰](/ja/learn/discord-sanctions)を選べます。

| 処罰 | 効果 | 利用条件 |
|---|---|---|
| **BAN** | メンバーをサーバーから追放し、最近のメッセージを削除します。一時的（既定は 1 日）。 | 無料 |
| **ソフトBAN** | BAN した後に解除します。メッセージは削除されますが、メンバーは戻れます | 無料 |
| **キック** | メンバーを追放します。自由に戻れます | Premium |
| **タイムアウト** | 選んだ時間、メンバーが発言できなくなります（最大 28 日） | Premium |
| **Jail** | サーバーで設定した [Jail ロール](./sanctions.mdx#jail)を付与します | Premium |
| **ミュート** | サーバーで設定した[ミュートロール](./sanctions.mdx#mute)を付与します | Premium |

期間のある処罰（BAN、タイムアウト、Jail、ミュート）では、「**期間**」セレクターで期間を選びます。5 分、1 時間、**1 日**（既定）、28 日、または「**カスタム値**」で自分の値（例：`5m`、`1h`、`2d`。最小 1 分）を入力します。ソフトBAN とキックには期間がないため、セレクターはグレーアウトされます。

:::tip
**ソフトBAN**は良い妥協点です。メッセージを一掃して乗っ取られたアカウントを追放しますが、正当な持ち主はアカウントを安全にした後に戻れます。
:::

:::info
**BAN** と **ソフトBAN** だけが、Discord の標準機能で、乗っ取られたアカウントのメッセージを**サーバー全体**から一度に削除できます。
その他の処罰（キック、タイムアウト、Jail、ミュート）では、RaidProtect 自身がメッセージを削除します。これらは [Premium](/ja/premium) サーバー専用です。
:::

:::info
- ロールが未設定の **Jail** または**ミュート**は、**タイムアウト**になります。セレクターの処罰の下にその旨が表示されます。
- サーバーが Premium を失った場合、Premium 限定の処罰は、次の作動時に自動で**ソフトBAN**に戻ります。
:::

### 処罰までの猶予 <span className="badge-experiment">実験中</span> {#grace}

善意のメンバーが、誤ってハニーポットに書き込んでしまうことがあります。**処罰までの猶予**は、処罰される前に、それを知らせる時間を与えます。

:::info 実験中：Shield Update
処罰までの猶予は、バージョン 3.6.0 に予定されている **Shield Update** の一部です。リリースまでは実験中で、[Premium](/ja/premium) サーバー向けに公開ベータとして提供されています。
:::

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**保護**」タブを開きます。
3. 「**ハニーポット**」の横にある「**設定**」をクリックします。
4. 「**処罰までの猶予**」で、「**すぐに処罰**」（既定）または「**先に確認し、後で処罰**」（30 秒、1 分、2 分、5 分）を選びます。

猶予を設定すると、次のようになります。
- メッセージは**削除**され、罠チャンネルでメンバーに**メンション**が送られ、「**誤りでした**」ボタンが表示されます。
- このボタンを押せるのは、そのメンバーだけです。時間内に押せば、処罰は適用されません。
- 猶予が終わるまでに押されなければ、処罰が適用されます。

:::info
スパムボットは、通常どこにでも同じテキストを投稿します。**同じメッセージ**を別の場所に投稿したアカウントは、待たずに**すぐ**処罰されます。
:::

### 除外するメンバー {#ignore}

ハニーポットへの投稿で**処罰しない対象**は、「**除外するメンバー**」セレクターで選べます。
- 「**なし（モデレートできないメンバーを除く）**」（既定）：運営メンバーを含め、全員が処罰されます。ボットがモデレートできないメンバー（RaidProtect より上位のロール）だけが自動で除外されます。
- 「**運営（管理者 / サーバー管理 / チャンネルの管理）**」：`管理者`、`サーバー管理`、`チャンネルの管理` の権限を持つメンバーは処罰されません。
- 「**スパム対策で除外されているメンバー**」：RaidProtect は、[スパム対策](./anti-spam.mdx#ignore)で除外されているロールとメンバーを再利用します。この一覧が空の場合は、`管理者`、`サーバー管理`、`メッセージの管理` の権限を持つメンバーが除外されます。

:::info
いずれの場合も、RaidProtect は**自分自身や他のボットを処罰しません**。ボットがハニーポットを作動させることはありません。
:::

## ℹ️ /honeypot コマンド {#command}

`/honeypot` コマンドは、`/settings` を経由せずに、ハニーポットの設定画面を直接開きます。`サーバー管理` 権限が必要です。

次のコマンドを使用します：```/honeypot```

## 🤝 ハニーポットと ScamLens は、組み合わせるとさらに効果的 {#scamlens-combo}

RaidProtect にはすでに **[ScamLens](./scam-images.md)** が組み込まれており、画像を分析して、既知の詐欺（仮想通貨、偽のプレゼント企画、偽のカジノ宣伝）にあたるものを削除します。

この 2 つは連携して動作します。
- **ScamLens が先に処理します。** ハニーポットに投稿された画像がすでに知られている場合、メッセージを削除して乗っ取られたアカウントを処罰するのは ScamLens です。ハニーポットの処罰は重ねて適用されません。
- **ハニーポットがそれ以外を引き継ぎます。** まだ知られていない新しい画像、リンクのスパム、大量メンション、テキストによるレイド、ボットなどです。
- **ハニーポットで捕まえた新しい画像は、すべて ScamLens を強化します。** その後、保護されているすべてのサーバーでブロックできるようになります。
- **ScamLens はハニーポットに従います。** 独自の設定をしない限り、ハニーポットの[処罰と期間](./scam-images.md#config)を適用します。

ScamLens は、すでにサーバーで既定で有効です。**ハニーポットを有効にしても、何も壊れません。**既存の保護を補完し、RaidProtect がコミュニティ全体をよりよく守る助けになります。

## よくある質問 {#faq}

### ScamLens があれば、ハニーポットは必要ですか？

画像による詐欺には、ScamLens で十分です。既定で有効で、検出、削除、処罰をすべて自動で行います。ハニーポットは、リンクのスパム、テキストによるレイド、ボットなど、その他の種類のスパムをブロックするのに特に役立ちます。

### ハニーポットはどんな処罰を適用しますか？

既定ではソフトBAN です。別の処罰も選べます。BAN とソフトBAN は無料で、キック、タイムアウト、Jail、ミュートは Premium サーバー専用です。ハニーポットの BAN は既定で 1 日で、期間は変更できます。

### メンバーが誤ってハニーポットに書き込んでしまいました。どうすればよいですか？

処罰までの猶予を有効にしてください。メッセージが削除され、メンバーにメンションが送られ、30 秒から 5 分の間に「誤りでした」をクリックできます。時間内にクリックすれば処罰されません。ただし、同じメッセージを他の場所にも投稿したアカウントは、すぐに処罰されます。

### 運営メンバーがハニーポットに書き込んだら処罰されますか？

「除外するメンバー」オプション次第です。既定では、運営メンバーを含め全員が処罰されます。RaidProtect が自分自身を処罰することはなく、ボットが罠を作動させることもありません。

### ハニーポットに捕まったアカウントのメッセージはどうなりますか？

処罰に加えて、そのメンバーが過去 10 分間に送信したメッセージが、スパムがすでに他のチャンネルに広がっている場合に備えて、サーバー全体で削除されます。
