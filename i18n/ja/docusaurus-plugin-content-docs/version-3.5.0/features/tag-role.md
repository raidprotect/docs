タグロールは、[サーバーのタグ](https://support.discord.com/hc/ja/articles/31444248479639-%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC%E3%82%BF%E3%82%B0)を Discord のプロフィールに追加したメンバーに、自動でロールを付与する機能です。こうしたメンバーにロールを付与することで、その貢献を評価し、サーバーを積極的に代表してもらうよう促せます。コミュニティの一体感を高めながら、最も忠実なアンバサダーに報いる、シンプルで効果的な方法です。

## ❓ タグロールの仕組み {#working}

仕組みはシンプルです。メンバーが Discord のプロフィールにサーバーのタグを追加すると、RaidProtect が自動で専用のロールを付与します。
メンバーがタグを外すと、ロールも外されます。

変更は、そのメンバーのプロフィールが次に更新されたとき（ニックネーム、アバター、バナー、ロール、タグなど）に検出されます。

:::info
タグが有効でない場合や、サーバーでまだこの機能が使えない場合、タグロールは何の効果もありません。
:::

## 🎖️ タグロールの設定 {#config}

設定は数クリックで完了します。
1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**ユーティリティ**」タブを開きます。
3. 「**タグロール**」の横にある「**設定**」をクリックします。
4. セレクターで既存のロールを選ぶか、「**代わりに作成する**」をクリックします。権限を一切持たない `Tag` ロールが作成されます。
5. 「**リセット**」ボタンをクリックすれば、いつでもタグロールを無効にできます。

タグロールの設定を変更するたびに、サーバーのログに記録されます。

:::tip
メンバーには、次にプロフィールを変更したとき（ニックネーム、アバター、バナー、ロール、タグなど）にロールが付与されます。
:::

### /tagrole コマンド {#command}

次のコマンドを使用します：```/tagrole```

`/settings` を経由せずに、タグロールの設定画面を直接開きます。「**ロールの管理**」権限を持つメンバー専用です。

### 拒否されるロール {#refused-roles}

タグロールは任意のメンバーに自動で付与されるため、問題を起こしかねないロールは拒否されます。

- **RaidProtect がすでに使っているロール**：Jail ロール、ミュートロール、キャプチャの認証ロール、自動ロール。
- **アプリまたはサーバーブーストが管理しているロール**：Discord は手動での付与を禁止しています。代わりに通常のロールを作成してください。
- **RaidProtect のロールより上にあるロール**：**サーバー設定 > ロール**で RaidProtect のロールを上にドラッグしてください。
- **あなたの最上位のロールより上にあるロール**（サーバーのオーナーを除く）。
- **機密性の高い権限を持つロール**：管理者、BAN、キック、サーバー管理、チャンネル・メッセージ・ロール・ウェブフック・表現・イベント・スレッドの管理。

### 警告の表示 {#warnings}

タグロールが機能しないとき、設定画面で警告されます。

- **権限不足**：RaidProtect には「**ロールの管理**」権限が必要です。`/settings` の「ユーティリティ」タブの「**タグロール**」の横にも、⚠️ の警告が表示されます。
- **サーバータグが有効でない**：サーバーで[サーバータグ](https://support.discord.com/hc/ja/articles/31444248479639-%E3%82%B5%E3%83%BC%E3%83%90%E3%83%BC%E3%82%BF%E3%82%B0)機能が有効になっていないため、現時点ではタグロールは何の効果もありません。

修正後は、「**再読み込み**」をクリックして再確認してください。

## よくある質問 {#faq}

### タグを付けているメンバーに、まだロールが付かないのはなぜですか？

タグは、メンバーのプロフィールが次に更新されたときに検出されます。何も変更していない間（ニックネーム、アバター、ロール、タグなど）は、ロールは付与されません。必要に応じて、サポートが完全な同期を実行できます。

### ロールが拒否されるのはなぜですか？

タグロールには、RaidProtect がすでに使っているロール、アプリが管理しているロール、RaidProtect またはあなたより上にあるロール、機密性の高い権限を持つロールは使えません。

### タグロールを設定できるのは誰ですか？

管理者は `/settings` から、「ロールの管理」権限を持つメンバーは `/tagrole` コマンドで設定できます。
