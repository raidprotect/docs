## 🚀 RaidProtect を始める {#start}

RaidProtect を使い始めるには、次のリンクからサーバーに招待するだけです。

<DocCard item={{ type: 'link', href: 'https://raidprotect.bot/invite', label: 'RaidProtect を招待' }} />
<br />

:::danger
ご注意ください。**RaidProtect の名前を使った偽のボット**が出回っています。招待は必ず公式サイトから行ってください。
:::

### 前提条件 {#requirement}

RaidProtect を正しく動作させるために、次の 2 点を行ってください。
1. RaidProtect に**管理者権限を付与**します。これにより、すべてのチャンネルを自動でモデレートできます。
2. RaidProtect の**ロールを、サーバーの管理者と同じ位置に配置**します。権限の仕組み上、RaidProtect は自分より上位のロールを持つユーザーを処罰できません。
