RaidProtect の **Automod** は、望ましくないコンテンツが投稿された時点で自動的に削除するフィルターをまとめたものです。各フィルターには、メッセージの投稿者に対する独自の処罰があります。

開くには：

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**保護**」タブを開きます。
3. 「**Automod**」の横にある「**設定**」をクリックします。

<Settings start="automod" />

## 🖼️ 詐欺画像 {#images}

「**画像**」フィルターは、既知の詐欺画像（仮想通貨詐欺、偽のプレゼント企画、偽のカジノ宣伝）を削除し、投稿者を処罰します。**既定で有効**で、設定は不要です。

詳細、処罰、画像カタログについては、[詐欺画像](./scam-images.md)のページをご覧ください。

## 🔗 他のサーバー {#servers}

「**他のサーバー**」フィルターは、他の Discord サーバーへの誘導を管理します。**招待**、**転送されたメッセージ**、**チャンネルリンク**、**イベントリンク**、そしてメンバーが表示している**サーバータグ**が対象です。無差別な宣伝や、競合サーバー・悪質なサーバーをブロックしつつ、パートナーには影響しません。

### 仕組み {#servers-working}

3 つの動作を個別に設定でき、それぞれ次のいずれかのモードを選びます。

- 「**無効**」：何もフィルターしません。
- 「**ブラックリスト**」：リストのサーバーは拒否され、それ以外は通過します。
- 「**ホワイトリスト**」：リストのサーバーだけが通過し、それ以外はすべて拒否されます。

| 動作 | 拒否された場合に起きること |
|---|---|
| **招待** | 招待を含むメッセージが削除されます。`ptb.` と `canary.` のリンクも対象で、埋め込み、コンポーネント、転送メッセージに隠れた招待や、あとから編集されたメッセージも読み取ります。 |
| **転送メッセージまたはチャンネルリンク** | そのサーバーから転送されたメッセージ、またはそのサーバーのチャンネルやイベントへのリンクを含むメッセージが削除されます。 |
| **表示中のサーバータグ** | メンバーは [Jail ロール](./sanctions.mdx#jail)で**隔離**されます。タグを外すとすぐに解除されます。 |

ご自身のサーバーは、どの招待でも常に通過し、運営チーム（**サーバー管理**または**メッセージの管理**の権限を持つ人）は対象になりません。

### 設定 {#servers-config}

1. Automod で、「**他のサーバー**」の横にある「**設定**」をクリックします。
2. 右上のスイッチでフィルターを有効にし、動作ごとにモードを選びます。

<Settings start="serverRefs" />

#### フレンド・グループの招待 <span className="badge-premium">Premium</span> {#servers-private}

フレンドやプライベートグループの招待は、どのサーバーにもつながっていません。「**招待**」のモード（「**無効**」以外）では、「**フレンド・グループ招待**」セレクターで、その扱いを個別に設定できます。

- 「**リストに従う**」（既定）：ブラックリストでは許可され、ホワイトリストでは削除されます。
- 「**常に許可**」：リストに関係なく許可されます。
- 「**常に削除**」：リストに関係なく削除されます。

Premium がない場合は、常にリストに従います。

:::tip
変更したフィルターを有効にしないまま画面を離れようとすると、RaidProtect が離れる前に有効にするよう提案します（「**無効のままにする**」が選択済みです）。
:::

### 処罰 {#servers-sanction}

拒否されたメッセージはすべて削除されます。「**削除したメッセージへの処罰**」で、投稿者への処罰を追加で選ぶか、「**メッセージの削除のみ**」を選びます。タイムアウト、ミュート、Jail、BAN の場合は、期間も選びます。

処罰は、メンバーごとに 1 分間に最大 1 回適用されます。招待を立て続けに貼ったメンバーが処罰されるのは 1 回だけです。

### サーバーのリスト {#servers-lists}

1. 「**サーバーを追加**」をクリックします。
2. まだ有効なサーバーの招待（例：`discord.gg/example`）を貼り付けます。名前と ID が読み取られます。ID だけでは受け付けられなくなりました。
3. リストを選びます（ブラックリストまたはホワイトリスト）。

すでに登録されているサーバーは、リストが変わるだけです。「**削除**」で、リストから 1 つまたは複数のサーバーを外せます。

**上限：** 2 つのリストを合わせて 25 サーバーまで。

:::tip
パートナーの招待だけを許可するには、「**招待**」を「**ホワイトリスト**」に設定し、パートナーをホワイトリストに追加します。ホワイトリストが空の場合、他のサーバーへの招待はすべて拒否されます。
:::

### ログ {#servers-logs}

処罰と隔離はすべて、対象のサーバーとチャンネルとともに[モデレーションログ](./moderation.mdx#logs)に記録されます。処罰なしで削除されたメッセージ（「**メッセージの削除のみ**」）も記録されます。処罰は[処罰の履歴](./sanctions.mdx)に表示され、理由は「拒否されたサーバーへの招待」「拒否されたフレンド・グループ招待」（Premium）「拒否されたサーバーの転送メッセージまたはチャンネルリンク」「拒否されたサーバーのタグ」となります。

## 📎 ファイルの拡張子 {#files}

「**ファイルの拡張子**」フィルターは、拒否された拡張子のファイルを削除します。特定の拡張子をブロックする（ブラックリスト）か、特定の拡張子だけを許可する（ホワイトリスト）かを、サーバー全体またはチャンネルごとに設定できます。運営チーム（**サーバー管理**または**メッセージの管理**の権限を持つ人）は対象になりません。

転送メッセージのファイルも対象で、スレッドは親チャンネルのルールに従います。

### 設定 {#files-config}

1. Automod で、「**ファイルの拡張子**」の横にある「**設定**」をクリックします。
2. 右上のスイッチでフィルターを有効にします。
3. 「**サーバー全体**」で、「**無効**」「**ブラックリスト**」「**ホワイトリスト**」からモードを選びます。
4. **グループ**（実行ファイル、画像、動画、音声、アーカイブ、ドキュメント）にチェックを入れる、または他の拡張子をカンマ区切りで入力します（例：`exe, msi`）。ドットは省略できます。1 つのルールには、グループに加えて最大 50 個の拡張子を入力できます。

<Settings start="files" />

:::warning
拡張子のないホワイトリストは、どのファイルも受け付けません。送信されたファイルはすべて削除されます。
:::

### チャンネルとカテゴリーごとのルール {#files-channels}

「**チャンネルを追加**」をクリックすると、チャンネル、スレッド、カテゴリーにルールを設定できます。カテゴリーのルールは、そのすべてのチャンネルに適用されます。

ルールは足し合わされますが、複数のルールで指定された拡張子については、**最も細かい**ルールが優先されます（チャンネル、カテゴリー、サーバーの順）。たとえば、あるチャンネルで許可された `.exe` は、サーバーのブラックリストにかかわらず通過します。どのルールにも指定されていない拡張子は、すべてのルールを通過します。

| | 無料 | <span className="badge-premium">Premium</span> |
|---|---|---|
| **チャンネルごとのルール** | 1（最初に設定したチャンネル） | 20 のチャンネルまたはカテゴリー |
| **カテゴリーのルール** | なし | あり |

Premium がない場合、上限を超えたルールは保持されますが、無効になります。

### 破損したファイル {#files-disguised}

画像や動画に見せかけるために名前を変えたファイル（`.png` に名前を変えた `.exe` など）は検出されます。Discord が本物の画像として読み込めないためです。ホワイトリストでは常に拒否されます。「**破損したファイルを常に拒否**」オプションを使うと、ホワイトリストがなくても、すべてのチャンネルで削除されます。

### 処罰 {#files-sanction}

拒否されたファイルは、そのメッセージとともに削除されます。「**削除したメッセージへの処罰**」で、投稿者への処罰を追加で選ぶか、「**メッセージの削除のみ**」を選びます。処罰は、メンバーごとに 1 分間に最大 1 回適用されます。

削除されたメッセージはすべて、ファイル、チャンネル、該当する拡張子とともに[モデレーションログ](./moderation.mdx#logs)に記録されます。処罰は[処罰の履歴](./sanctions.mdx)に表示され、理由は「拒否された拡張子のファイル」となります。

## よくある質問 {#faq}

### パートナーは引き続き招待を共有できますか？

はい。「他のサーバー」フィルターのホワイトリストに追加するか、ブラックリストに入れないでください。

### メンバーが拒否されたタグを外すとどうなりますか？

隔離は自動で解除されます。

### モデレーターもフィルターされますか？

いいえ。サーバー管理またはメッセージの管理の権限を持つメンバーは、「他のサーバー」フィルターの対象になりません。
