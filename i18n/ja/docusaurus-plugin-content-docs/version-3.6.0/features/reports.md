RaidProtect の通報システムでは、コミュニティが不審なメッセージやメンバーを、右クリック、専用ボタン、`/report` コマンドから数クリックでモデレーターに報告できます。チームが通報を効率よく処理できるよう設定できます。

## ❓ 通報の仕組み {#working}
メンバーは、主に 4 つの方法でコンテンツを通報できます。

1. **メッセージを右クリック**
ルールに違反していると思うメッセージを右クリックし、**`アプリ`** を選んで、**`このメッセージを通報`** をクリックします。ウィンドウが開き、通報の理由を入力します。

2. **プロフィールを右クリック**
同様に、問題があると思うプロフィールを右クリックし、**`アプリ`** を選んで、**`ユーザーを通報`** をクリックします。ウィンドウが開き、何を通報するか（プロフィール画像、ユーザー名、自己紹介、ボイスでの活動、DM での活動）と理由を指定します。

3. **情報パネルのボタン**
[情報パネル（`/display public`）](./display.mdx)で「通報」機能が有効な場合、パネルのすぐ下に「**メンバーを通報**」ボタンが表示され、メンバーがすばやくユーザーを通報できます。

4. **スラッシュコマンド**
メンバーは、サーバー内のどのチャンネルでも **`/report`** コマンドでユーザーを通報できます。

次のコマンドを使用します：```/report (member)```

`(member)` を対象のユーザーに置き換えます。理由は、プロフィールの右クリックと同様に、ウィンドウで入力します。

:::info
通報を有効にすると、[メッセージのキャッシュ](./moderation.mdx#snipe)も有効になります。RaidProtect は 1 時間分のメッセージをメモリに保持し、通報されたコンテンツをアラートに添付します。
:::

## 🚩 通報の設定 {#config}

通報は**通報チャンネル**に届きます。選ばなかった場合は、全般のログチャンネルに送信されます。すべての設定は 1 つの画面にあります。

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**モデレーション**」タブを開きます。
3. 「**通報**」の横にある「**設定**」をクリックします。
4. 画面タイトル右の「**有効化**」をクリックして、通報システムをオンにします。

<Settings start="reports" />

### チャンネルを設定する {#config-channel}

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**モデレーション**」タブを開きます。
3. 「**通報**」の横にある「**設定**」をクリックします。
4. 「**通報の受信先**」の横にある「**編集**」をクリックします。
5. ウィンドウで希望のチャンネル（_例：#通報 や #reports_）を選ぶか、「**チャンネルを作成してもらう**」にチェックを入れて、RaidProtect に非公開の `通報` チャンネルを作成させます。

チャンネルを選ばなかった場合、またはログチャンネルを選んだ場合は、通報は全般のログチャンネルに送信されます。

<SettingsModal name="reportChannel" />

### 通知ロールを設定する {#config-role}

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**モデレーション**」タブを開きます。
3. 「**通報**」の横にある「**設定**」をクリックします。
4. 「**通知ロール**」の横にある「**編集**」をクリックします。
5. ウィンドウで希望のロール（_例：@モデレーター や @通報通知_）を選ぶか、「**その他のメンション**」として `@everyone`、`@here`、または「**ロールを作成してもらう**」（RaidProtect が `新しい通報` ロールを作成します）を選びます。

ロールを設定していない場合は、`@here` がメンションされます。

<SettingsModal name="reportRole" />

:::warning
通報を適切に管理できるよう、チャンネルはモデレーターと管理者専用にしてください。
:::

### 通報のまとめ表示 {#group}

「**まとめ表示**」の切り替えで、同じメンバーに対する複数の通報の表示方法を決めます。

- **有効**（既定）：同じメンバーに対する通報は、1 つのアラートにまとめられます。
- **無効**：通報ごとに個別のアラートが作成されます。

通報画面で、「**まとめ表示**」の横にある「**有効化**」または「**無効化**」をクリックします。

<a id="config-notify"></a>

### 通報者への通知 {#notify}

「**通報者への通知**」の横にある「**編集**」ボタンでウィンドウが開き、通報が処理されたあとに、通報したメンバーが DM で受け取る内容を選べます。

| レベル | 効果 |
|---|---|
| **無効** | 通報者には通知が届きません。 |
| **処理のみ**（既定） | 通報が処理されたことだけを通報者に伝えます。 |
| **結果も伝える** | 通報が受理されたか却下されたかを伝えます。 |
| **モデレーターも伝える** | どのモデレーターが処理したかも伝えます。 |

他の通報とまとめられた場合でも、通報者に届くメッセージは通報ごとに 1 通だけです。

### 信頼ロール <span className="badge-premium">Premium</span> {#trusted-role}

「**信頼ロール**」を使うと、最も信頼できるメンバーが緊急時に即座に動けます。このロールを持つメンバーが通報する際、「**予防的な措置**」オプションにチェックを入れると、モデレーターが通報を処理するまでの間、通報されたユーザーに**24 時間の予防的なタイムアウト**を適用できます。

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**モデレーション**」タブを開きます。
3. 「**通報**」の横にある「**設定**」をクリックします。
4. 「**信頼ロール**」の横にある「**編集**」をクリックします。
5. ウィンドウでロールを選ぶか、「**ロールを作成してもらう**」にチェックを入れます（RaidProtect が `信頼できる通報者` ロールを作成します）。信頼ロールを無効にするには、空欄のままにします。

予防的なタイムアウトの動作：

- 予防的なタイムアウトは**サイレント**です。モデレーターが処罰を確認するまで、通報されたユーザーに DM は届きません。
- 理由は「**予防的な処罰：**」に続けて通報の理由が表示されます。
- 通報がメッセージに関するものである場合、そのメッセージは削除されます。
- アラートは緊急としてマークされ、メンションの前に「**🛑 緊急の通報**」が付きます。
- 処罰は通報に紐づけられ、通報を処理するモデレーターが確認または取り消しできます。

:::info
この機能は [**Premium**](/ja/premium) サーバー専用です。
:::

### 通報者の信頼度 {#bad-reporters}

「**虚偽の通報者**」の横にある「**編集**」ボタンで「**通報者の信頼度**」ウィンドウが開き、通報が繰り返し却下されているメンバーに対処できます。

- **しきい値**：対処までに却下された通報の件数（3、5、6、10、15。既定は「**無効**」）。
- **集計期間**：集計する期間（7、14、30、60、90 日。既定は 30 日）。
- しきい値に達したときの**アクション**：
  - 「**モデレーターに通知**」（既定）：「**通報をブロック**」ボタンと処罰ボタン（例：「**通報者を警告する**」）付きのアラートが送信されます。
  - 「**自動でブロック**」：そのメンバーは通報を送信できなくなります。
  - 「**自動で処罰**」：設定した処罰が適用されます。
  - 「**ブロックして処罰**」：上の 2 つを組み合わせます。
- **処罰**：虚偽の通報者に適用する処罰（既定は警告。タイムアウト、ミュート、キック、BAN も選べます）。

<SettingsModal name="reportBad" />

:::info
[ミュートロール](./sanctions.mdx#mute)が未設定の場合、ミュートの処罰はタイムアウトになります。
:::

:::tip
[`/block` コマンド](./utilities.mdx#block)を使えば、いつでも手動でメンバーを通報からブロックできます。
:::

## 通報を管理する {#manage}

通報は、設定したチャンネルに、複数のアクションが付いたアラートとして届きます。

- **🙋 対応する：** 「**対応する**」をクリックすると、他のモデレーターにこの通報を担当していることが伝わります。ボタンは「**対応中**」に変わります。

- **✅ 解決済み：** 通報が正当でも処罰が不要な場合（別の方法で解決した、注意で済んだ、メッセージが投稿者自身によって削除された、など）は、「**解決済み**」をクリックします。通報は承認済みとなり、通報されたユーザーは処罰されません。処罰する場合は、代わりに下の「**このメンバーを処罰する…**」メニューを使ってください。

- **❌ 却下：** 通報が正当でない場合は、「**却下**」をクリックします。却下は[通報者の信頼度](#bad-reporters)に集計されます。

- **⚖️ 処罰：** 通報を引き受けると使える「**このメンバーを処罰する…**」メニューで、通報チャンネルを離れずに、通報されたユーザーへ直接処罰を適用できます。

[まとめ表示](#group)が有効な場合、同じメンバーに対する後続の通報は、新しいアラートを作る代わりに既存のアラートに追加されます（例：「**3 件のメッセージ & 1 件のプロフィール は 2 人のユーザーから通報されました**」）。

:::note
モデレーターがこの機能の使い方を十分に理解していることを確認し、アクティブなメンバーには責任を持って使うよう促してください。
:::

## よくある質問 {#faq}

### メンバーやメッセージを通報するには？

メッセージまたはプロフィールを右クリックし、「アプリ」から「このメッセージを通報」または「ユーザーを通報」を選びます。情報パネルのボタンや、どのチャンネルでも使える `/report (member)` コマンドからも通報できます。理由はウィンドウで入力します。

### 通報はどこに届きますか？

設定した通報チャンネルに届きます。未設定の場合は、全般のログチャンネルに届きます。通報を適切に処理するため、このチャンネルはモデレーターと管理者専用にしてください。

### 通報のたびに、どのロールがメンションされますか？

設定した通知ロール、または `@everyone` です。設定がない場合、RaidProtect は `@here` をメンションします。

### 虚偽の通報を抑えるには？

「虚偽の通報者」の設定は、通報が繰り返し却下されているメンバーに働きます。しきい値と集計期間を決め、アクション（モデレーターへの通知、通報のブロック、処罰、またはその両方）を選びます。[`/block` コマンド](./utilities.mdx#block)で手動でブロックすることもできます。
