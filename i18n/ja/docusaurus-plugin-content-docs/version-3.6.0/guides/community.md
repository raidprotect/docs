---
title: コミュニティを有効にする
description: "サーバーの Discord コミュニティを有効にして、RaidProtect に必要なセキュリティ設定（DM の遮断、レイドモードなど）を使えるようにします。"
---

コミュニティを有効にすると、Discord の高度なセキュリティ設定がいくつか使えるようになります。RaidProtect の一部の機能にはこれらが必要です。
- [DM の遮断](../features/dm-lock.mdx)（**DM Lock**）
- [レイドモード](../features/raid-mode.md)と[参加ロック](../features/join-lock.mdx)：レイド中の対応が「**招待をブロック**」（既定の設定）の場合に**限ります**。

[キャプチャ](../features/captcha.md)と、レイドモードのその他の対応（「**参加者をキック**」「**キャプチャに送る**」「**レイド中はキャプチャを凍結**」）は、コミュニティなしでも動作します。

## 🚦 前提条件 {#requirement}

- Discord サーバーの管理者であること。

## 🚩 コミュニティ機能を有効にする {#steps}

1. **サーバー設定を開く**
   - 左上のサーバー名をクリックし、「サーバー設定」を選びます。

2. **「コミュニティ」セクションを開く**
   - サイドバーの**コミュニティを有効にする**タブを開き、**始める**をクリックします。

:::note
サーバーですでにコミュニティが有効な場合、このセクションの名前は**コミュニティの概要**になります。
:::

3. **有効化ウィザードに従う**
   - すべてのメンバーに対してメール認証を有効にします。
   - 不適切なコンテンツのフィルターを有効にします。
   - ルールチャンネルとお知らせチャンネルを設定します。
   - コミュニティサーバーのガイドラインに同意します。

4. **設定を完了する**
   - 「設定を完了」をクリックします。有効化が完了すると、サーバーに「コミュニティ」バッジが表示されます。

![Discord コミュニティを有効にするスクリーンショット](../../../../en/docusaurus-plugin-content-docs/current/assets/rp-enable-community.webp)

## 💡 有効化後に DM Lock とレイドモードを使う {#use}

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. [DM の遮断](../features/dm-lock.mdx)を使うには、「**保護**」タブを開き、「**DM の遮断**」の横にある「**編集**」をクリックします。
3. [レイドモード](../features/raid-mode.md#config)を使うには、「**参加**」タブを開き、「**オート RaidMode**」の横にある「**設定**」をクリックします。

コミュニティの有効化を求める案内が表示されていた場合は、「**再読み込み**」をクリックしてください。コミュニティが有効になると表示は消えます。
