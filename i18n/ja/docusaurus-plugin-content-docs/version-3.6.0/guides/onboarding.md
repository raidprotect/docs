`#認証` チャンネルが新規メンバーに既定で表示されていないと、メンバーは[キャプチャ](../features/captcha.md)を通過できず、足止めされたままになります。このガイドは、**Discord のオンボーディング**（サーバー設定 > オンボーディング）に関するものです。RaidProtect のようこそメッセージや自動ロールについては、[参加とウェルカム](../features/onboarding.md)のページをご覧ください。

ほとんどの場合、RaidProtect が問題を自動で修正します。まずは手順 1 から始めてください。

## 1️⃣ RaidProtect に修正を任せる {#auto-fix}

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**参加**」タブを開きます。
3. 「**キャプチャ**」の横にある「**設定**」をクリックします。
4. 認証チャンネルが**既定で表示されていない**という警告が出ている場合は、次のいずれかをクリックします。
   - 「_カテゴリー_ **に移動**」：新規メンバーにすでに表示されているカテゴリーにチャンネルを移動します。
   - 「**新しいカテゴリーを作成**」：「ようこそ」カテゴリーを作成し、既定のチャンネルに追加します。

移動してもチャンネルの権限は維持されます。

<Settings start="captcha" />

:::tip
同じ画面では、`@未認証` ロールの**漏れ**も通知されます。Discord のオンボーディングが付与して認証を回避してしまうロールや、認証中のメンバーにまだ表示されているチャンネルなどです。「**修正する**」ボタンで、該当するチャンネルを非表示にします。[キャプチャ画面のアラート](../features/captcha.md#alerts)もご覧ください。
:::

## 2️⃣ チャンネルの権限を確認する {#permissions}

RaidProtect は、`#認証` チャンネルと `@未認証` ロールの権限を自動で設定します。変更した場合は、次の点を確認してください。

1. `#認証` チャンネルの設定を開きます（右クリック > **チャンネルを編集**）。
2. **権限**タブで次を確認します。
   - `@everyone` に、チャンネルを見る権限が**ないこと**。
   - `@未認証` ロールに、**チャンネルを見る**権限と**メッセージ履歴を読む**権限が**あること**。
   - 既定のモードである**パネル（インタラクティブ）**では、`@未認証` はメッセージを送信**できてはいけません**。コードはウィンドウ内で入力します。**チャレンジ（クラシック）**モードでは、コードを入力するために**メッセージを送信**できる必要があります。

{/* ![チャンネル権限の確認のスクリーンショット](../assets/rp-verification-channel-permissions.webp) : 「メッセージを送信」が許可された状態を示す。チャレンジモードでのみ正しい */}

## 3️⃣ ウェルカム用カテゴリーを確認する {#default-category}

手動で修正したい場合は、次の手順で行います。

1. **サーバー設定** > **オンボーディング**に移動します。
2. **デフォルトチャンネル**セクションで、`#認証` を含むカテゴリーが、新規メンバーに表示されるようにチェックされていることを確認します。
3. 必要に応じて、`#認証` をチェック済みのカテゴリーに移動します。
4. 変更を保存します。

![オンボーディングのカテゴリー確認のスクリーンショット](../../../../en/docusaurus-plugin-content-docs/current/assets/rp-welcome-category.webp)

## 4️⃣ RaidProtect で設定を更新する {#refresh-config}

1. [`/settings` コマンド](../setup.md#settings)を実行します。
2. 「**参加**」タブを開きます。
3. 「**キャプチャ**」の横にある「**設定**」をクリックします。
4. 警告がまだ表示されている場合は、「**再読み込み**」をクリックして確認をやり直します。警告が消えれば、キャプチャは正しく動作しています。

## 5️⃣ テストアカウントで試す {#test-account}

すべてが正しく設定されていることを確認するには、次の手順を行います。

1. 別の Discord アカウントでサーバーに参加します。
2. 参加時に `#認証` チャンネルが表示されていることを確認します。
3. 「**認証する**」をクリックしてコードを入力します（パネルモード）。またはチャンネルにコードを入力します（チャレンジモード）。
4. 認証が済めば、そのアカウントは他のチャンネルにアクセスできるはずです。

## 🛠️ よくある問題と解決策 {#common-issues}

| 問題 | 解決策 |
|---------|----------|
| 🔴 `#認証` チャンネルが見えないまま | キャプチャ画面で「_カテゴリー_ **に移動**」をクリックするか、チャンネルを Discord のオンボーディングで**チェック済みのカテゴリー**に入れてください。 |
| 🚫 `@未認証` ロールが書き込めない | パネルモードでは正常です。メンバーは「**認証する**」をクリックします。チャレンジモードでは、`#認証` で**メッセージを送信する権限**を付与してください。 |
| 🔓 未認証のメンバーに他のチャンネルが見える | キャプチャ画面の漏れの警告で「**修正する**」をクリックし、Discord のオンボーディングが参加時に付与しているロールを外してください。 |
| ❌ 変更後にキャプチャが動作しない | キャプチャ画面（`/settings` の「**参加**」タブ）で「**再読み込み**」をクリックしてください。 |

---

✅ これらの手順に従えば、認証システムが完全に機能し、メンバーを安全に迎え入れながら、ボットやレイドを効果的にブロックできます。
