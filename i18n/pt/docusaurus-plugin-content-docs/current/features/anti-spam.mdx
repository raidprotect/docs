O Anti-spam do RaidProtect é uma ferramenta poderosa para impedir o spam no seu servidor Discord. Graças ao seu sistema de detecção automática, ele cuida dos problemas sozinho, sem que você precise intervir.

## ❓ Como funciona o anti-spam {#working}

O anti-spam do RaidProtect detecta e bloqueia automaticamente os comportamentos suspeitos. Ele diferencia dois tipos de spam.
- **Spam pesado:** Mensagens contendo links de convite, menções em massa ou imagens. Esse tipo de spam costuma ser usado durante raids.
- **Spam leve:** Mensagens enviadas com frequência, mas menos intrusivas.

O anti-spam do RaidProtect atua de duas maneiras.
- **Sanções:** Expulsão ou banimento automático dos spammers.
- **Notificações:** Envio de mensagens para o canal de logs para sinalizar os spams bloqueados, com uma prévia das ações detectadas.

## 🛡️ Configuração do anti-spam {#config}

O RaidProtect oferece três níveis de segurança para atender às necessidades do seu servidor.
- 🔴 **Alto:** Sanciona todos os spams e até o spam pesado nos canais ignorados.
- 🟠 **Médio:** Sanciona todos os spams, mas respeita os canais ignorados.
- 🟢 **Baixo:** Sanciona apenas o spam pesado.

### Alterar o nível de segurança {#level}

1. Execute o [comando `/settings`](../setup.md#settings).
2. Clique no botão "**Anti-spam**".
3. Selecione o nível de anti-spam desejado no primeiro seletor.

### Gerenciar cargos, usuários e canais ignorados {#ignore}

Você pode excluir certos canais, cargos ou até usuários da vigilância do anti-spam para ter mais flexibilidade. 😉
1. Execute o [comando `/settings`](../setup.md#settings).
2. Clique no botão "**Anti-spam**".
3. Selecione as diferentes opções a ignorar nos diversos seletores:
- Canal(is) a ignorar
- Cargo(s) a ignorar
- Membro(s) a ignorar

:::info
Os canais que contêm "**spam**" no nome são ignorados automaticamente. As pessoas com a permissão de administrador são totalmente ignoradas.
:::

### Configurar as sanções por gatilho {#triggers}

Você pode personalizar as sanções aplicadas conforme o tipo de spam detectado. Isso permite uma resposta adaptada à gravidade da infração.

1. Execute o [comando `/settings`](../setup.md#settings).
2. Clique no botão "**Anti-spam**".
3. Vá até a aba "**Sanções**".
4. Para cada gatilho, selecione uma sanção específica. Você pode modificar esses valores por meio dos menus suspensos:
- **Selecionar um gatilho**: escolha o tipo de spam a configurar.
- **Selecionar uma sanção**: escolha a sanção correspondente.

#### Tipos de sanções e gatilhos {#sanctions}

Estas são as diferentes **sanções disponíveis**:

- **Aviso**: Envia um aviso ao membro.
- **Timeout**: Silencia o membro durante um período definido.
- **Mute**: Atribui o [cargo Mute](./sanctions.mdx#mute) configurado no seu servidor.
- **Jail**: Atribui o [cargo Jail](./sanctions.mdx#jail) configurado no seu servidor.
- **Kick**: Expulsa o membro do servidor.
- **Softban**: Bane e desbane imediatamente o membro, excluindo assim suas mensagens.
- **Ban**: Bane definitivamente o membro.
- **Desativar**: Desliga completamente o gatilho, nenhuma sanção será aplicada.

:::note
Para os gatilhos "Spam de duplicatas ou spam importante" e "Spam multicanal", a sanção mais branda que pode ser selecionada é o **Timeout** (não há Aviso): trata-se de spam sério, que justifica uma resposta firme.
:::

E os **gatilhos** que o RaidProtect pode detectar, com a sanção aplicada por padrão:

| Gatilho                                | Descrição                                                | Sanção padrão       |
|----------------------------------------|----------------------------------------------------------|---------------------|
| Spam                                   | Envio repetido de mensagens                              | Aviso               |
| Spam com selfbot                       | Uso de selfbots para dar spam                            | Softban             |
| Spam de menções                        | Menções em massa repetidas                               | Softban             |
| Spam de links                          | Envio massivo de links                                   | Ban                 |
| Spam de comandos externos              | Uso de comandos externos para dar spam                   | Ban                 |
| Spam de anexos                         | Envio massivo de arquivos ou imagens                     | Desativado          |
| Spam de duplicatas ou spam importante  | Mensagens copiadas e coladas ou spam excessivo           | Softban             |
| Imagens de fraude (Crypto Scam)        | Imagens de fraude detectadas pelo [ScamLens](/blog/threat-weather-june-2026) | Timeout             |
| Spam multicanal                        | Spam distribuído por vários canais                       | Jail                |

:::info
O gatilho **Spam multicanal** é especial: a sua sanção substitui a do gatilho de origem quando o spam atinge vários canais, mas apenas se for mais severa.
:::

#### Duração das sanções {#duration}

Quando as sanções aplicadas pelo anti-spam suportam uma duração (mute, timeout, jail), você pode definir uma **duração única** aplicada a todas essas sanções (1 hora por padrão).

1. Execute o [comando `/settings`](../setup.md#settings).
2. Clique no botão "**Anti-spam**".
3. Vá até a aba "**Sanções**".
4. Selecione uma duração predefinida no seletor "**Duração das sanções**", ou clique em "**Duração personalizada**" para digitar o valor que preferir (por ex. `30m`, `2h`, `7d`).

:::info
A duração é ignorada para as sanções que não a suportam (kick, softban, ban, aviso).
:::
