O histórico de sanções do RaidProtect permite que você acompanhe e gerencie todas as sanções aplicadas no seu servidor. Este sistema centraliza todas as ações de moderação em um banco de dados pesquisável e editável, facilitando assim o trabalho da sua equipe de moderação.

## ❓ Como funciona o histórico {#working}

O histórico de sanções registra automaticamente todas as ações de moderação realizadas no seu servidor:

- **Sanções manuais**: Todos os comandos de moderação (`/ban`, `/tempban`, `/kick`, `/timeout`, `/warn`) são registrados automaticamente no histórico.
- **Sanções automáticas**: As sanções aplicadas pelo anti-spam também são adicionadas ao histórico de sanções.
- **Banimentos, expulsões e timeouts**: As sanções aplicadas sem utilizar o RaidProtect são adicionadas ao histórico.
- **Automod do Discord**: As sanções aplicadas pelo automod do Discord também são adicionadas.
- **Notificações de sanção**: Os membros sancionados recebem uma mensagem privada informando-os sobre a sanção e o seu motivo. O bot também envia um aviso de recebimento detalhado confirmando o status do envio: **recebida**, **DM fechadas**, **expirada** ou **silenciosa** (quando a opção `[silent]` é utilizada). Para expulsões, softbans e bans temporários, esta mensagem também contém um **botão com um convite para o servidor** para que o membro possa voltar quando a sanção terminar.

:::info
Todas as sanções registradas contêm: o usuário sancionado, o moderador responsável, o motivo (até 512 caracteres), a data e a hora, bem como o tipo de sanção e se o usuário foi notificado.
:::

## 🔍 Pesquisar sanções {#search}

O comando `/sanctions search` permite que você pesquise sanções no histórico segundo diferentes critérios.

Utilize o comando: ```/sanctions search [user] [moderator] [type] [date] [status] [moderator_type]```

- `[user]`: Pesquisar todas as sanções de um usuário específico.
- `[moderator]`: Pesquisar todas as sanções aplicadas por um moderador específico.
- `[type]`: Filtrar por tipo de sanção (Ban, Softban, Unban, Kick, Timeout, Untimeout, Warn, Jail, Unjail, Mute, Unmute).
- `[date]`: Filtrar por data da sanção.
- `[status]`: Filtrar por status da sanção (Ativa, Expirada, Cancelada, Falhada).
- `[moderator_type]`: Filtrar por tipo de moderador (Ações humanas, Ações automatizadas, RaidProtect, Discord, Antispam, etc.).

![Captura de tela da pesquisa de sanções](../../../../en/docusaurus-plugin-content-docs/current/assets/rp-sanctions-search.webp)

:::tip
Você pode combinar vários critérios para refinar a sua pesquisa. Por exemplo, pesquisar todos os banimentos realizados por um moderador específico.
:::

## ℹ️ Ver uma sanção {#info}

O comando `/sanctions info` permite que você obtenha informações detalhadas sobre uma sanção específica.

Utilize o comando: ```/sanctions info (id)```

Substitua `(id)` pelo identificador da sanção que você deseja visualizar.

![Captura de tela das informações de uma sanção](../../../../en/docusaurus-plugin-content-docs/current/assets/rp-sanctions-info.webp)

## ✏️ Editar uma sanção {#edit}

O comando `/sanctions edit` permite que você modifique o motivo de uma sanção existente, útil para corrigir um erro ou adicionar detalhes.

Utilize o comando: ```/sanctions edit (id) (new_reason)```

Substitua `(id)` pelo identificador da sanção a modificar e `(new_reason)` pelo novo motivo (máximo 512 caracteres).

![Captura de tela da edição de uma sanção](../../../../en/docusaurus-plugin-content-docs/current/assets/rp-sanctions-edit.webp)

:::warning
Editar uma sanção atualiza o registro no histórico, mas não altera a sanção aplicada no Discord (por exemplo, um usuário banido continuará banido).
:::

## 🗑️ Excluir uma sanção {#delete}

O comando `/sanctions delete` permite que você exclua uma sanção do histórico. Esta ação é irreversível.

Utilize o comando: ```/sanctions delete (id) [reason]```

Substitua `(id)` pelo identificador da sanção a excluir. O parâmetro `[reason]` permite **justificar a exclusão**, que será registrada nos logs.

![Captura de tela da exclusão de uma sanção](../../../../en/docusaurus-plugin-content-docs/current/assets/rp-sanctions-delete.webp)

### Gerenciamento de duplicatas {#duplicates}

Quando uma sanção ativa e anterior é encontrada, você pode:

- **Mesclar** as duas sanções: as durações serão somadas, se possível, e os motivos serão concatenados.
- **Cancelar** a sanção ativa e criar uma nova sanção.
- **Sobrescrever** a sanção ativa com as informações da sanção digitada.

## ⚙️ Configuração das sanções {#config}

### Desativar as sanções {#disable}

Você pode **desativar completamente o sistema de sanções** no seu servidor. Quando as sanções estão desativadas, o RaidProtect deixa de registrar qualquer sanção no histórico e os comandos relacionados ficam indisponíveis.

1. Use o [comando `/settings`](../setup.md#settings).
2. Clique no botão "**Sanções**".
3. Clique em "**Sistema de sanções**" para ativar ou desativar todo o módulo.

### Prisão {#jail}

Configure a **Prisão** para ativar uma sanção de moderação baseada em cargo, mais restritiva que um mute comum. Uma vez configurado, esse cargo permite isolar um membro com permissões severamente limitadas e desbloqueia o uso dos comandos [`/jail`](./moderation.mdx#jail) e [`/tempjail`](./moderation.mdx#tempjail).

1. Use o [comando `/settings`](../setup.md#settings).
2. Clique no botão "**Sanções**".
3. Selecione "**Prisão**".
4. Escolha um cargo existente através do seletor ou clique em "**Criar um para mim**".

Ao criar o cargo, você também pode configurar o **canal de informações da Prisão**:

- **Selecionar um canal existente** para exibir as informações destinadas aos membros presos.
- **Criar um novo canal** informando um nome (padrão `acesso-restrito`).

Esse canal corresponde ao espaço reservado nos [painéis de informação](./display.mdx), gerenciado automaticamente pela configuração da Prisão.

:::info
Se um cargo de Prisão já estiver configurado, você pode modificar o canal de informações através do botão dedicado no submenu da Prisão.
:::

#### Cargos durante a prisão {#jail-roles}

No submenu da Prisão, o botão **Cargos durante a prisão** controla o que o RaidProtect faz com os cargos do membro quando ele é preso. Dois modos:

- **Adicionar o cargo de jail** *(padrão)*: o cargo de jail é simplesmente adicionado aos cargos existentes do membro.
- **Substituir todos os cargos**: o RaidProtect **remove todos os cargos do membro** durante o tempo de prisão e os restaura quando ele é solto. Mais rigoroso, isso evita que um cargo com permissões explícitas contorne as restrições do cargo de jail.

Clique no botão para alternar entre os dois modos.

### Cargo de Mute {#mute}

Configure o **Cargo de Mute** para usar uma sanção baseada em cargo em vez do timeout do Discord para durações prolongadas. Quando a duração do mute excede o limite definido, o bot atribuirá automaticamente o Cargo de Mute ao membro em vez de aplicar um timeout do Discord.

1. Use o [comando `/settings`](../setup.md#settings).
2. Clique no botão "**Sanções**".
3. Selecione "**Cargo de Mute**".
4. Escolha um cargo existente através do seletor ou clique em "**Criar um para mim**".

#### Limite de Mute {#mute-threshold}

Configure o **limite do Cargo de Mute** para definir a partir de qual duração o bot usará um mute baseado em cargo em vez do timeout do Discord. Quando a duração de um mute excede esse limite, o Cargo de Mute é aplicado automaticamente. Um valor de 0 desativa completamente o uso do timeout.

1. Use o [comando `/settings`](../setup.md#settings).
2. Clique no botão "**Sanções**".
3. Selecione "**Limite de Mute**".
4. Escolha um valor no seletor ou insira um valor personalizado.

:::info
O limite de 28 dias para o timeout é imposto pelo Discord. Além dessa duração, o Cargo de Mute será sempre utilizado, se estiver configurado.
:::
:::info
Os **timeouts aplicados pelo AutoMod do Discord** são automaticamente convertidos em mute por cargo se a sua duração ultrapassar o limite configurado, para garantir a coerência com as suas sanções manuais. A duração permanece limitada a 28 dias (limite do Discord).

Esse recurso está atualmente em **beta pública para servidores [Premium](/pt/premium)**.
:::

### Privacidade das Sanções {#sanctions-privacy}

Configure o nível de privacidade das sanções para controlar quais informações os membros podem acessar sobre as **suas próprias sanções**, através do comando [`/minhas-sancoes`](./utilities.mdx#my-sanctions) ou do botão **Minhas Sanções**.

1. Use o [comando `/settings`](../setup.md#settings).
2. Clique no botão "**Sanções**".
3. Selecione "**Privacidade das Sanções**".
4. Escolha o nível de acesso desejado:

| **Nível**                            | **Descrição**                                                                                       |
| ------------------------------------ | --------------------------------------------------------------------------------------------------- |
| Desativado                           | Os membros não podem consultar as suas sanções pessoais.                                            |
| Apenas sanções                       | Os membros podem consultar apenas as suas sanções e o tempo restante, se aplicável.                 |
| Com motivos                          | Os membros podem consultar as suas sanções juntamente com os motivos, sem a identidade do moderador. |
| Com motivos e moderadores            | Os membros podem consultar todas as informações: sanções, motivos e moderadores.                    |

:::note
Independentemente do nível selecionado, **os moderadores mantêm acesso total** ao histórico de sanções através das ferramentas de moderação.
:::

### Mostrar mídias {#show-medias}

Configure a exibição de mídias nos motivos das sanções. Quando esta opção está desativada, os links que contêm as seguintes extensões são automaticamente removidos dos motivos das sanções ao serem exibidos aos membros (via [`/minhas-sancoes`](./utilities.mdx#my-sanctions) ou notificações de sanção):

`png`, `jpg`, `jpeg`, `gif`, `webp`, `webm`, `mp4`

1. Use o [comando `/settings`](../setup.md#settings).
2. Clique no botão "**Sanções**".
3. Clique no botão "**Mostrar mídias**" para ativar ou desativar a opção.

## ✨ Nomes das sanções (Premium) {#custom-names}

Com a versão premium, você pode personalizar o nome de cada tipo de sanção para adaptá-lo ao vocabulário do seu servidor. Para cada tipo, você pode configurar:

- **Nome**: Substitua o nome padrão por um de sua escolha, até 32 caracteres (ex.: "Warn" → "Cartão Amarelo").
- **Verbo**: Defina o verbo utilizado nas mensagens, até 32 caracteres (ex.: "advertido"). Se deixado vazio, o nome é utilizado.
- **Modo DM**: Escolha a formulação da mensagem privada enviada ao membro sancionado:
  - "Você foi [verbo]" (padrão)
  - "Você recebeu um [nome]"

Os tipos de sanções personalizáveis são: Ban, Unban, Kick, Jail, Unjail, Timeout, Untimeout, Mute, Unmute e Warn.

1. Use o [comando `/settings`](../setup.md#settings).
2. Clique no botão "**Sanções**".
3. Selecione "**Nomes das sanções**".
4. Escolha o tipo de sanção a personalizar e informe o nome, o verbo e o modo DM desejados.

:::tip
Deixe os campos vazios para redefinir um tipo de sanção ao seu nome padrão. Você também pode usar o botão "Redefinir tudo" para redefinir todos os nomes.
:::

## 📦 Importar / Exportar sanções {#import-export}

O RaidProtect permite que você importe ou exporte o histórico de sanções do seu servidor. Para isso, acesse o nosso [servidor de suporte](https://raidprotect.bot/discord) e envie uma mensagem privada ao bot de suporte (no topo da lista de membros), que o acompanhará no processo.
