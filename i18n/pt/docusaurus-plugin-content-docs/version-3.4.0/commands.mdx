Todos os comandos do RaidProtect, agrupados por categoria. Clique no nome de um comando para acessar sua documentação detalhada.

## Legenda dos protótipos {#legend}

- `(arg)`: argumento **obrigatório**.
- `[arg]`: argumento **opcional**.
- `[--flag]`: flag booleana opcional (slash: `flag: true`, mensagem: `--flag`).
- `[--flag=valor]`: flag opcional com valor.
- `(@membro)` / `(#canal)` / `(@&cargo)`: prefixo que indica o tipo esperado.

## ⚙️ Duas formas de utilizar um comando {#usage}

Os dois formatos oferecem **exatamente as mesmas possibilidades**: tudo o que é possível em slash é possível por mensagem, e vice-versa. A diferença está apenas na forma de digitar o comando.

### Slash commands: o mais simples {#slash}

Digite `/` em um canal, escolha o comando, e **o Discord apresenta cada parâmetro em uma interface dedicada** (seletor de usuário, seletor de canal, autocomplete nas durações, etc.). É a forma recomendada por padrão: você não precisa memorizar nada.

```
/ban @membro motivo: spam de scam
```

### Message commands: o mais complexo {#prefix}

Uma vez [ativado o prefixo em `/settings`](./guides/prefix.md), você também pode escrever os comandos como mensagem clássica (`?ban …`, `?kick …`, etc.). Sem interface gráfica: é preciso **conhecer a sintaxe** (argumentos posicionais, flags nomeadas, argumento livre no fim da linha). Em contrapartida, é mais rápido no teclado para os moderadores que dominam os comandos.

#### Argumentos posicionais

Fornecidos na ordem do protótipo, sem nome. São os argumentos principais do comando.

```
?ban 123456789012345678
?slowmode 10s
```

#### Flags nomeadas (`--nome=valor`)

Para as opções secundárias. As flags podem ser colocadas em **qualquer lugar** do comando, em qualquer ordem.

- `--silent` (booleana): apenas ativa a opção.
- `--delete-messages=7d`: passa um valor à opção.

```
?ban @membro --delete-messages=7d --silent motivo do ban
?tempban @membro 1d --silent ele voltou a fazer
```

#### Argumento «rest» (texto livre)

O último argumento de alguns comandos (tipicamente `[motivo]`) captura **tudo o que você escrever depois**, incluindo espaços, sem precisar colocar aspas.

```
?warn @membro você infringiu novamente a regra 3 do servidor
```
