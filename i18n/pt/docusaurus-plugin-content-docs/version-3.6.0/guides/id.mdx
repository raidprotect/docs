Os identificadores do Discord são números únicos que permitem identificar com precisão cada usuário, canal, servidor ou mensagem no Discord. Eles são uma forma confiável e permanente de identificar elementos na plataforma.

:::note Utilidade para a moderação
O uso de identificadores do Discord é particularmente útil para ações de moderação, pois permite:
- **Sancionar um usuário ausente**: Banir alguém que saiu do servidor
- **Evitar erros**: Identificar com precisão a pessoa certa mesmo com nomes de usuário semelhantes
- **Manter um registro**: Os identificadores nunca mudam, ao contrário dos nomes de usuário
- **Resolver conflitos**: Identificação clara em caso de caracteres especiais
:::

## Ativar o modo desenvolvedor

Você precisa ativar o modo desenvolvedor para usar os identificadores do Discord.

<SeparatedBox>
<Tabs>
  <TabItem value="desktop" label="No Discord Desktop/Web" default>

    1. **Abra as configurações do usuário**
    - Clique no ícone de engrenagem no canto inferior esquerdo da interface

    2. **Acesse as configurações avançadas**
    - Na barra lateral, vá até a aba **Avançado**

    3. **Ative o modo desenvolvedor**
    - Ative a opção “**Modo desenvolvedor**” clicando no interruptor
    - O botão deve ficar azul após a ativação

  </TabItem>
  <TabItem value="mobile" label="No Discord Mobile">

    1. **Abra as configurações do usuário**
    - Toque no seu avatar no canto inferior direito
    - Toque no ícone de engrenagem no canto superior direito da interface

    2. **Acesse as configurações avançadas**
    - Deslize para baixo e toque em “**Avançado**”

    3. **Ative o modo desenvolvedor**
    - Ative a opção “**Modo desenvolvedor**”

  </TabItem>
</Tabs>
</SeparatedBox>

## Copiar um identificador

Assim que o modo desenvolvedor estiver ativado, você pode copiar o identificador de qualquer elemento:

<SeparatedBox>
<Tabs>
  <TabItem value="user" label="ID do usuário" default>

    - **Clique com o botão direito** no avatar ou nome de usuário
    - Selecione “**Copiar ID do usuário**”

  </TabItem>
  <TabItem value="channel" label="ID do canal">

    - **Clique com o botão direito** no nome do canal na lista de canais
    - Selecione “**Copiar ID do canal**”

  </TabItem>
  <TabItem value="server" label="ID do servidor">

    - **Clique com o botão direito** no nome do servidor no canto superior esquerdo
    - Selecione “**Copiar ID do servidor**”

  </TabItem>
  <TabItem value="message" label="ID da mensagem">

    - **Clique com o botão direito** em uma mensagem
    - Selecione “**Copiar ID da mensagem**”

  </TabItem>
</Tabs>
</SeparatedBox>

## Uso com o RaidProtect

Os identificadores podem ser usados nos comandos do RaidProtect em vez de menções:

- [`/ban user:123456789012345678 reason:Violation des règles du serveur`](../features/moderation#ban)
- [`/clear amount:100 user:123456789012345678`](../features/moderation#clear)
- [`/userinfo user:123456789012345678`](../features/utilities#userinfo)
- [`/bypass minage user:123456789012345678`](../features/onboarding#bypass-minage)

:::info
Você pode banir um usuário pelo identificador do Discord dele, mesmo que ele não esteja online ou presente no seu servidor.
:::
