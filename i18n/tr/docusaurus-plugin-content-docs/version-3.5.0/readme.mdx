Bu dokümantasyonun amacı, RaidProtect'in nasıl çalıştığını size açıklamaktır. Geri bildirimlerinizi bize iletmekten çekinmeyin; böylece dokümantasyonu iyileştirebiliriz.
Projedeki yeniliklerden haberdar olmak için [Discord sunucumuza katılmayı](https://raidprotect.bot/discord) unutmayın. Botun kullanımıyla ilgili sorularınızı yanıtlayacak destek ekibimizle de iletişime geçebilirsiniz. 😄

## 🚀 RaidProtect'e başlangıç {#start}

RaidProtect'i kullanmaya başlamak için aşağıdaki bağlantıyı kullanarak onu sunucunuza davet etmeniz yeterlidir.

<DocCard item={{ type: 'link', href: 'https://raidprotect.bot/invite', label: 'RaidProtect\'i davet et' }} />
<br />

:::danger
Dikkat, **RaidProtect adını kullanan** **bot kopyaları** dolaşımda; botu yalnızca resmî sitemizden davet edin.
:::

### Ön koşullar {#requirement}

RaidProtect'in düzgün çalışmasını sağlamak için:
1. RaidProtect'e **Yönetici iznini verin**. Bu, tüm kanallarınızı otomatik olarak denetlemesine olanak tanır.
2. **Rolünü sunucunuzun yöneticilerinin rolü seviyesine yerleştirin**. İzin sistemi, RaidProtect'in kendisinden üstte bir role sahip kullanıcılara yaptırım uygulamasına izin vermez.
