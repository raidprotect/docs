自 2018 年由 [Baptiste](https://baptiste.lol/) 创建以来，RaidProtect 已成为法语圈 Discord 服务器安全领域不可或缺的机器人之一。经过四年多的演进与开发，项目如今迎来一次重要的过渡：**RaidProtect 由 [S*l*ash FR](https://slash.fr.community/) 和 DFR.gg 背后的团队接手**。此次接手旨在保障机器人的未来，为其带来新的前景，并丰富其开发。

<!--truncate-->

## 为什么要接手？ {#why}

随着时间推移，维护 RaidProtect 这样的机器人变得越来越复杂。Discord 的不断变化、API 的更新以及日益增长的负载，让 Baptiste 越来越难以在保证稳定性和有效性的同时持续更新 RaidProtect。与其让 RaidProtect 停止运行，他选择将项目托付给我们。

于是，团队接过了接力棒，带来了应对 RaidProtect 相关技术与组织挑战所需的资源和能力。我们的目标很简单：改进并现代化机器人，同时忠于它一贯的样子。

## 哪些会改变（哪些不会！） {#changing}

#### ✅ RaidProtect 仍是您熟悉的那个机器人 {#same}
您正在使用的功能不会消失。我们保持**相同的理念**，只是希望在不打乱您使用习惯的前提下改进它。安全与可靠依然是项目的核心。

#### 🔄 技术重构，带来更佳性能 {#technical-overhaul}
机器人已被完全重写，变得更快、更稳定，也更能适应 Discord 的变化。这次重构不仅仅是一次改进，更是一种必然：随着 Discord API 新版本的推出，旧版机器人将根本无法继续运行。此次更新也让我们能够更轻松地添加新功能。

#### 🛠️ 更新与新功能即将到来 {#updates}
此次接手的一大优势是，我们终于可以投入时间和资源，让 RaidProtect 变得更加高效。以下是部分正在筹备的新内容：
- 支持**斜杠命令**，更好地贴合 Discord 的标准。
- 更多**配置选项**，以适应每个服务器的需求。
- **多语言系统**，扩大 RaidProtect 的覆盖范围。

#### 🔐 对安全的更坚定承诺 {#safety}
RaidProtect 的设计初衷是保护服务器，这始终是我们的首要任务。我们将密切关注 Discord 的发展，并让机器人适配平台推出的新工具。

## 您的问题，我们的解答（FAQ） {#faq}

在宣布接手 RaidProtect 后，我们收到了社区的大量提问。无论是在支持服务器上，还是在我们专为此次过渡举办的活动中，我们都感受到了大家对机器人未来的浓厚兴趣。为了把事情说清楚并给出准确的答复，我们在此汇总了最常见的问题。

#### 你们是谁？为什么是你们？ {#faq-1}

我们不只是一个团队，更是一群朋友。自 2017 年起，我们便将热情与专业结合起来，打造在线社区。我们还创办了 S*l*ash FR，一个专注于 Discord 及其最佳实践的法语社区。RaidProtect 自然而然地融入了这一生态。

我们知道，项目背后有一家公司这件事可能会让一些人感到担忧。坦白说，是的，我们需要为 RaidProtect 筹措资金，因为运行如此规模的机器人成本很高。但我们不想限制机器人，也不想把一切都变成付费内容。所有现有功能都将保持免费，付费选项则面向需要高级工具的用户。

#### 为什么由你们的公司接手 RaidProtect？ {#faq-2}
我们的公司专注于 Discord 服务器管理和机器人开发。团队希望投身一个大型项目，而 RaidProtect 完美契合了这一抱负。

#### 与 S*l*ash FR 有什么关系？ {#faq-3}
S*l*ash FR 是我们为聚集 Discord 爱好者而创建的社区。RaidProtect 自然在其中占有一席之地，但它仍是一个独立的项目。

#### RaidProtect 现有团队会有变动吗？ {#faq-4}
不会，社区团队的大部分成员将继续这段旅程，并有来自 S*l*ash FR 的新成员加入协助。Baptiste 本人也将不时为项目提供支持。

#### 机器人会变成付费的吗？ {#faq-5}
所有现有功能都将**保持免费**。不过，部分新的高级功能可能会以高级订阅的形式提供，以支付维护和开发费用。

#### RaidProtect 的设计和形象会改变吗？ {#faq-6}
不会，RaidProtect 的视觉形象**保持不变**。不过，网站将进行更新，以更好地反映项目的发展。

#### 你们的团队会开发其他机器人吗？ {#faq-7}
收购 RaidProtect 是我们未来为 Discord 服务器提供更多工具这一计划的一部分。不过，当前的首要任务仍是优化和完善 RaidProtect。

---

RaidProtect 在不断发展，但精神始终如一。我们知道这个机器人对许多服务器有多么重要，我们希望把它打造成一个更可靠、更高效、更贴合您需求的工具。

感谢大家的信任，冒险才刚刚开始！🚀
