3.3.3 版本完善了**管理人员工具箱**：全新的**集中式管理视图**、更丰富的处罚功能（软封禁、silent 选项、监禁角色），以及多项反突袭和 Antispam 调整。

![RaidProtect 3.3.3 ModView blog post social card](./assets/rp-modview.webp)

<!--truncate-->

## 🔍 ModView：一条命令，掌握成员的一切 {#modview}

再也不用在多条命令之间来回切换才能了解一位成员的情况。全新的 [`/modview`](/docs/features/moderation#modview) 命令会打开**集中式管理视图**：完整汇总该成员的信息，并可直接使用所有快捷操作。

- 其[**处罚记录**](/docs/features/sanctions)，附带最新状态。
- 工作人员共享的[**内部管理备注**](/docs/features/moderation#note)。
- 其在最近一小时内[**最后一条被删除的消息**](/docs/features/moderation#snipe)（如有）。

最重要的是**快捷操作**：直接在视图中处罚该成员（封禁、踢出、禁言、监禁、警告……）或修改其备注，无需重新输入命令，也无需切换窗口。

ModView 还带来了两条配套命令：

- **[`/note`](/docs/features/moderation#note)**：为成员添加仅工作人员可见的私人备注。非常适合在管理人员之间传递背景信息，又不会让处罚记录变得杂乱。
- **[`/snipe`](/docs/features/moderation#snipe)**：获取频道或成员在最近一小时内最后被删除的消息。

:::tip
也可以通过右键菜单打开 ModView：右键点击个人资料 → **应用** → **打开 Modview**。
:::

## ⚖️ 更丰富的处罚功能 {#sanctions}

多项新增功能让日常的处罚管理更加精细：

- **新命令 [`/softban`](/docs/features/moderation#softban)**：先封禁再解封成员。其消息会被删除，但仍可重新加入。非常适合在账户被盗后进行清理。
- 所有处罚命令均支持 **[`silent` 选项](/docs/features/moderation)**：当您希望单独处理情况时，可阻止 RaidProtect 向目标发送私信。
- `/ban` 和 `/tempban` 新增 **[`delete-messages` 参数](/docs/features/moderation#ban)**：在封禁时直接选择要删除的消息历史时长。
- **[“替换为监禁角色”模式](/docs/features/sanctions#jail-roles)**：监禁处罚现在可以在监禁期间移除成员的所有角色，并在释放时自动恢复。
- **AutoMod → 角色禁言转换**（*Premium 公测*）：Discord AutoMod 施加的、超过[配置阈值](/docs/features/sanctions#mute-threshold)的超时会被自动转换为[角色禁言](/docs/features/sanctions#mute)，与 RaidProtect 的系统完全保持一致。

其他一些不那么显眼的改进：更完善的处罚私信**送达回执跟踪**（已收到、私信已关闭、已过期、silent），踢出、软封禁或临时封禁后的通知私信中新增**服务器邀请按钮**，可以**为 `/sanctions delete` 添加原因**，以及可在服务器上[**完全停用处罚**](/docs/features/sanctions#disable)。

## ✨ 其他新内容 {#other}

- **自定义 RaidProtect 的个人资料**（*Premium*）：头像、横幅和昵称书写风格，让机器人融入您服务器的视觉形象。
- **[Antispam 处罚时长](/docs/features/anti-spam#duration)**：为 Antispam 施加的所有处罚选择统一时长。
- **全新的消息命令解析**：解析更严格，并与斜杠命令保持一致。
- 启用自动突袭模式时[**自动关闭私信**](/docs/features/raid-mode#close-dm)，在突袭期间阻断恶意私信浪潮。
- 斜杠命令的 **`duration` 参数支持自动补全**。
- [`/lock`](/docs/features/channel-lock#lock-duration) 和 [`/slowmode`](/docs/features/moderation#slowmode) 新增 **`[duration]` 参数**，可临时应用更改，无需再手动解除。
