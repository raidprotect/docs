RaidProtect 的全部命令，按类别分组。点击命令名称即可查看其详细文档。

## 命令格式图例 {#legend}

- `(arg)`：**必填**参数。
- `[arg]`：**可选**参数。
- `[--flag]`：可选的布尔标志（斜杠命令：`flag: true`，消息命令：`--flag`）。
- `[--flag=值]`：可选的带值标志。
- `(@user)` / `(#channel)` / `(@&role)`：表示所需类型的前缀。

## ⚙️ 使用命令的两种方式 {#usage}

常用的管理命令有两种形式：斜杠命令，以及带前缀的消息命令。其他命令，如 `/sanctions`、`/snipe` 或 `/audit`，只能以斜杠命令使用。[消息命令列表](./guides/prefix.md#activated)注明了哪些命令支持前缀。

### 斜杠命令：最简单的方式 {#slash}

在频道中输入 `/`，选择命令，**Discord 会在专用界面中为您提供每个参数**（用户选择器、频道选择器、时长自动补全等）。这是默认推荐的方式：您无需记忆任何内容。

```
/ban @成员 reason: 诈骗刷屏
```

### 消息命令：较复杂的方式 {#prefix}

在 [`/settings` 中启用消息命令](./guides/prefix.md)后，您也可以用普通消息的形式输入命令（`?ban …`、`?kick …` 等）。没有图形界面：您需要**熟悉语法**（位置参数、命名标志、行尾的自由参数）。作为回报，对于熟练掌握命令的管理员来说，用键盘输入更快。

#### 位置参数

按格式中的顺序给出，不带名称。它们是命令的主要参数。

```
?ban 123456789012345678
?slowmode 10s
```

#### 命名标志（`--名称=值`）

用于次要选项。标志可以放在命令中的**任意位置**，顺序不限。

- `--silent`（布尔）：直接启用该选项。
- `--delete-messages=7d`：为该选项传入一个值。

```
?ban @成员 --delete-messages=7d --silent 封禁原因
?tempban @成员 1d --silent 他又犯了
```

#### “rest”参数（自由文本）

部分命令的最后一个参数（通常是 `[reason]`）会捕获**其后写下的所有内容**，包括空格，无需加引号。

```
?warn @成员 你又违反了服务器的第 3 条规则
```
