**多账号**功能让您的团队可以声明多个 Discord 账号属于同一个人。其中一个账号受到的[处罚](./sanctions.mdx)会扩展到其他账号：被封禁的成员无法再用第二个账号回来规避处罚。

:::info 试验中：Identity Update
多账号属于计划在 3.7.0 版本发布的 **Identity Update**。在正式发布之前，它处于试验阶段，面向 [Premium](/zh-CN/premium) 服务器开放公开测试。
:::

## ❓ 工作原理 {#working}

- **每人一个分组**：分组汇集了您的团队认为属于同一个人的账号。分组为您的服务器所独有：不会与其他服务器共享任何内容。
- **共享处罚**（[Premium](/zh-CN/premium)）：封禁、踢出、禁言、监禁和超时会按您为每种处罚选择的[模式](#modes)扩展到分组中的其他账号。处罚仍记在被针对的账号名下，其他账号则获得该处罚的状态。没有 Premium 时，账号可以关联和查看，但不会扩展任何处罚：处罚日志会提及该成员的其他账号。
- **共同解除**：解除其中任何一个账号的处罚，都会为所有账号解除，无论是否使用 Premium。
- **分组搜索**：[搜索某个账号的处罚](./sanctions.mdx#search)时，也会显示分组中其他账号的处罚。
- **Discord 的 AutoMod**：Discord 的 AutoMod 施加的超时和禁言同样会扩展到关联账号。
- **由验证码发现**：[验证码的 Activity](./captcha.md#activity-alts) 可以自行关联两个确定属于同一个人的账号，或向您的团队提出关联建议。
- **日志**：关联、移除以及主账号的变更都会记录在[管理日志](./moderation.mdx#logs)中。

**上限：** 无，每个分组的账号数量和分组数量均不受限制。

## 🔗 使用 /alt 关联账号 {#alt}

使用命令：```/alt [user] [other]```

- 不带选项：显示服务器中已关联账号的分组列表。其中的“**关联两个账号**”按钮可关联服务器中的两位成员，或通过 ID 关联两个不在服务器中的账号。
- 带 `[user]`：显示该账号所在的分组；如果它没有与其他账号关联，则只显示该账号本身。每个账号都会显示其状态（已被服务器封禁、在服务器中、不在服务器中、已隔离），主账号排在最前。
- 带 `[user]` 和 `[other]`：直接关联这两个账号，并将其声明为同一个人。

将 `[user]` 和 `[other]` 替换为所需账号的提及或 [ID](../guides/id.mdx)。机器人不能被关联。

在分组的面板中：

- “**关联成员**”可向分组添加一个账号：服务器中的成员，或不在服务器中的账号的 Discord ID。
- “**修改分组中的账号**”选择器会打开一个窗口，可将其“**设为分组的主账号**”或“**将此账号移出分组**”。被移出的账号不再被视为同一个人，但如果它已随分组一起被封禁，则仍保持封禁。

您也可以在[管理视图 `/modview`](./moderation.mdx#modview) 中通过“**管理**”按钮查看成员的关联账号。

:::info
`/alt` 命令及其按钮需要**封禁成员**权限。
:::

## 🛠️ 配置多账号 {#config}

1. 使用 [`/settings` 命令](../setup.md#settings)。
2. 打开“**管理**”选项卡。
3. 点击“**多账号**”旁边的“**配置**”。

<Settings start="alts" />

### 关联账号的处罚 <span className="badge-premium">Premium</span> {#modes}

对于每种处罚，请选择它如何扩展到分组：

1. 在“多账号”界面中，点击“**关联账号的处罚**”旁边的“**编辑**”。
2. 在窗口中，为每种处罚选择一种模式。

界面中的“**全部设为…**”选择器会一次性为所有处罚应用同一种模式。

<SettingsModal name="altsModes" />

| 模式 | 效果 | 涉及的处罚 |
|---|---|---|
| “**立即**”*（默认）* | 封禁：所有关联账号立即被封禁，无论是否在服务器中。踢出：在服务器中的关联账号也会被踢出。禁言、监禁和超时：在服务器中的账号立即受罚，其他账号在加入时受罚。 | 全部 |
| “**在服务器的立即处理，其余加入时处理**” | 在服务器中的账号立即被封禁，不在服务器中的账号若在封禁期间加入服务器，则会被封禁。 | 封禁 |
| “**陷阱**” | 只处罚被针对的账号。分组中的另一个账号如果在处罚期间加入或发言，会被视为规避，并受到[规避处罚](#evasion)。 | 除踢出外的全部 |
| “**已停用**” | 处罚只针对所选的账号。 | 全部 |

### 群体处罚 {#group-sanction}

当处罚扩展到多个账号时，它在历史记录（[`/sanctions`](./sanctions.mdx#search)、`/modview`）中会显示为**一条群体处罚**（例如“**群体封禁**”），并列出所涉及的账号（“**账号**”）及各自的状态。每个账号保留自己的一行，并标注“属于群体处罚”。撤销、删除或修改（原因、时长）群体处罚会同时作用于所有账号。账号只能在 `/my-sanctions` 中查看自己的那一行。

### 规避处罚 {#evasion}

规避处罚适用于处于“**陷阱**”模式的关联账号：它在其分组受罚期间加入服务器或在服务器中发言。

1. 在“多账号”界面中，点击“**规避处罚**”旁边的“**编辑**”。
2. 在窗口中，选择“**处罚**”，如有需要再选择其“**时长**”。

<SettingsModal name="altsEvasion" />

- “**沿用剩余处罚**”*（默认）*：该账号共享分组的处罚直至结束，不会另外记在其名下。
- **某种处罚**（封禁、踢出、禁言、监禁或超时）：处罚记在其名下，有自己的时长，且不会随分组解除。时长留空表示永久处罚（例如：`1h`、`3d`、`2w`）。

:::info
超时始终需要时长，最长 28 天。禁言和监禁要求已配置其[角色](./sanctions.mdx#config)。
:::

### 每人仅限一个账号 {#single-account}

启用此设置后，每个分组中只有**主账号**可以在服务器上活动。其他账号会通过[监禁角色](./sanctions.mdx#jail)被**隔离**（在记录中显示为“**隔离**”处罚）。如果它们成为主账号，或被移出分组，就会自行解除隔离。

1. 使用 [`/settings` 命令](../setup.md#settings)。
2. 打开“**管理**”选项卡。
3. 点击“**多账号**”旁边的“**配置**”。
4. 点击“**每人仅限一个账号**”旁边的“**启用**”。

:::warning
此设置要求已有[监禁角色](./sanctions.mdx#jail)。没有的话，RaidProtect 会拒绝启用。
:::

要更改分组的主账号，请对其中任一账号使用 `/alt`，然后使用“**修改分组中的账号**”选择器。

## 常见问题 {#faq}

### 多账号会在服务器之间共享吗？

不会。分组为您的服务器所独有，不会与其他服务器共享任何内容。

### 我解封其中一个账号时会发生什么？

解除其中任何一个账号的处罚，都会为分组中的所有账号解除。

### 我可以关联不在我服务器中的账号吗？

可以。在 `/alt` 面板中，点击“**关联成员**”并输入其 Discord ID。

### 谁可以使用 /alt？

拥有**封禁成员**权限的成员；在 Identity Update 处于试验阶段期间，仅限 [Premium](/zh-CN/premium) 服务器。
