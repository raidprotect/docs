RaidProtect 的 **Automod** 汇集了各种过滤器，一旦有不需要的内容被发布，就会自动将其移除。每个过滤器对消息发送者都有各自的处罚。

打开方式：

1. 使用 [`/settings` 命令](../setup.md#settings)。
2. 打开“**防护**”选项卡。
3. 点击“**Automod**”旁边的“**配置**”。

<Settings start="automod" />

## 🖼️ 诈骗图片 {#images}

**图片**过滤器会删除已知的诈骗图片（加密货币诈骗、虚假抽奖、虚假赌场推广），并处罚其发送者。它**默认启用**，无需任何配置。

完整详情、处罚和图片目录请参阅[诈骗图片](./scam-images.md)页面。

## 🔗 其他服务器 {#servers}

**其他服务器**过滤器用于控制所有指向其他 Discord 服务器的内容：**邀请**、**转发的消息**、**频道链接**和**活动链接**，以及您的成员所**显示的服务器标签**。它可以拦截乱发的广告以及竞争对手或恶意服务器，而不会影响您的合作伙伴。

### 工作原理 {#servers-working}

三种行为可分别设置，每种行为可选择以下模式之一：

- “**已停用**”：不过滤任何内容。
- “**黑名单**”：名单中的服务器被拒绝，其他服务器放行。
- “**白名单**”：只有名单中的服务器放行，其余全部被拒绝。

| 行为 | 被拒绝时会发生什么 |
|---|---|
| **邀请链接** | 包含该邀请的消息会被删除。`ptb.` 和 `canary.` 链接同样计入；藏在嵌入、组件或转发消息中的邀请，以及事后被编辑的消息，也都会被识别。 |
| **转发的消息或频道链接** | 从该服务器转发的消息，或包含指向其任一频道或活动的链接的消息，会被删除。 |
| **显示的服务器标签** | 成员会被通过[监禁角色](./sanctions.mdx#jail)**隔离**。一旦其移除标签，隔离即解除。 |

您自己的服务器始终放行（无论通过它的哪一个邀请），您的团队（拥有**管理服务器**或**管理消息**权限）也永远不会被针对。

### 配置 {#servers-config}

1. 在 Automod 中，点击“**其他服务器**”旁边的“**配置**”。
2. 使用右上角的开关启用过滤器，然后为每种行为选择一种模式。

<Settings start="serverRefs" />

#### 好友和群组邀请 <span className="badge-premium">Premium</span> {#servers-private}

好友邀请或私人群组邀请不会通向任何服务器。在“**邀请链接**”模式下（只要不是“**已停用**”），“**好友和群组邀请**”选择器可单独设置它们的处理方式：

- “**遵循列表**”*（默认）*：黑名单模式下放行，白名单模式下删除。
- “**始终允许**”：无论名单如何，一律接受。
- “**始终删除**”：无论名单如何，一律删除。

没有 Premium 时，它们始终遵循名单。

:::tip
如果您修改了某个过滤器却没有启用它就离开其界面，RaidProtect 会在您离开前建议启用它（默认预选“**保持停用**”）。
:::

### 处罚 {#servers-sanction}

每条被拒绝的消息都会被删除。在“**被删除消息的处罚**”中，可另外为其发送者选择一种处罚，或选择“**仅删除消息**”。对于超时、禁言、监禁或封禁，还需选择其时长。

处罚对每位成员每分钟最多执行一次：连续粘贴多个邀请的成员只会被处罚一次。

### 服务器名单 {#servers-lists}

1. 点击“**添加服务器**”。
2. 粘贴该服务器仍然有效的邀请（例如 `discord.gg/example`）：其名称和 ID 都会从中读取。不再接受单独的 ID。
3. 选择名单：黑名单或白名单。

已在名单中的服务器只会切换到另一个名单。“**移除**”可将一个或多个服务器从名单中移除。

**上限：** 两个名单合计最多 25 个服务器。

:::tip
若只允许您合作伙伴的邀请，请将“**邀请链接**”设为“**白名单**”，并把您的合作伙伴加入白名单。空白名单会拒绝所有指向其他服务器的邀请。
:::

### 日志 {#servers-logs}

每次处罚和每次隔离都会记录在您的[管理日志](./moderation.mdx#logs)中，并注明相关的服务器和频道。仅删除消息而不处罚（“**仅删除消息**”）的情况也会被记录。处罚会出现在[处罚记录](./sanctions.mdx)中，原因为“邀请链接指向被拒绝的服务器”、“被拒绝的好友或群组邀请”（Premium）、“转发的消息或频道链接来自被拒绝的服务器”或“显示了被拒绝服务器的标签”。

## 📎 文件扩展名 {#files}

**文件扩展名**过滤器会删除扩展名被拒绝的文件。您可以屏蔽某些扩展名（黑名单），或只允许某些扩展名（白名单），作用于整个服务器或逐个频道设置。您的团队（拥有**管理服务器**或**管理消息**权限）永远不会被针对。

转发消息中的文件同样计入，子区遵循其所在频道的规则。

### 配置 {#files-config}

1. 在 Automod 中，点击“**文件扩展名**”旁边的“**配置**”。
2. 使用右上角的开关启用过滤器。
3. 在“**整个服务器**”下，选择一种模式：“**已停用**”、“**黑名单**”或“**白名单**”。
4. 勾选**分组**（可执行文件、图片、视频、音频、压缩包、文档），和/或输入其他扩展名并用逗号分隔，例如 `exe, msi`。点号可省略。除分组外，一条规则最多接受 50 个自定义扩展名。

<Settings start="files" />

:::warning
不含任何扩展名的白名单不接受任何文件：发送的所有文件都会被删除。
:::

### 按频道和分类设置的规则 {#files-channels}

点击“**添加频道**”，即可为某个频道、子区或分类设置规则。分类的规则适用于其下所有频道。

各条规则会叠加生效，但当某个扩展名被多条规则提及时，由**最具体**的规则决定（频道，其次是分类，最后是服务器）。例如，在某个频道中被允许的 `.exe` 即使在服务器黑名单中也会放行。未被任何规则提及的扩展名会通过所有规则。

| | 免费版 | <span className="badge-premium">Premium</span> |
|---|---|---|
| **按频道设置的规则** | 1 条（第一个设置的频道） | 20 个频道或分类 |
| **分类规则** | 否 | 是 |

没有 Premium 时，超出的规则会被保留，但不会生效。

### 损坏的文件 {#files-disguised}

被改名以冒充图片或视频的文件（例如改名为 `.png` 的 `.exe`）会被识别出来：Discord 无法将其作为真正的图片读取。白名单始终会拒绝它。“**始终拒绝损坏的文件**”选项会在所有频道中将其删除，即使没有白名单也是如此。

### 处罚 {#files-sanction}

每个被拒绝的文件都会连同其消息一起被删除。在“**被删除消息的处罚**”中，可另外为其发送者选择一种处罚，或选择“**仅删除消息**”。处罚对每位成员每分钟最多执行一次。

每条被删除的消息都会记录在您的[管理日志](./moderation.mdx#logs)中，并注明相关的文件、频道和扩展名。处罚会出现在[处罚记录](./sanctions.mdx)中，原因为“扩展名被拒绝的文件”。

## 常见问题 {#faq}

### 我的合作伙伴仍然可以分享他们的邀请吗？

可以。将他们加入其他服务器过滤器的白名单，或者不要把他们放进黑名单。

### 成员移除被拒绝的标签后会怎样？

其隔离会自动解除。

### 管理员会被过滤吗？

不会。拥有管理服务器或管理消息权限的成员永远不会被其他服务器过滤器针对。
