RaidProtect 的**欢迎**功能会在新成员加入您的 Discord 服务器时立即接待他们：一条带有专属卡片的**欢迎消息**、**自动角色**，以及**账号最短注册时长**，后者可拦截那些临时创建、常被用于[突袭](/zh-CN/learn/discord-raid)的账号。这三项设置都位于 `/settings` 的“**新成员**”选项卡中，与[验证码](./captcha.md)和 [Auto RaidMode](./raid-mode.md) 并列。

## ❓ 工作原理 {#working}

当用户加入您的服务器时，在其被放行之前，会依次应用[突袭模式](./raid-mode.md#action)、[账号最短注册时长](#minage)和[验证码](./captcha.md)。放行之后，他会获得[自动角色](#autorole)和[欢迎消息](#welcome-message)。

## 👋 欢迎消息 {#welcome-message}

当成员被服务器放行时，欢迎消息会发送到您选择的频道。它包含您的文字和为每位成员生成的**欢迎卡片**：他的头像、“欢迎来到”加上服务器名称，以及他的成员序号。

<Settings start="welcome" />

### 启用欢迎消息 {#welcome-config}

1. 使用 [`/settings` 命令](../setup.md#settings)。
2. 打开“**新成员**”选项卡。
3. 点击“**欢迎消息**”旁边的“**配置**”。
4. 在“**欢迎频道**”中，选择用于发送消息的文字频道。选择频道即会启用该消息。

界面右上角的开关可启用或停用欢迎消息。界面下方会显示消息预览，并在每次修改时更新。

:::info
欢迎频道不能是验证码、监禁、HoneyPot 或 DISCON 的频道。如果该频道被删除，该设置将被清空。
:::

### 文字与变量 {#welcome-text}

1. 使用 [`/settings` 命令](../setup.md#settings)。
2. 打开“**新成员**”选项卡。
3. 点击“**欢迎消息**”旁边的“**配置**”。
4. 在“**消息内容**”中，点击“**文本**”。
5. 写下您的消息（最多 1200 个字符），然后确认。将输入框留空则恢复默认消息。

<SettingsModal name="welcomeText" />

默认文字为“欢迎 `{user.mention}` 来到 **`{server.name}`**！🎉”，使用服务器的语言。您可以使用以下变量：

| 变量 | 替换为 |
|---|---|
| `{user.mention}` | 成员的提及 |
| `{user.name}` | 他的用户名 |
| `{user.displayname}` | 他的显示名称 |
| `{user.id}` | 他的 [ID](../guides/id.mdx) |
| `{server.name}` | 服务器名称 |
| `{server.member_count}` | 服务器的成员数量 |
| `{server.id}` | 服务器 ID |

### 提及成员 {#welcome-mention}

“**提及成员**”选项默认启用，发布欢迎消息时会通知新成员。它只会提及新加入的人，绝不会提及 @everyone 或角色。

### 按钮 {#welcome-buttons}

您可以在消息下方添加按钮，链接到服务器中的某个频道，例如“阅读规则”。

1. 使用 [`/settings` 命令](../setup.md#settings)。
2. 打开“**新成员**”选项卡。
3. 点击“**欢迎消息**”旁边的“**配置**”。
4. 在“**管理按钮**”中，选择“**添加按钮**”。
5. 为按钮命名，并选择要链接的频道。

要修改或删除按钮，请在同一列表中选择它。

**上限：** 免费版 2 个按钮，[Premium](/zh-CN/premium) 版 4 个按钮。如果 Premium 到期，只会保留显示前 2 个按钮。

### 颜色 <span className="badge-premium">Premium</span> {#welcome-color}

使用 [Premium](/zh-CN/premium) 时，在“**消息内容**”中点击“**颜色**”，可选择消息左侧竖条的颜色：列表中的 RaidProtect 颜色，或十六进制代码（例如 `#D35F5F`）。未选择时，如果您[自定义](/zh-CN/premium)了机器人的昵称，消息会沿用昵称的颜色，否则使用默认颜色。欢迎卡片也会采用相同的色调。

### 涌入与突袭 {#welcome-raid}

- **合并发送：** 当大量成员同时加入时，加入的成员会被合并处理，以免刷屏频道。
- **涌入期间静默：** 只要由 RaidProtect 维持的[突袭模式](./raid-mode.md)或[加入锁定](./join-lock.mdx)处于启用状态，就不会发送任何欢迎消息。

## 🏷️ 自动角色 {#autorole}

自动角色会在每位新成员加入时立即授予，如果启用了[验证码](./captcha.md)，则在通过验证码之后授予。它们取代了验证码以往的自动角色，该设置已被自动迁移。

1. 使用 [`/settings` 命令](../setup.md#settings)。
2. 打开“**新成员**”选项卡。
3. 点击“**自动身份组**”旁边的“**配置**”。
4. 选择一个或多个角色。

要移除所有自动角色，请点击“**重置**”。

<Settings start="autorole" />

**上限：** 免费版 3 个角色，[Premium](/zh-CN/premium) 版 10 个角色。

:::warning
请避免使用带有权限的角色：自动授予的角色不应赋予任何权力。RaidProtect 会拒绝由集成管理的角色、位于它或您自己的角色之上的角色，以及带有管理权限的角色：您所选角色中可接受的会被保留，另有一条单独的消息说明其余角色被拒绝的原因（若全部被拒绝，则保持现有配置不变）。如果所选角色之后获得了更多权限，它会向您发出提醒。
:::
:::info
如果您的服务器使用其他机器人来授予自动角色，它可能会在验证码之前就授予角色。请改用 RaidProtect 的自动角色。
:::

## 🎂 账号最短注册时长 {#minage}

为加强安全性，您可以要求新成员的 Discord 账号达到最短年龄。在突袭前不久才创建的账号无法通过。该过滤器对每一次加入都会生效。

1. 使用 [`/settings` 命令](../setup.md#settings)。
2. 打开“**新成员**”选项卡。
3. 点击“**账号最短注册时长**”旁边的“**配置**”。
4. 在“**账号最短注册时长**”中，选择 2 小时、12 小时、1 天或 2 天，或选择“**自定义值**”（例如 `0y 3d 1h`，最长 10 年）。
5. 在“**处理方式**”中，选择对注册时间过短的账号如何处理。

要停用该过滤器，请点击“**重置**”。RaidProtect 需要 `KICK_MEMBERS` 权限。

<Settings start="minage" />

### 处理方式 {#minage-action}

| 处理方式 | 对注册时间过短的账号的效果 |
|---|---|
| “**踢出**”（默认） | 只要其账号仍过新，每次尝试加入都会被踢出。 |
| “**监禁至达到要求**” | 它进入后看不到服务器的任何内容，一旦达到要求的年龄就会脱离[监禁](./sanctions.mdx#jail)。 |
| “**拦在入口**” | 它被拦在[验证码](./captcha.md)处，只有达到年龄后才能解答。 |

该账号会收到一条私信，告知其可访问服务器的日期。踢出、监禁和封禁都会记录在日志频道中。

:::info
- “**监禁至达到要求**”需要在“**管理**”选项卡 > “**处罚**”中配置监禁角色。没有的话，RaidProtect 会建议您配置，或改用“**封禁至达到要求**”：账号会被逐出服务器，并在正确的日期自动解除封禁。
- “**拦在入口**”要求验证码已启用，且为**面板（交互）**模式。
:::

### 🎫 绕过最短年龄 {#bypass-minage}

使用命令：```/bypass minage [user]```

将 `[user]` 替换为所需的 [ID](../guides/id.mdx)，该用户将有 10 分钟的时间加入服务器，而不会被所需年龄拦下。您也可以不指定用户而直接使用该命令，以查看当前的绕过用户列表。

## 常见问题 {#faq}

### 欢迎消息何时发送？

在成员被放行时发送：如果验证码不适用，则在他加入时立即发送，否则在通过验证码之后发送。在突袭或加入锁定期间不会发送。

### 可以去掉欢迎卡片吗？

不可以，欢迎卡片会附在每条欢迎消息上。使用 Premium 时，您可以更改它的颜色。

### 可以授予多少个自动角色？

免费版 3 个，使用 Premium 为 10 个。带有管理权限的角色会被拒绝。

### 自动角色会在验证码之前授予吗？

不会。当验证码适用于该成员时，他的自动角色会在通过验证码之后授予。

### 应该选择多长的最短年龄？

从几小时到 1 天的数值就足以排除大多数为突袭而创建的账号，同时不会妨碍真正的成员。[`/setup` 命令](../setup.md)默认设置为 6 小时。

### 注册时间过短的账号会被封禁吗？

默认不会：它每次尝试都会被踢出。您也可以将其监禁至达到要求的年龄，或将其拦在验证码之后。临时封禁只是在未配置监禁时的备用方案。
