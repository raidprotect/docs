RaidProtect 的 **HoneyPot**（陷阱频道）是一项反垃圾信息功能：一个 **[任何人都不应发言](/zh-CN/learn/honeypot-warming)** 的频道。由于真正的成员都知道要避开这个频道，在其中发言的只会是 **[被盗账号](/zh-CN/learn/token-grabber)** 或垃圾信息机器人：RaidProtect 会自动处罚它们。

:::info
**ScamLens 已默认启用。** 反诈骗功能 [ScamLens](./scam-images.md) 无需任何配置，已在您的服务器上生效：它专注于**诈骗图片**，能以极高的可靠性检测并删除它们，并处罚被盗账号。因此，对于图片诈骗，ScamLens 已经完全足够。如果您想要最高级别的安全性，并拦截**其他类型的垃圾信息**（链接刷屏、文字突袭、机器人），HoneyPot 会更有用。
:::

## ❓ 工作原理 {#working}

启用 HoneyPot 后，RaidProtect 会在服务器的**最顶部**创建一个文字频道，并随机取一个清晰易懂的名称。该频道有三个特点：
- **所有人都可以在其中发言**，包括尚未通过验证码的成员和拥有[监禁角色](./sanctions.mdx#jail)的成员。这是有意为之：被盗账号或机器人不应该能够避开陷阱。
- 频道创建时会发布一条**警告消息**（“请勿在此发送任何消息”），并附带“**Translate**”按钮，让每个人都能用自己的语言阅读。
- 抓到第一个账号后，“**Translate**”旁边会出现一个**被举报账号计数**按钮。

只要有成员在该频道中发言：
- RaidProtect 会执行**您选择的处罚**（封禁、软封禁、踢出、超时、监禁或禁言），且不会给该成员发送私信。
- 该成员在**过去 10 分钟内发送的消息**会在整个服务器范围内被删除，以便在垃圾信息已扩散到其他频道时将其制止。
- 该操作会被记入自动管理日志（原因：*通过被盗用户账户发送垃圾信息*）。

如果您选择了[处罚前的延迟](#grace)，该成员会先有机会说明这是个误会。

## 🛠️ 设置 HoneyPot {#config}

1. 使用 [`/settings` 命令](../setup.md#settings)。
2. 打开“**防护**”选项卡。
3. 点击“**HoneyPot**”旁边的“**配置**”。
4. 点击右上角的“**启用**”：RaidProtect 会创建频道、设置权限并发布警告消息。

<Settings start="honeypot" />

频道创建后，您可以：
- **重新生成频道**（“**HoneyPot 频道**”旁边的按钮）：删除旧频道并创建一个新名称的新频道。如果您怀疑有成员为了帮助其他账号避开陷阱而泄露了陷阱频道的名称，这会很有用。
- **停用**（右上角的开关）：删除频道并停止该功能。

:::warning 所需权限
RaidProtect 需要 `管理频道` 和 `封禁成员` 权限。缺少这些权限时，会显示错误提示框，按钮也会呈灰色。
:::

### 选择处罚 {#sanction}

默认情况下，HoneyPot 执行**软封禁**。在“**应用的处罚**”选择器中提供多种[处罚](/zh-CN/learn/discord-sanctions)：

| 处罚 | 效果 | 可用性 |
|---|---|---|
| **封禁** | 将成员移出服务器并删除其近期消息。临时封禁（默认 1 天）。 | 免费 |
| **软封禁** | 先封禁再解封：删除消息，但成员可以回来 | 免费 |
| **踢出（Kick）** | 将成员移出服务器，成员可以自由回来 | Premium |
| **超时** | 在所选时间内禁止成员发言（最长 28 天） | Premium |
| **监禁** | 授予服务器上已配置的[监禁角色](./sanctions.mdx#jail) | Premium |
| **禁言** | 授予服务器上已配置的[禁言角色](./sanctions.mdx#mute) | Premium |

对于有时长的处罚（封禁、超时、监禁、禁言），请在“**时长**”选择器中选择时长（默认 1 天），或选择“**自定义值**”输入您自己的时长（例如 `5m`、`1h`、`2d`；最短 1 分钟）。对于没有时长的软封禁和踢出，该选择器呈灰色。

选择器提供的选项随处罚而变：

| 处罚 | 提供的选项 |
|---|---|
| **封禁** | 永久、1 天、7 天、30 天 |
| **监禁** | 永久、1 小时、1 天、7 天 |
| **禁言** | 5 分钟、1 小时、1 天、7 天 |
| **超时** | 5 分钟、1 小时、1 天、28 天 |

封禁和监禁可以是**永久**的：处罚不会自行解除。更换处罚时，如果所选时长仍然可用，则会保留（永久不会沿用到超时或禁言，超时也始终保持在 28 天以内）。

:::tip
**软封禁**是一个不错的折中方案：它会清理消息并将被盗账号移出，但合法的账号主人在账号安全恢复后可以回来。
:::

:::info
只有**封禁**和**软封禁**能让 Discord 一次性在**整个服务器范围内**原生删除被盗账号的消息。  
对于其他处罚（踢出、超时、监禁、禁言），消息由 RaidProtect 自行删除：这些处罚仅限 [Premium](/zh-CN/premium) 服务器使用。
:::

:::info
- 未配置角色的**监禁**或**禁言**会变成**超时**。选择器会在该处罚下方注明。
- 如果您的服务器失去 Premium，下次触发时，Premium 处罚会自动改回**软封禁**。
:::

### 处罚前的延迟 {#grace}

善意的成员可能会误在 HoneyPot 中发言。**处罚前的延迟**让他在被处罚之前有时间说明情况。

1. 使用 [`/settings` 命令](../setup.md#settings)。
2. 打开“**防护**”选项卡。
3. 点击“**HoneyPot**”旁边的“**配置**”。
4. 在“**处罚前的延迟**”中，选择“**立即处罚**”（默认）或“**先询问，30 秒后处罚**”（也可选 1 分钟、2 分钟或 5 分钟）。

设置延迟后：
- 消息会被**删除**，该成员会在陷阱频道中被**提及**，并附带“**这是误操作**”按钮；
- 只有该成员可以点击按钮。如果他及时点击，则不会执行任何处罚；
- 如果在延迟结束前没有点击，处罚就会生效。

:::info
垃圾信息机器人通常到处发布相同的文本。如果某个账号在别处发布了**相同的消息**，会被**立即**处罚，无需等待。
:::

### 忽略的成员 {#ignore}

您可以在“**忽略的成员**”选择器中选择，当有人在 HoneyPot 中发言时，**哪些人不会被处罚**：
- “**无人（无法处罚的成员除外）**”*（默认）*：所有人都会被处罚，包括工作人员。只有机器人无法管理的成员（角色高于 RaidProtect）会被自动豁免。
- “**工作人员（管理员 / 管理服务器 / 管理频道）**”：拥有 `管理员`、`管理服务器` 或 `管理频道` 权限的成员不会被处罚。
- “**Antispam 忽略的成员**”：RaidProtect 沿用 [Antispam](./anti-spam.mdx#ignore) 中被忽略的角色和成员。如果该名单为空，则忽略拥有 `管理员`、`管理服务器` 或 `管理消息` 权限的成员。

:::info
无论如何，RaidProtect **永远不会处罚它自己，也不会处罚其他机器人**。机器人不会触发 HoneyPot。
:::

## ℹ️ /honeypot 命令 {#command}

`/honeypot` 命令会直接打开 HoneyPot 的配置界面，无需经过 `/settings`。它需要 `管理服务器` 权限。

使用命令：```/honeypot```

## 🤝 HoneyPot 与 ScamLens，搭配效果更好 {#scamlens-combo}

RaidProtect 已内置 **[ScamLens](./scam-images.md)**，它会分析图片，并删除其中已知的诈骗图片（加密货币、虚假抽奖、虚假赌场促销）。

两者携手工作：
- **ScamLens 优先。** 如果发布在 HoneyPot 中的图片已为人所知，则由 ScamLens 删除消息并处罚被盗账号；HoneyPot 的处罚不会再重复执行。
- **HoneyPot 接手**其余所有情况：尚未被收录的新图片、链接刷屏、大量提及、文字突袭、机器人。
- **HoneyPot 抓到的每一张新图片都会充实 ScamLens**，使其之后能在所有受保护的服务器上拦截该图片。
- **ScamLens 跟随您的 HoneyPot**：只要您没有为它单独设置，它就会采用您 HoneyPot 的[处罚和时长](./scam-images.md#config)。

ScamLens 已在您的服务器上默认启用。**启用 HoneyPot 不会破坏任何现有设置**：它只是对现有功能的补充，并帮助 RaidProtect 更好地保护整个社区。

## 常见问题 {#faq}

### 如果我已经有 ScamLens，HoneyPot 还有用吗？

对于图片诈骗，ScamLens 已经完全足够：它默认启用，能自动检测、删除并处罚。HoneyPot 主要用于拦截其他类型的垃圾信息，例如链接刷屏、文字突袭和机器人。

### HoneyPot 会执行哪种处罚？

默认是软封禁。您可以选择其他处罚：封禁和软封禁免费，而踢出、超时、监禁和禁言仅限 Premium 服务器。HoneyPot 的封禁默认持续 1 天，您可以修改该时长。

### 有成员误在 HoneyPot 中发言了，怎么办？

启用处罚前的延迟：消息会被删除，成员会被提及，并有 30 秒到 5 分钟的时间点击“这是误操作”。如果他及时点击，就不会被处罚。不过，在别处发布了相同消息的账号会被立即处罚。

### 工作人员在 HoneyPot 中发言会被处罚吗？

这取决于“忽略的成员”选项。默认情况下，所有人都会被处罚，包括工作人员。RaidProtect 永远不会处罚自己，机器人也永远不会触发陷阱。

### 被 HoneyPot 抓到的账号发送的消息会怎样？

除了处罚之外，该成员在过去 10 分钟内发送的消息会在整个服务器范围内被删除，以便在垃圾信息已扩散到其他频道时将其制止。
