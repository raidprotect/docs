**服务器日志**会记录您服务器上发生的事情：谁创建了频道、修改了角色、删除了消息，或将成员从语音频道断开。每条日志都以执行者开头（“@modo 创建了频道 #常规。”），并显示修改前后的内容。

:::info 试验中：Logging Update
服务器日志属于 **Logging Update**，计划在 3.8.0 版本中推出。在正式发布之前，它们处于试验阶段，面向 [Premium](/zh-CN/premium) 服务器开放公开测试。
:::

## ⚙️ 配置日志 {#config}

1. 使用 [`/settings` 命令](../setup.md#settings)。
2. 打开“**管理**”选项卡。
3. 点击“**日志**”旁边的“**配置**”。
4. 打开“**服务器日志**”，然后为每个类别选择一个频道。

每个类别中有两个列表：

- **发送的类型**：取消勾选某个类型后，它将不再发送到任何地方。
- **发送到其他频道的类型**：为某个类型指定单独的频道。没有单独频道的类型会发送到其类别的频道。

**上限：** 免费版最多 3 个不同的日志频道，[Premium](/zh-CN/premium) 版最多 15 个。没有 Premium 时，只有前 3 个频道会收到日志：其余频道会被暂停，其设置会被保留。

[管理日志](./moderation.mdx#logs)的“**常规**”、“**管理**”和“**验证码**”频道保持不变。

## 📚 日志类别 {#families}

| 类别 | 记录的内容 |
| --- | --- |
| **频道、角色和邀请** | 分类、频道、语音频道和子区的创建、修改或删除，包括权限。角色（及其新的排列顺序）、邀请、Webhook、集成，以及机器人的添加或移除及其角色。Discord 的 AutoMod 规则（包括添加或移除的词语和表达式）以及活动。对活动感兴趣的成员为 [Premium](/zh-CN/premium) 专属。 |
| **成员** | 加入（附带账号年龄）和离开（附带加入日期和角色）、接受规则、角色的添加或移除、昵称、服务器头像、被清理的不活跃成员以及助力。 |
| **消息** | 被删除的消息及删除者、被编辑的消息、批量删除、消息的置顶或取消置顶。 |
| **语音** <span className="badge-premium">Premium</span> | 加入、离开及会话时长、切换频道、麦克风、声音、摄像头和屏幕共享。团队的操作（禁言、禁听、移动、断开连接）单独记录，并注明执行者。舞台的开启、修改或结束，以及上台发言或举手的成员。 |
| **表情符号和反应** | 表情符号、贴纸和音效板声音的创建、修改或删除。反应的添加或移除为 [Premium](/zh-CN/premium) 专属，默认不勾选。 |

被编辑的消息会显示编辑前后的内容。对于较长的消息，只显示改动的行。

当操作的执行者填写了**原因**（可在 Discord 的审核日志中查看）时，该原因会显示在日志中。与角色相关的日志带有“**身份组**”按钮，可打开该角色的 [`/roleinfo`](./utilities.mdx#roleinfo) 信息卡。

由 RaidProtect 自身删除的消息（Antispam、HoneyPot、反诈骗、`/clear`）会保留在相应模块的日志中，不会重复记录。

## 🎨 日志格式 {#format}

在同一界面的“**日志格式**”中选择格式。

| 格式 | 显示方式 |
| --- | --- |
| **默认** | 时间、图标、提及及其名称，然后是详情。 |
| **卡片** | 每条日志一个彩色卡片，包含标题和详情。 |
| **紧凑** <span className="badge-premium">Premium</span> | 每条日志一行：时间、图标和提及。 |

失去 Premium 的服务器会恢复为默认格式。其选择会被保留，待 Premium 恢复后继续使用。

## 💾 内存中的消息 {#cache}

为了找回被删除消息的内容，RaidProtect 会在内存中保留最近的消息：免费版 **15 分钟**，[Premium](/zh-CN/premium) 版 **6 小时**。超过这个时间，日志会注明内容未被保留。

使用 Premium 时，被删除消息的附件也会复制到日志中（每个文件 10 MB，每个服务器 100 MB，最早的附件会最先被替换）。
