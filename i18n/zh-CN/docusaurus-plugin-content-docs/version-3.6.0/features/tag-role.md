标签角色可以为在 Discord 个人资料中添加了[您服务器标签](https://support.discord.com/hc/zh-tw/articles/31444248479639-%E4%BC%BA%E6%9C%8D%E5%99%A8%E6%A8%99%E7%B1%A4)的成员自动授予角色。通过为这些成员授予角色，您可以肯定他们的参与，并鼓励他们积极代表您的服务器。这是一种简单而有效的方式，既能增强集体认同感，又能奖励社区中最忠实的大使。

## ❓ 标签角色的工作原理 {#working}

原理很简单。成员一在 Discord 个人资料上添加服务器标签，RaidProtect 就会自动为其授予一个特定角色。
如果成员移除了标签，该角色也会被一并移除。

我们会在成员的个人资料下一次更新（昵称、头像、横幅、角色、标签……）时检测到这一变化。

:::info
如果未启用标签，或者您的服务器尚未拥有该功能，标签角色将不会产生任何效果。
:::

## 🎖️ 配置标签角色 {#config}

只需点击几下即可完成配置：
1. 使用 [`/settings` 命令](../setup.md#settings)。
2. 打开“**实用工具**”选项卡。
3. 点击“**标签角色**”旁边的“**配置**”。
4. 通过选择器选择一个现有角色，或点击“**帮我创建一个**”：我们会创建一个名为 `标签`、不带任何权限的角色。
5. 您随时可以点击“**重置**”按钮来停用标签角色。

标签角色的每次配置变更都会记录在您的服务器日志中。

### /tagrole 命令 {#command}

使用命令：```/tagrole```

它会直接打开标签角色的配置界面，无需经过 `/settings`。仅限拥有“**管理角色**”权限的成员使用。

### 被拒绝的角色 {#refused-roles}

标签角色会自动授予任何成员，因此我们会拒绝可能引发问题的角色。

- **已被 RaidProtect 使用的角色**：监禁角色、禁言角色、验证码的验证角色或自动角色。
- **由应用或服务器助力管理的角色**：Discord 禁止手动授予。请改为创建一个普通角色。
- **位于 RaidProtect 角色之上的角色**：请在**服务器设置 > 角色**中将 RaidProtect 的角色拖到其上方。
- **位于您最高角色之上的角色**（服务器所有者除外）。
- **带有敏感权限的角色**：管理员、封禁、踢出、管理服务器、频道、消息、角色、Webhook、表情与贴纸、活动或子区。

### 警示提示框 {#warnings}

当标签角色无法正常工作时，配置界面会提醒您：

- **缺少权限**：RaidProtect 需要“**管理角色**”权限。在 `/settings` 的“实用工具”选项卡中，“**标签角色**”旁边也会显示 ⚠️ 警示。
- **未启用服务器标签**：您的服务器尚未启用[服务器标签](https://support.discord.com/hc/zh-tw/articles/31444248479639-%E4%BC%BA%E6%9C%8D%E5%99%A8%E6%A8%99%E7%B1%A4)功能，因此标签角色目前不会产生任何效果。

修复后，请点击“**刷新**”重新检查。

## 常见问题 {#faq}

### 为什么佩戴标签的成员还没有获得角色？

我们会在成员的个人资料下一次更新时检测标签。只要成员没有修改任何内容（昵称、头像、角色、标签……），就不会授予角色。如有需要，支持团队可以发起一次完整同步。

### 为什么我的角色被拒绝？

标签角色不能是已被 RaidProtect 使用的角色、由应用管理的角色、位于 RaidProtect 或您自己之上的角色，也不能是带有敏感权限的角色。

### 谁可以配置标签角色？

管理员可通过 `/settings` 配置，拥有“管理角色”权限的成员可通过 `/tagrole` 命令配置。
