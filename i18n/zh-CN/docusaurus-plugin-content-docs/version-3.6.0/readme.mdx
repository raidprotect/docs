## 🚀 开始使用 RaidProtect {#start}

要开始使用 RaidProtect，只需通过以下链接将它邀请到您的服务器。

<DocCard item={{ type: 'link', href: 'https://raidprotect.bot/invite', label: '邀请 RaidProtect' }} />
<br />

:::danger
请注意，目前有**冒用 RaidProtect 名称**的**机器人副本**在流传，请务必只通过我们的官方网站邀请它。
:::

### 前提条件 {#requirement}

为确保 RaidProtect 正常运行：
1. **授予 RaidProtect 管理员权限。** 这样它才能自动管理您所有的频道。
2. **将它的角色放在与服务器管理员相同的层级。** 由于权限系统的限制，RaidProtect 无法处罚角色位于它之上的用户。
