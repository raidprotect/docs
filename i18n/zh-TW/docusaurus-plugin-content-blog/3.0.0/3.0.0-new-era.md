自 2018 年由 [Baptiste](https://baptiste.lol/) 創立以來，RaidProtect 已成為 Discord 伺服器安全領域中不可或缺的法語機器人之一。經過四年多的演進與開發，這個專案如今正迎來一次重要的轉變：**RaidProtect 由 [S*l*ash FR](https://slash.fr.community/) 與 DFR.gg 背後的團隊接手**。此次接手旨在確保機器人的未來，為它帶來新的展望，並豐富其開發。

<!--truncate-->

## 為什麼要接手？ {#why}

隨著時間推移，維護像 RaidProtect 這樣的機器人變得越來越複雜。面對 Discord 的演變、API 的更新以及日益增加的負載，Baptiste 越來越難在保持 RaidProtect 與時俱進的同時，確保其穩定性與效率。與其看著 RaidProtect 停擺，他選擇將專案託付給我們。

團隊因此接下了這個任務，並帶來足以應對 RaidProtect 相關技術與組織挑戰的資源與能力。我們的目標很簡單：改進並現代化這個機器人，同時忠於它一貫的樣貌。

## 有哪些改變（以及哪些不會改變！） {#changing}

#### ✅ RaidProtect 仍是您熟悉的那個機器人 {#same}
您正在使用的功能不會消失。我們保留**相同的理念**，只是想在不打亂您使用習慣的前提下改進它。安全與可靠依然是專案的核心。

#### 🔄 技術全面翻新，效能更佳 {#technical-overhaul}
機器人已完全重寫，變得更快、更穩定，也更能適應 Discord 的變化。這次翻新不只是改進，更是必要之舉：隨著新版 Discord API 的推出，舊版機器人根本無法再運作。這次更新也讓我們能更輕鬆地加入新功能。

#### 🛠️ 即將推出的更新與新功能 {#updates}
這次接手的一大好處，是我們終於能投入時間與資源，讓 RaidProtect 變得更加有效。以下是幾項正在準備中的新功能：
- 支援**斜線指令**，更符合 Discord 的標準。
- 更多**設定選項**，以適應每個伺服器的需求。
- **多語言系統**，擴大 RaidProtect 的影響範圍。

#### 🔐 對安全更堅定的承諾 {#safety}
RaidProtect 的設計初衷是保護伺服器，而這始終是我們的首要任務。我們將密切關注 Discord 的發展，並讓機器人適應平台所提供的新工具。

## 您的問題，我們的回答（FAQ） {#faq}

在我們宣布接手 RaidProtect 時，收到了許多來自社群的問題。無論是在支援伺服器上，還是在我們為這次轉移舉辦的專屬活動中，我們都看到大家對機器人的未來抱有濃厚的興趣。為了釐清狀況並提供明確的答案，我們在此整理了最常見的疑問。

#### 你們是誰？為什麼是你們？ {#faq-1}

與其說是一個團隊，我們更是一群朋友，自 2017 年起便結合熱情與專業來打造線上社群。我們也創立了 S*l*ash FR，一個專注於 Discord 及其最佳實踐的法語社群。RaidProtect 自然而然地加入了這個生態系。

我們知道，專案背後有一家公司，可能會讓部分人感到擔心。老實說，是的，我們必須為 RaidProtect 籌措資金，因為這種規模的機器人營運成本很高。但我們不想限制機器人，也不想把一切都變成付費。所有現有功能都將維持免費，付費選項則提供給想要進階工具的使用者。

#### 為什麼你們的公司要接手 RaidProtect？ {#faq-2}
我們的公司專精於 Discord 伺服器管理與機器人開發。團隊希望投入一個具規模的專案，而 RaidProtect 正好完全符合這份抱負。

#### 和 S*l*ash FR 有什麼關係？ {#faq-3}
S*l*ash FR 是我們為了凝聚 Discord 愛好者而創立的社群。RaidProtect 在其中自然有一席之地，但它仍是一個獨立的專案。

#### RaidProtect 現有的團隊會改變嗎？ {#faq-4}
不會，社群團隊的大部分成員都會繼續這段旅程，並有來自 S*l*ash FR 的新成員協助。Baptiste 本人也會持續不定期地支援專案。

#### 機器人會變成付費的嗎？ {#faq-5}
所有現有功能都將**維持免費**。不過，部分新的進階功能可能會以 Premium 訂閱的形式提供，以支應維護與開發的費用。

#### RaidProtect 的設計與形象會改變嗎？ {#faq-6}
不會，RaidProtect 的視覺識別**維持不變**。不過，網站將會進行更新，以更好地反映專案的演進。

#### 你們的團隊會開發其他機器人嗎？ {#faq-7}
收購 RaidProtect 是我們長期為 Discord 伺服器提供其他工具這個目標的一部分。不過，目前的首要任務仍是最佳化並完善 RaidProtect。

RaidProtect 在演進，但精神始終如一。我們知道這個機器人對許多伺服器有多重要，我們希望讓它成為一個越來越可靠、高效且符合您需求的工具。
