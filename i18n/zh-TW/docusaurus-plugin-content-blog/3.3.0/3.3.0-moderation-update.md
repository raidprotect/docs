3.3.0 版推出了處罰紀錄，重新塑造您 Discord 伺服器上的處罰管理方式：這是一套完整的系統，用於追蹤、管理與分析所有管理動作。

![RaidProtect Moderation Update blog post social card](./assets/rp-moderation-update.webp)

<!--truncate-->

## 📋 每一筆處罰都有完整紀錄 {#new}

透過全新的[處罰紀錄](/docs/features/sanctions)，記下所有管理動作。再也不必猜測誰在何時、因何受到處罰：

- **自動集中管理**：停權、踢出、超時以及 Automod 的處罰都會自動記錄。
- 使用 [`/sanctions search`](/docs/features/sanctions#search) **進階搜尋**：立即找到成員的紀錄。
- 使用 [`/sanctions info`](/docs/features/sanctions#info) 查看**完整細節**：查閱特定處罰的所有細節。
- 使用 [`/sanctions edit`](/docs/features/sanctions#edit) **彈性修改**：更正原因或調整現有的處罰。
- 使用 [`/sanctions delete`](/docs/features/sanctions#delete) **刪除或撤銷**：必要時撤銷處罰或將其從紀錄中刪除。
- **[智慧管理處罰狀態](/docs/features/sanctions#status)**

現在每一筆處罰都會產生一份回執，確認成員是否確實收到私訊通知。

---

## ⚡ 全新的管理工具 {#moderation}

這次更新也以三個不可或缺的新指令充實您的管理工具庫：

- **[`/tempban`](/docs/features/moderation#tempban)**：在設定的期間內暫時停權成員。
- **[`/warn`](/docs/features/moderation#warn)**：警告成員，並在紀錄中完整追蹤。
- **[`/untimeout`](/docs/features/moderation#untimeout)**：在預定到期前解除超時。

---

## 🛡️ 突襲模式與加入鎖定再升級 {#raid}

反突襲系統變得更聰明、更有彈性：

- **自動停用**：[突襲模式](/docs/features/raid-mode#raid-mode)與 [Auto RaidMode](/docs/features/raid-mode#duration) 會在一段時間後自動停用，再也不會忘記關閉！
- **時長參數**：使用 [`/raidmode`](/docs/features/raid-mode#raid-mode) 啟用時即可直接設定時長。
- **新的 [`/joinlock`](/docs/features/join-lock) 指令**：無限期關閉邀請，完全掌控新加入者。
- **[帳號最短註冊時長](/docs/features/raid-mode#minage)的回執**：收到回執，確認成員是否確實收到說明訊息。

---

## ✨ 3.3.0 的其他新功能 {#changelog}

- **處罰專用紀錄**：設定一個專門的頻道，集中所有處罰紀錄。
- **[`/channel duplicate`](/docs/features/utilities#channel-duplicate)**：連同所有設定嚴格複製頻道。
- **`/changelog` 指令**：直接在 Discord 中查看更新日誌，也可透過 `/settings` 與 `/about` 存取。
