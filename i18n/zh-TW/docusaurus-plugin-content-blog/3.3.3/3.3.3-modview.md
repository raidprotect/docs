3.3.3 版補齊了**管理人員工具箱**：全新的**集中式管理檢視**、更豐富的處罰（軟停權、silent 選項、監禁角色），以及多項反突襲與 Antispam 的調整。

![RaidProtect 3.3.3 ModView blog post social card](./assets/rp-modview.webp)

<!--truncate-->

## 🔍 ModView：一個指令掌握成員的一切 {#modview}

不必再在多個指令之間來回切換，才能了解成員的狀況。全新的 [`/modview`](/docs/features/moderation#modview) 指令會開啟**集中式管理檢視**：成員的完整摘要，以及可直接使用的所有快捷操作。

- 其**[處罰紀錄](/docs/features/sanctions)**，並顯示最新狀態。
- 管理團隊共用的**[內部管理備註](/docs/features/moderation#note)**。
- 其最近一小時內的**[最後一則被刪除的訊息](/docs/features/moderation#snipe)**（如果有的話）。

最重要的是**快捷操作**：直接從檢視中處罰成員（停權、踢出、禁言、監禁、警告……）或修改其備註，無需重新輸入指令或切換視窗。

兩個輔助指令隨 ModView 一同推出：

- **[`/note`](/docs/features/moderation#note)**：為成員新增僅管理團隊可見的私人備註。非常適合在管理人員之間傳遞背景資訊，又不會讓處罰紀錄變得雜亂。
- **[`/snipe`](/docs/features/moderation#snipe)**：找回頻道或成員在最近一小時內最後被刪除的訊息。

:::tip
ModView 也可以透過情境選單使用：在個人檔案上按右鍵 → **應用程式** → **開啟 Modview**。
:::

## ⚖️ 更豐富的處罰 {#sanctions}

多項新增功能讓日常的處罰管理更加精細：

- **新的 [`/softban`](/docs/features/moderation#softban) 指令**：先停權再解除停權成員。其訊息會被刪除，但他可以再回來。非常適合在帳號遭駭後進行清理。
- 所有處罰指令新增 **[`silent` 選項](/docs/features/moderation)**：當您想另行處理狀況時，可防止 RaidProtect 傳送私訊給對象。
- `/ban` 與 `/tempban` 新增 **[`delete-messages` 參數](/docs/features/moderation#ban)**：在停權時直接選擇要刪除的歷史訊息時長。
- **[「以監禁角色取代」模式](/docs/features/sanctions#jail-roles)**：監禁處罰現在可以在監禁期間移除成員的所有角色，並在其被釋放時自動恢復。
- **AutoMod → 以角色為基礎的禁言轉換**（*Premium 公開測試版*）：Discord AutoMod 施加的超時若超過[所設定的閾值](/docs/features/sanctions#mute-threshold)，會自動轉換為[以角色為基礎的禁言](/docs/features/sanctions#mute)，與 RaidProtect 的系統完全一致。

其他較不顯眼的改進：更完善的處罰私訊**回執追蹤**（已收到、私訊已關閉、已逾時、靜默）、在踢出、軟停權或暫時停權後的通知私訊中加入**伺服器邀請按鈕**、可**為 `/sanctions delete` 加上原因**，以及可在伺服器上**[完全停用處罰](/docs/features/sanctions#disable)**。

## ✨ 其他新功能 {#other}

- **自訂 RaidProtect 的個人檔案**（*Premium*）：頭像、橫幅與暱稱書寫風格，讓機器人融入您伺服器的視覺識別。
- **[Antispam 處罰的時長](/docs/features/anti-spam#duration)**：為 Antispam 所施加的所有處罰選擇時長。
- **全新的訊息指令解析**：解讀更嚴謹，並與斜線指令保持一致。
- 啟用 Auto RaidMode 時**[自動關閉私訊](/docs/features/raid-mode#close-dm)**，在突襲期間截斷充滿敵意的私訊浪潮。
- 斜線指令的 **`duration` 參數支援自動完成**。
- [`/lock`](/docs/features/channel-lock#lock-duration) 與 [`/slowmode`](/docs/features/moderation#slowmode) 新增 **`[duration]` 參數**，可暫時套用變更，無需事後手動解除。
