RaidProtect 的所有指令，依類別分組。點擊指令名稱即可前往其詳細文件。

## 原型圖例 {#legend}

- `(arg)`：**必填**參數。
- `[arg]`：**選填**參數。
- `[--flag]`：選填的布林旗標（斜線指令：`flag: true`，訊息指令：`--flag`）。
- `[--flag=值]`：選填的帶值旗標。
- `(@member)` / `(#channel)` / `(@&role)`：表示預期類型的前綴。

## ⚙️ 使用指令的兩種方式 {#usage}

常用的管理指令有兩種格式：斜線指令，以及帶前綴的訊息指令。其他指令，例如 `/sanctions`、`/snipe` 或 `/audit`，只能以斜線指令使用。[訊息指令清單](./guides/prefix.md#activated)列出了哪些指令接受前綴。

### 斜線指令：最簡單 {#slash}

在頻道中輸入 `/`，選擇指令，**Discord 會在專屬介面中為您提供每個參數**（使用者選擇器、頻道選擇器、時長自動完成等）。這是預設的建議方式：您無需記住任何東西。

```
/ban @member reason: 詐騙垃圾訊息
```

### 訊息指令：最複雜 {#prefix}

在 [`/settings` 中啟用訊息指令](./guides/prefix.md)後，您也可以用一般訊息的方式輸入指令（`?ban …`、`?kick …` 等）。沒有圖形介面：您必須**熟悉語法**（位置參數、具名旗標、行尾的自由參數）。作為回報，對熟悉指令的管理人員來說，用鍵盤操作更快。

#### 位置參數

依原型的順序給出，不帶名稱。這些是指令的主要參數。

```
?ban 123456789012345678
?slowmode 10s
```

#### 具名旗標（`--名稱=值`）

用於次要選項。旗標可以放在指令中的**任何位置**，順序不拘。

- `--silent`（布林）：直接啟用該選項。
- `--delete-messages=7d`：為該選項傳入一個值。

```
?ban @member --delete-messages=7d --silent 停權原因
?tempban @member 1d --silent 他又再犯了
```

#### 「rest」參數（自由文字）

部分指令的最後一個參數（通常是 `[reason]`）會擷取**您在其後寫的所有內容**，包含空格，無需加上引號。

```
?warn @member 你又違反了伺服器的第 3 條規則
```
