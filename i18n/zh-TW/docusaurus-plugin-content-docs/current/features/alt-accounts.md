**多帳號**讓您的團隊可以宣告多個 Discord 帳號屬於同一個人。其中一個帳號的[處罰](./sanctions.mdx)會延伸到其他帳號：被停權的成員無法再用第二個帳號回來規避處罰。

:::info 實驗：Identity Update
多帳號屬於預計於 3.7.0 版推出的 **Identity Update**。在正式推出之前，它處於實驗階段，為 [Premium](/zh-TW/premium) 伺服器提供公開測試版。
:::

## ❓ 運作方式 {#working}

- **一人一個群組**：群組會彙整您的團隊視為同一個人的帳號。群組專屬於您的伺服器：不會與其他伺服器共享任何內容。
- **共享處罰**（[Premium](/zh-TW/premium)）：停權、踢出、禁言、監禁和超時會依您為各項處罰所選的[模式](#modes)，延伸到群組中的其他帳號。處罰仍以被指定帳號的名義記錄，其他帳號則獲得其狀態。處罰絕不會延伸到負責管理伺服器的帳號（具有管理員、管理伺服器、停權成員、踢出成員或對成員設定超時權限的帳號）、伺服器擁有者以及機器人。沒有 Premium 時，帳號可以被關聯與查閱，但不會延伸任何處罰：此時處罰紀錄會列出該成員的其他帳號。
- **共同解除**：解除群組中任一帳號的處罰，不論是哪一個，都會解除所有帳號的處罰，無論有無 Premium。
- **群組搜尋**：[搜尋某個帳號的處罰](./sanctions.mdx#search)時，也會顯示群組中其他帳號的處罰。
- **Discord 的 AutoMod**：由 Discord AutoMod 施加的超時和禁言，同樣會延伸到關聯帳號。
- **由驗證碼發現**：[驗證碼的 Activity](./captcha.md#activity-alts) 可以自行關聯兩個確定是同一個人的帳號，或向您的團隊提議建立關聯。
- **紀錄**：關聯、移除以及主帳號的變更都會記錄在[管理紀錄](./moderation.mdx#logs)中。處罰紀錄會列出關聯帳號及其使用者名稱；採用嵌入格式時，還會附有「**關聯帳號**」按鈕，可開啟被處罰成員的 `/alt` 面板。

**限制**：群組中的帳號數量與群組數量皆無上限。一項處罰一次最多延伸到 **10 個關聯帳號**：其餘帳號會在下次發言或加入時受到處罰，而處罰下方的按鈕可立即處罰它們。

## 🔗 使用 /alt 關聯帳號 {#alt}

使用指令：```/alt [member] [other]```

- 不帶選項：顯示伺服器中已關聯帳號的群組清單。其中的「**關聯兩個帳號**」按鈕可關聯兩位伺服器成員，或透過 ID 關聯兩個不在伺服器中的帳號。
- 帶有 `[member]`：顯示該帳號的群組；若它未與任何其他帳號關聯，則只顯示該帳號本身。每個帳號都會顯示其狀態（已被伺服器停權、在伺服器中、不在伺服器中、隔離中），主帳號排在最前面。
- 帶有 `[member]` 和 `[other]`：直接關聯這兩個帳號，並宣告為同一個人。

如果群組中有帳號已被停權（[Premium](/zh-TW/premium)），關聯帳號會共用同一個停權：RaidProtect 會讓您選擇「**一併停權**」其他帳號、「**解除停權**」為所有帳號解除該停權，或「**稍後**」再決定。

將 `[member]` 和 `[other]` 替換為所需帳號的提及或 [ID](../guides/id.mdx)。機器人無法被關聯。

在群組的面板中：

- 「**關聯成員**」會將帳號加入群組：可以是伺服器成員，也可以是不在伺服器中的帳號的 Discord ID。
- 「**編輯群組中的帳號**」選單會開啟視窗，讓您將該帳號設為「**群組的主帳號**」或「**將此帳號移出群組**」。被移出的帳號不再被視為同一個人，但如果它已隨群組一併被停權，則仍維持停權。

您也可以在[管理檢視 `/modview`](./moderation.mdx#modview) 中，透過「**管理**」按鈕找到成員的關聯帳號。

:::info
`/alt` 指令及其按鈕需要**停權成員**權限。
:::

## 🛠️ 設定多帳號 {#config}

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**管理**」分頁。
3. 點擊「**多帳號**」旁的「**設定**」。

<Settings start="alts" />

### 關聯帳號的處罰 <span className="badge-premium">Premium</span> {#modes}

針對每項處罰，選擇它如何延伸到群組：

1. 在多帳號畫面中，點擊「**關聯帳號的處罰**」旁的「**編輯**」。
2. 在視窗中，為每項處罰選擇一種模式。

畫面上的「**全部設為…**」選單可一次將所有處罰套用相同的模式。

<SettingsModal name="altsModes" />

| 模式 | 效果 | 適用的處罰 |
|---|---|---|
| 「**立即**」*（預設）* | 停權：所有關聯帳號會立即被停權，無論是否在場。踢出：在伺服器中的關聯帳號也會被踢出。禁言、監禁和超時：在場的帳號立即受到處罰，其他帳號於加入時受罰。 | 全部 |
| 「**在場者立即，其他於加入時**」 | 在場的帳號立即被停權，不在場的帳號若在停權期間加入伺服器，也會被停權。 | 停權 |
| 「**陷阱**」 | 只處罰被指定的帳號。群組中的另一個帳號若在處罰期間加入或發言，會被視為規避，並受到[規避處罰](#evasion)。 | 除踢出以外的全部 |
| 「**停用**」 | 處罰只針對所選帳號。 | 全部 |

### 群組處罰 {#group-sanction}

當處罰延伸到多個帳號時，它在紀錄（[`/sanctions`](./sanctions.mdx#search)、`/modview`）中會顯示為**單一一筆群組處罰**（例如「**群組停權**」），並列出受影響的帳號（「**帳號**」）及各自的狀態。每個帳號仍保有自己的一行，標示為「屬於群組處罰」。取消、刪除或修改（原因、時長）群組處罰，會同時作用於所有帳號。成員只能在 `/my-sanctions` 中看到自己的那一行。

### 規避處罰 {#evasion}

規避處罰適用於「**陷阱**」模式下被抓到的關聯帳號：在其群組的處罰期間加入伺服器或在其中發言。

1. 在多帳號畫面中，點擊「**規避處罰**」旁的「**編輯**」。
2. 在視窗中，選擇「**處罰**」，必要時再選擇其「**時長**」。

<SettingsModal name="altsEvasion" />

- 「**沿用剩餘處罰**」*（預設）*：該帳號共享群組的處罰直到結束，不會另外以其名義施加處罰。
- **一項處罰**（停權、踢出、禁言、監禁或超時）：以其名義施加，有自己的時長，之後對整個群組生效。若該帳號離開伺服器後再加入，禁言或監禁會再次生效。將時長留空即為永久處罰（例如：`1h`、`3d`、`2w`）。

:::info
超時一律需要時長，最長 28 天。禁言和監禁則需要已設定其[角色](./sanctions.mdx#config)。
:::

### 每人僅限一個帳號 {#single-account}

此設定與驗證碼偵測一樣免費，啟用後，只有每個群組的**主帳號**可以在伺服器上活動。其他帳號會被以[監禁角色](./sanctions.mdx#jail)**隔離**（在紀錄中處罰為「**隔離**」）。若它們成為主帳號，或被移出群組，就會自行解除隔離。

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**管理**」分頁。
3. 點擊「**多帳號**」旁的「**設定**」。
4. 點擊「**每人僅限一個帳號**」旁的「**啟用**」。

:::info
此設定需要[監禁角色](./sanctions.mdx#jail)。若沒有，會跳出視窗讓您選擇「**啟用並設定 jail**」：設定會被啟用，角色一建立，次要帳號就會被隔離。
:::

若要變更群組的主帳號，請對其中一個帳號使用 `/alt`，然後使用「**編輯群組中的帳號**」選單。

## 常見問題 {#faq}

### 多帳號會在伺服器之間共享嗎？

不會。群組專屬於您的伺服器，不會與其他伺服器共享任何內容。

### 解除其中一個帳號的停權會怎樣？

解除其中一個帳號的處罰，會解除群組中所有帳號的處罰。

### 我可以關聯一個不在我伺服器上的帳號嗎？

可以。在 `/alt` 面板中，點擊「**關聯成員**」並輸入其 Discord ID。

### 誰可以使用 /alt？

擁有**停權成員**權限的成員，且在 Identity Update 處於實驗階段期間，需在 [Premium](/zh-TW/premium) 伺服器上使用。
