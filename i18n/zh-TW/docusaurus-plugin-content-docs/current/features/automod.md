RaidProtect 的 **Automod** 整合了多個過濾器，在不當內容發布時自動將其移除。每個過濾器都有針對訊息作者的專屬處罰。

開啟方式：

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**防護**」分頁。
3. 點擊「**Automod**」旁的「**設定**」。

## 🖼️ 詐騙圖片 {#images}

**圖片**過濾器會刪除已知的詐騙圖片（加密貨幣詐騙、假贈品活動、假賭場促銷），並處罰其作者。它**預設啟用**，無需任何設定。

完整的細節、處罰以及圖片目錄，請見[詐騙圖片](./scam-images.md)頁面。

## 🔗 其他伺服器 {#servers}

**其他伺服器**過濾器控制所有指向其他 Discord 伺服器的內容：**邀請**、**轉發訊息**、**頻道連結**和**活動連結**，以及您的成員所顯示的**伺服器標籤**。它能阻擋亂發的廣告以及競爭或惡意的伺服器，且不影響您的合作夥伴。

### 運作方式 {#servers-working}

三種行為可分別設定，各自採用下列其中一種模式：

- 「**停用**」：不過濾任何內容。
- 「**黑名單**」：清單中的伺服器會被拒絕，其他伺服器則放行。
- 「**白名單**」：只有清單中的伺服器會放行，其他一律拒絕。

| 行為 | 被拒絕時的結果 |
|---|---|
| **邀請** | 含有該邀請的訊息會被刪除。`ptb.` 與 `canary.` 連結同樣計入，藏在嵌入內容、元件或轉發訊息中的邀請也會被讀取，事後被編輯的訊息亦同。 |
| **轉發訊息或頻道連結** | 從該伺服器轉發的訊息，或含有指向其任一頻道或活動連結的訊息，會被刪除。 |
| **顯示的伺服器標籤** | 成員會被以[監禁角色](./sanctions.mdx#jail)**隔離**。當他移除標籤後，隔離即解除。 |

您自己的伺服器一律放行（無論使用它的哪一個邀請），且您的團隊（擁有**管理伺服器**或**管理訊息**權限）永遠不會被針對。

### 設定 {#servers-config}

1. 在 Automod 中，點擊「**其他伺服器**」旁的「**設定**」。
2. 使用右上角的開關啟用過濾器，然後為每種行為選擇一種模式。

<Settings start="serverRefs" />

#### 好友和群組邀請 <span className="badge-premium">Premium</span> {#servers-private}

好友或私人群組的邀請不會通往任何伺服器。在「**邀請**」模式下（只要不是「**停用**」），「**好友和群組邀請**」選單會單獨決定它們的處理方式：

- 「**遵循清單**」*（預設）*：黑名單下放行，白名單下刪除。
- 「**一律允許**」：無論清單為何，皆接受。
- 「**一律刪除**」：無論清單為何，皆刪除。

沒有 Premium 時，它們一律遵循清單。

:::tip
如果您離開一個已修改但尚未啟用的過濾器畫面，RaidProtect 會在您離開前提議啟用它（預設選取「**保持停用**」）。
:::

### 處罰 {#servers-sanction}

每則被拒絕的訊息都會被刪除。在「**被刪除訊息的處罰**」中，您可以另外為其作者選擇處罰，或選擇「**僅刪除訊息**」。若選擇超時、禁言、監禁或停權，還需選擇其時長。

處罰對每位成員每分鐘最多套用一次：連續貼上多個邀請的成員只會被處罰一次。

### 伺服器清單 {#servers-lists}

1. 點擊「**新增伺服器**」。
2. 貼上該伺服器仍然有效的邀請（例如 `discord.gg/example`）：會從中讀取它的名稱和 ID。不再接受單獨的 ID。
3. 選擇清單：黑名單或白名單。

已存在的伺服器只會切換到另一份清單。「**移除**」可從清單中移除一個或多個伺服器。

**限制**：兩份清單合計最多 25 個伺服器。

:::tip
若只想允許合作夥伴的邀請，請將「**邀請**」設為「**白名單**」，並將您的合作夥伴加入白名單。空的白名單會拒絕所有指向其他伺服器的邀請。
:::

### 紀錄 {#servers-logs}

每次處罰和每次隔離都會記錄在您的[管理紀錄](./moderation.mdx#logs)中，並註明相關的伺服器和頻道。僅刪除訊息而不處罰（「**僅刪除訊息**」）時同樣會被記錄。處罰會出現在[處罰紀錄](./sanctions.mdx)中，原因為「已拒絕其他伺服器的邀請」、「被拒絕的好友或群組邀請」（Premium）、「已拒絕其他伺服器的轉發訊息或頻道連結」或「已拒絕其他伺服器的標籤」。

## 📎 副檔名 {#files}

**副檔名**過濾器會刪除副檔名被拒絕的檔案。您可以封鎖特定副檔名（黑名單），或只允許特定副檔名（白名單），套用於整個伺服器或逐一頻道設定。您的團隊（擁有**管理伺服器**或**管理訊息**權限）永遠不會被針對。

轉發訊息中的檔案同樣計入，討論串則沿用其所屬頻道的規則。

### 設定 {#files-config}

1. 在 Automod 中，點擊「**副檔名**」旁的「**設定**」。
2. 使用右上角的開關啟用過濾器。
3. 在「**整個伺服器**」下選擇一種模式：「**停用**」、「**黑名單**」或「**白名單**」。
4. 勾選**群組**（執行檔、圖片、影片、音訊、壓縮檔、文件），和/或輸入以逗號分隔的其他副檔名，例如 `exe, msi`。點號可省略。除了群組之外，一條規則最多可接受 50 個自訂副檔名。

:::warning
沒有任何副檔名的白名單不接受任何檔案：所有傳送的檔案都會被刪除。
:::

### 依頻道與分類設定規則 {#files-channels}

點擊「**新增頻道**」，即可為頻道、討論串或分類設定規則。分類的規則適用於其下所有頻道。

規則會疊加，但若某個副檔名被多條規則提及，則由**最精確**的規則決定（頻道，其次分類，最後伺服器）。例如，在某個頻道中被允許的 `.exe`，即使伺服器設有黑名單也會放行。沒有任何規則提及的副檔名，在所有規則下皆放行。

| | 免費 | <span className="badge-premium">Premium</span> |
|---|---|---|
| **頻道規則** | 1 條（第一個設定的頻道） | 20 個頻道或分類 |
| **分類規則** | 否 | 是 |

沒有 Premium 時，超出的規則會保留，但不會生效。

### 損毀的檔案 {#files-disguised}

被改名以偽裝成圖片或影片的檔案（例如被改名為 `.png` 的 `.exe`）會被辨識出來：Discord 無法將其當作真正的圖片讀取。白名單一律會拒絕它。「**一律拒絕損毀的檔案**」選項會在所有頻道中刪除它，即使沒有白名單也一樣。

### 處罰 {#files-sanction}

每個被拒絕的檔案都會連同其訊息一起被刪除。在「**被刪除訊息的處罰**」中，您可以另外為其作者選擇處罰，或選擇「**僅刪除訊息**」。處罰對每位成員每分鐘最多套用一次。

每則被刪除的訊息都會記錄在您的[管理紀錄](./moderation.mdx#logs)中，並註明相關的檔案、頻道與副檔名。處罰會出現在[處罰紀錄](./sanctions.mdx)中，原因為「被拒絕副檔名的檔案」。

## 常見問題 {#faq}

### 我的合作夥伴還能分享他們的邀請嗎？

可以。將他們加入其他伺服器過濾器的白名單，或不要把他們列入黑名單。

### 當成員移除被拒絕的標籤時會怎樣？

他的隔離會自動解除。

### 管理人員也會被過濾嗎？

不會。擁有管理伺服器或管理訊息權限的成員永遠不會被其他伺服器過濾器針對。
