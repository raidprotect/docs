RaidProtect 的**加入鎖定**（join lock）功能會關閉新成員加入伺服器的通道，直到您將其停用為止，突破了 Discord 原生功能的限制：Discord 只能透過「暫停加入」網路安全動作阻擋 24 小時。

## 🚦 使用情境與建議 {#recommendations}

- **私人與封閉的伺服器**：加入鎖定特別推薦給需要保持私密、不希望有任何新成員加入的伺服器（企業伺服器、小型團隊、私人群組）。
- **工作人員伺服器**：適用於專為管理或行政團隊設立、只有獲授權成員才能進入的伺服器。
- **企業或專業伺服器**：適用於在內部使用 Discord、並希望確保只有現任員工能進入伺服器的組織。
- **規模有限的社群**：適用於已達到理想規模上限、希望永久不再接受新成員的伺服器。

## ❓ 加入鎖定的運作方式 {#working}

只要加入鎖定處於啟用狀態，RaidProtect 就會對新成員套用您為 Auto RaidMode 所選的[突襲期間處理方式](./raid-mode.md#action)。與 Discord 原生功能需要每 24 小時手動續期不同，此阻擋會在無需介入的情況下持續生效，直到您將其停用。

| 突襲期間的處理方式 | 加入鎖定的效果 |
|---|---|
| 「**封鎖邀請**」（預設） | 伺服器的邀請會被停用：沒有任何新人能進入。 |
| 「**踢出新加入的成員**」（[Premium](/zh-TW/premium)） | 每位新成員都會被踢出，並收到一則私訊，告知目前已關閉加入。 |
| 「**傳送驗證碼**」 | 新成員**在解答[驗證碼](./captcha.md)後即可進入**：因此伺服器並未關閉。 |
| 「**突襲期間凍結驗證碼**」 | 只要加入鎖定處於啟用狀態，新成員就會被擋在驗證碼之後等待。 |

:::warning
若伺服器需要真正保持封閉，請選擇「**封鎖邀請**」、「**踢出新加入的成員**」或「**突襲期間凍結驗證碼**」。若選擇「**傳送驗證碼**」，加入鎖定只會對新成員要求通過驗證碼。
:::
:::info
已在伺服器中的成員仍保持活躍，可以繼續正常使用伺服器。只要加入鎖定處於啟用狀態，[歡迎訊息](./onboarding.md#welcome-message)就不會發送。
:::
:::warning
使用「**封鎖邀請**」處理方式時，Discord 的社群功能是加入鎖定不可或缺的條件。[請參考我們的指南，確認您的伺服器已啟用社群。](../guides/community.md)其他處理方式無需啟用社群即可運作。
:::

## 🚩 設定加入鎖定 {#config}

使用指令：```/joinlock [status]```

- 若不帶選項，該指令會顯示加入鎖定的狀態，並附上「**啟用**」或「**停用**」按鈕。
- 將 `[status]` 替換為 **True** 可直接啟用，替換為 **False** 可直接停用。

![/joinlock 指令的截圖](../../../../en/docusaurus-plugin-content-docs/current/assets/rp-join-lock.webp)

此指令需要**管理伺服器**權限，且每次狀態變更時，紀錄頻道都會發布一則訊息。

:::info
`joinlock` 指令[可使用前綴執行](../guides/prefix.md)。只要加入鎖定處於啟用狀態，[`/raidmode` 指令](./raid-mode.md#enable)就無法使用：請先停用加入鎖定。
:::

## 常見問題 {#faq}

### 與突襲模式有什麼差別？

[突襲模式](./raid-mode.md)是暫時性的（最長 24 小時），並且可以在一波突襲期間自動啟動。加入鎖定則由手動啟用，並會持續生效，直到您將其停用。

### 需要啟用 Discord 社群嗎？

只有當 Auto RaidMode 的突襲期間處理方式為「**封鎖邀請**」時才需要。若採用其他處理方式，加入鎖定無需啟用社群即可運作。

### 新成員還能進入嗎？

使用「**封鎖邀請**」、「**踢出新加入的成員**」或「**突襲期間凍結驗證碼**」時不能。使用「**傳送驗證碼**」時，他們在解答驗證碼後即可進入。
