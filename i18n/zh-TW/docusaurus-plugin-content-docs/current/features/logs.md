**伺服器紀錄**會記下您伺服器上發生的事：誰建立了頻道、修改了身分組、刪除了訊息，或將成員從語音頻道中斷連線。每則紀錄都以執行者開頭（「@管理員 建立了頻道 #一般。」），並顯示修改前後的內容。

:::info 實驗：Logging Update
伺服器紀錄屬於 **Logging Update**，預計於 3.8.0 版推出。在正式推出之前，它處於實驗階段，為 [Premium](/zh-TW/premium) 伺服器提供公開測試版。
:::

## ⚙️ 設定紀錄 {#config}

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**管理**」分頁。
3. 點擊「**紀錄**」旁的「**設定**」。
4. 開啟「**伺服器紀錄**」，然後為每個類別選擇一個頻道。

每個類別都有兩份清單：

- **發送的類型**：取消勾選某個類型，就不會再將它發送到任何地方。
- **發送到其他頻道的類型**：為某個類型指定獨立的頻道。沒有獨立頻道的類型會沿用其類別的頻道。

**限制：**免費版最多 3 個不同的紀錄頻道，[Premium](/zh-TW/premium) 最多 15 個。沒有 Premium 時，只有前 3 個頻道會收到紀錄：其他頻道會暫停，其設定則會保留。

[管理紀錄](./moderation.mdx#logs)的「**一般**」、「**管理**」和「**驗證碼**」頻道維持不變。

## 📚 紀錄類別 {#families}

| 類別 | 記錄的內容 |
| --- | --- |
| **頻道、身分組與邀請** | 建立、修改或刪除的類別、頻道、語音頻道與討論串，包含權限。身分組、邀請、Webhook、整合，以及新增或移除的機器人與其身分組。 |
| **成員** | 加入（附帳號年齡）與離開（附加入日期與身分組）、接受規則、新增或移除的身分組、暱稱、被移除的不活躍成員，以及加成。 |
| **訊息** | 刪除的訊息（附刪除者）、修改的訊息、大量刪除，以及釘選或取消釘選的訊息。 |
| **語音** <span className="badge-premium">Premium</span> | 加入、離開（附工作階段時長）、切換頻道、麥克風、聲音、鏡頭與螢幕分享。工作人員的動作（靜音、拒聽、移動、中斷連線）會另外記錄，並附上執行者。 |
| **表情符號與反應** | 建立、修改或刪除的表情符號、貼圖與音效板音效。新增或移除的反應僅限 [Premium](/zh-TW/premium)，且預設為取消勾選。 |

修改的訊息會顯示修改前後的內容。若是長訊息，只會顯示有變更的行。

由 RaidProtect 本身刪除的訊息（Antispam、HoneyPot、反詐騙、`/clear`）會保留在相關模組的紀錄中，不會重複記錄。

## 🎨 紀錄格式 {#format}

在同一個畫面的「**紀錄格式**」中選擇格式。

| 格式 | 顯示方式 |
| --- | --- |
| **預設** | 時間、圖示、附名稱的提及，接著是詳細內容。 |
| **嵌入** | 每則紀錄一個彩色區塊，附標題與詳細內容。 |
| **精簡** <span className="badge-premium">Premium</span> | 每則紀錄一行：時間、圖示與提及。 |

失去 Premium 的伺服器會改回預設格式。其選擇會保留，待恢復 Premium 時沿用。

## 💾 記憶體中的訊息 {#cache}

為了找回已刪除訊息的內容，RaidProtect 會將近期訊息保留在記憶體中：免費版 **15 分鐘**，[Premium](/zh-TW/premium) 則為 **6 小時**。超過這段時間，紀錄會註明內容未被保留。

有了 Premium，已刪除訊息的附件也會複製到紀錄中（每個檔案 10 MB，每個伺服器 100 MB，最舊的會優先被取代）。
