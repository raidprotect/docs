RaidProtect 的**歡迎功能**會在新成員加入您的 Discord 伺服器時立即照顧他們：一則附有他們專屬卡片的**歡迎訊息**、**自動身分組**，以及能將專為此目的而建立的帳號（常用於[突襲](/zh-TW/learn/discord-raid)）擋在門外的**帳號最短註冊時長**。這三項設定位於 `/settings` 的「**新成員加入**」分頁，與[驗證碼](./captcha.md)和 [Auto RaidMode](./raid-mode.md) 並列。

## ❓ 運作方式 {#working}

當使用者加入您的伺服器時，在他獲准進入前，會依序套用[突襲模式](./raid-mode.md#action)、[帳號最短註冊時長](#minage)，然後是[驗證碼](./captcha.md)。獲准後，他會收到[自動身分組](#autorole)和[歡迎訊息](#welcome-message)。

## 👋 歡迎訊息 {#welcome-message}

當成員獲准進入伺服器時，歡迎訊息會發送到您選擇的頻道。它包含您的文字以及為每位成員產生的**歡迎卡片**：他的頭像、「歡迎來到」加上伺服器名稱，以及他的成員編號。

<Settings start="welcome" />

### 啟用歡迎訊息 {#welcome-config}

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**新成員加入**」分頁。
3. 點擊「**歡迎訊息**」旁的「**設定**」。
4. 在「**歡迎頻道**」中，選擇要發送訊息的文字頻道。選擇頻道即會啟用該訊息。

畫面右上角的開關可啟用或停用歡迎訊息。畫面下方會顯示訊息預覽，並會在每次修改時更新。

:::info
歡迎頻道不能是驗證碼、監禁、HoneyPot 或 DISCON 的頻道。如果頻道被刪除，該設定會被清空。
:::

### 文字與變數 {#welcome-text}

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**新成員加入**」分頁。
3. 點擊「**歡迎訊息**」旁的「**設定**」。
4. 在「**訊息內容**」中，點擊「**文字**」。
5. 撰寫您的訊息（最多 1,200 個字元），然後確認。將欄位留空可恢復為預設訊息。

<SettingsModal name="welcomeText" />

預設文字為「歡迎 `{user.mention}` 來到 **`{server.name}`**！🎉」，使用伺服器的語言。您可以使用以下變數：

| 變數 | 替換為 |
|---|---|
| `{user.mention}` | 成員的提及 |
| `{user.name}` | 其使用者名稱 |
| `{user.displayname}` | 其顯示名稱 |
| `{user.id}` | 其 [ID](../guides/id.mdx) |
| `{server.name}` | 伺服器名稱 |
| `{server.member_count}` | 伺服器的成員數 |
| `{server.id}` | 伺服器 ID |

### 提及成員 {#welcome-mention}

預設啟用的「**提及成員**」選項，會在新成員的歡迎訊息發布時通知他。它只會提及新加入者，絕不會提及 @everyone 或角色。

### 按鈕 {#welcome-buttons}

您可以在訊息下方新增按鈕，連結到伺服器中的某個頻道，例如「閱讀規則」。

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**新成員加入**」分頁。
3. 點擊「**歡迎訊息**」旁的「**設定**」。
4. 在「**管理按鈕**」中，選擇「**新增按鈕**」。
5. 為按鈕命名、選擇要連結的頻道，並可視需要選擇一個**表情符號**：標準表情符號，或此伺服器的表情符號（`<:name:id>`、`:name:` 或其 ID）。無效的表情符號不會妨礙儲存：按鈕會在沒有表情符號的情況下建立。

若要編輯或刪除按鈕，請在同一份清單中選取它。

**限制**：免費版 2 個按鈕，[Premium](/zh-TW/premium) 版 4 個按鈕。若 Premium 到期，只會保留顯示前 2 個按鈕。

### 顏色 <span className="badge-premium">Premium</span> {#welcome-color}

使用 [Premium](/zh-TW/premium) 時，在「**訊息內容**」中點擊「**顏色**」，即可選擇訊息左側色條的顏色：清單中的 RaidProtect 顏色，或十六進位色碼（例如 `#D35F5F`）。若未選擇，且您已[自訂](/zh-TW/premium)機器人的暱稱顏色，訊息就會沿用該顏色，否則使用預設顏色。歡迎卡片也會染上相同的顏色。

### 人潮湧入與突襲 {#welcome-raid}

- **分組**：當大量成員同時加入時，加入通知會被合併，避免洗版頻道。
- **突襲期間暫停**：只要 RaidProtect 的[突襲模式](./raid-mode.md)或[加入鎖定](./join-lock.mdx)處於啟用狀態，就不會發送任何歡迎訊息。

## 🏷️ 自動身分組 {#autorole}

自動身分組會在每位新成員加入時立即授予；若已啟用[驗證碼](./captcha.md)，則在通過驗證碼後授予。它們取代了驗證碼舊有的自動身分組，原本的設定已自動沿用。

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**新成員加入**」分頁。
3. 點擊「**自動身分組**」旁的「**設定**」。
4. 選擇一個或多個角色。

若要移除所有自動身分組，請點擊「**重置**」。

<Settings start="autorole" />

**限制**：免費版 3 個角色，[Premium](/zh-TW/premium) 版 10 個角色。

:::warning
請避免帶有權限的角色：自動授予的角色不應賦予任何權力。RaidProtect 會拒絕由整合管理的角色、位階高於它或高於您的角色，以及帶有管理權限的角色：所選的角色中可接受的會被保留，另有一則訊息說明其他角色被拒絕的原因（若全部被拒絕，原有的設定維持不變）。如果所選角色之後獲得了權限，它也會發出警示。
:::
:::info
如果您的伺服器使用其他機器人來授予自動身分組，它可能會在驗證碼之前就授予角色。請改用 RaidProtect 的自動身分組。
:::

## 🤖 機器人加入 {#bots}

預設情況下，加入伺服器的機器人會像成員一樣獲得[自動身分組](#autorole)。「**新成員加入**」分頁中的「**機器人**」區段可以改變這一點。

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**新成員加入**」分頁。
3. 點擊「**機器人**」旁的「**設定**」。

- **機器人角色**：授予每個加入的機器人，**取代**自動身分組。若未選擇角色，機器人會獲得自動身分組。**限制：**免費版 1 個角色，[Premium](/zh-TW/premium) 版 15 個角色。與自動身分組相同的限制同樣適用（由整合管理的角色、位階高於您或高於 RaidProtect 的角色，或帶有管理權限的角色）。
- **踢出未經授權的機器人**：任何新加入的機器人都會立即被踢出，除非擁有者事先已使用 `/bypass bot` 指令授權。預設為停用。**只有伺服器擁有者**可以啟用或停用此選項，以及授權機器人。

### 授權機器人 {#bypass-bot}

使用指令：```/bypass bot [bot]```

將 `[bot]` 替換為要授權的機器人：它可以在接下來的 10 分鐘內加入伺服器**一次**，而不會被踢出。若未指定機器人，指令會列出目前已授權的機器人。每次授權都會記錄在您的紀錄中。

:::info
RaidProtect 需要「**踢出成員**」權限，以及位階高於該機器人的角色，才能將其踢出。否則，紀錄中會註明此情況，且該機器人會留下。
:::

## 🎂 帳號最短註冊時長 {#minage}

為了加強安全性，您可以對新成員的 Discord 帳號要求最短註冊時長。就在突襲前才建立的帳號會被擋在門外。此過濾器適用於每一次加入。

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**新成員加入**」分頁。
3. 點擊「**帳號最短註冊時長**」旁的「**設定**」。
4. 在「**帳號最短註冊時長**」中，選擇 2 小時、12 小時、1 天或 2 天，或選擇「**自訂值**」（例如 `0y 3d 1h`，最長 10 年）。
5. 在「**處理方式**」中，選擇對過新帳號的處理方式。

若要停用過濾器，請點擊「**重置**」。RaidProtect 需要 `KICK_MEMBERS` 權限。

<Settings start="minage" />

### 處理方式 {#minage-action}

| 處理方式 | 對過新帳號的效果 |
|---|---|
| 「**踢出**」（預設） | 只要帳號仍然過新，每次嘗試加入都會被踢出。 |
| 「**隔離至達到要求**」 | 他進入後看不到伺服器的任何內容（透過[監禁角色](./sanctions.mdx#jail)），達到要求的年齡後，就會在註明的日期解除隔離。 |
| 「**攔在入口**」 | 他被卡在[驗證碼](./captcha.md)上，帳號達到年齡後才能解答。 |

該帳號會收到一則私訊，告知他何時能存取伺服器。踢出、隔離和停權都會記錄在紀錄頻道中。

:::info
- 「**隔離至達到要求**」需要設定監禁角色，位於「**管理**」分頁 >「**處罰**」。若沒有監禁角色，RaidProtect 會提議您進行設定，或改用「**封鎖至達到要求**」：帳號會離開伺服器，其停權會在正確的日期自動解除。
- 「**攔在入口**」需要已啟用且處於**面板（互動）**模式的驗證碼。
:::

### 🎫 帳號最短註冊時長繞過 {#bypass-minage}

使用指令：```/bypass minage [user]```

將 `[user]` 替換為所需的 [ID](../guides/id.mdx)，該使用者將有 10 分鐘的時間加入伺服器，而不會被年齡要求擋下。您也可以不指定使用者來使用此指令，以查看目前的繞過使用者清單。它也會解除過新帳號的隔離。`/unjail` 不會解除隔離：它會指出應使用的指令。

## 常見問題 {#faq}

### 歡迎訊息何時發送？

在成員獲准進入時：若驗證碼不適用，則在加入時立即發送，否則在通過驗證碼後發送。突襲期間或加入鎖定期間不會發送。

### 可以移除歡迎卡片嗎？

不行，歡迎卡片會附在每則歡迎訊息上。使用 Premium 時，您可以變更其顏色。

### 可以授予多少個自動身分組？

免費版 3 個，Premium 版 10 個。帶有管理權限的角色會被拒絕。

### 自動身分組會在驗證碼之前授予嗎？

不會。當驗證碼適用於該成員時，他的自動身分組會在通過驗證碼後授予。

### 該選擇多長的最短註冊時長？

幾個小時到 1 天的值，就足以擋掉大多數為突襲而建立的帳號，又不會妨礙真正的成員。[`/setup` 指令](../setup.md)預設設定為 6 小時。

### 過新的帳號會被停權嗎？

預設不會：他每次嘗試都會被踢出。您也可以將他隔離至達到要求的年齡，或將他留在驗證碼之後。暫時停權只是在未設定監禁角色時的退路。
