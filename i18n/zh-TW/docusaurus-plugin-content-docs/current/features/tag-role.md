標籤角色可自動為將[您的伺服器標籤](https://support.discord.com/hc/zh-tw/articles/31444248479639-%E4%BC%BA%E6%9C%8D%E5%99%A8%E6%A8%99%E7%B1%A4)加入其 Discord 個人檔案的成員指派角色。為這些成員指派角色，能肯定他們的投入，並鼓勵他們積極代表您的伺服器。這是一個簡單卻有效的方式，既能強化集體認同，也能獎勵社群中最忠實的大使。

## ❓ 標籤角色的運作方式 {#working}

運作方式很簡單。只要成員在其 Discord 個人檔案上加入伺服器標籤，RaidProtect 就會自動為他指派一個特定角色。
如果成員移除標籤，該角色也會被移除。

我們會在成員下次個人檔案更新時（暱稱、頭像、橫幅、角色、標籤……）偵測到這項變更。

:::info
如果標籤未啟用，或您的伺服器尚未擁有此功能，標籤角色將不會有任何作用。
:::

## 🎖️ 設定標籤角色 {#config}

只需幾下點擊即可完成設定：
1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**工具**」分頁。
3. 點擊「**標籤角色**」旁的「**設定**」。
4. 在選單中選擇現有角色，或點擊「**幫我建立一個**」：我們會建立一個不含任何權限的 `標籤` 角色。
5. 您隨時可以點擊「**重置**」按鈕來停用標籤角色。

標籤角色的每次設定變更都會記錄在您的伺服器紀錄中。

### /tagrole 指令 {#command}

使用指令：```/tagrole```

它會直接開啟標籤角色的設定畫面，無需經過 `/settings`。僅限擁有「**管理角色**」權限的成員使用。

### 被拒絕的角色 {#refused-roles}

標籤角色會自動給予任何成員，因此我們會拒絕可能造成問題的角色。

- **RaidProtect 已在使用的角色**：監禁角色、禁言角色、驗證碼的驗證角色或自動身分組。
- **由應用程式或伺服器加成所管理的角色**：Discord 禁止手動指派。請改為建立一個一般角色。
- **位階高於 RaidProtect 角色的角色**：請在**伺服器設定 > 角色**中，將 RaidProtect 的角色拖曳到更高處。
- **位階高於您自己最高角色的角色**（伺服器擁有者除外）。
- **含有敏感權限的角色**：管理員、停權成員、踢出成員、管理伺服器、頻道、訊息、角色、Webhook、表情符號與貼圖、活動或討論串。

### 警示區塊 {#warnings}

當標籤角色無法運作時，設定畫面會提醒您：

- **缺少權限**：RaidProtect 需要「**管理角色**」權限。`/settings` 工具分頁中「**標籤角色**」旁也會顯示 ⚠️ 警示。
- **伺服器標籤未啟用**：您的伺服器尚未啟用[伺服器標籤](https://support.discord.com/hc/zh-tw/articles/31444248479639-%E4%BC%BA%E6%9C%8D%E5%99%A8%E6%A8%99%E7%B1%A4)功能，因此標籤角色目前沒有任何作用。

修正後，請點擊「**重新整理**」再次檢查。

## 常見問題 {#faq}

### 為什麼佩戴標籤的成員還沒有獲得角色？

我們會在成員下次個人檔案更新時偵測標籤。只要他沒有修改任何內容（暱稱、頭像、角色、標籤……），就不會被指派角色。如有需要，支援團隊可以執行完整同步。

### 為什麼我的角色被拒絕？

標籤角色不能是 RaidProtect 已在使用的角色、由應用程式管理的角色、位階高於 RaidProtect 或您自己的角色，也不能是含有敏感權限的角色。

### 誰可以設定標籤角色？

管理員可透過 `/settings` 設定，而擁有「管理角色」權限的成員可透過 `/tagrole` 指令設定。
