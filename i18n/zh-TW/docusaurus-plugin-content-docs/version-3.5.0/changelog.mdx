## 3.7.0 Identity Update <span className="badge-experiment">實驗</span> {#3-7-0}

:::info 實驗
Identity Update 處於實驗階段：在 3.7.0 正式推出之前，它為 [Premium](/zh-TW/premium) 伺服器提供公開測試版。其內容仍可能變動。
:::

- 新增 [`/alt`](./features/alt-accounts.md#alt) 指令與[多帳號](./features/alt-accounts.md)：關聯同一個人的帳號，選擇其主帳號，其處罰（停權、踢出、禁言、監禁、超時、軟停權）會延伸到關聯帳號。解除其中一個的處罰，就會解除所有帳號的處罰。 <SuggestionLink id="404" /> <SuggestionLink id="263" />
- [關聯帳號的處罰](./features/alt-accounts.md#modes)可依類型設定，並提供**陷阱**模式，以及針對在處罰期間加入或發言的關聯帳號的[規避處罰](./features/alt-accounts.md#evasion)。
- 不在伺服器中的關聯帳號，會在其加入時受到處罰。
- 新增[每人僅限一個帳號](./features/alt-accounts.md#single-account)設定：次要帳號會被隔離。
- [驗證碼](./features/captcha.md#activity-alts)能偵測多帳號：它會自行關聯確定是同一個人的帳號，並向您的團隊提議可能的關聯。
- [關聯帳號的處罰](./features/alt-accounts.md#modes)僅限 **Premium**。沒有 Premium 時，`/alt` 仍可無限制地關聯與查閱帳號。

## 3.6.0 Shield Update <span className="badge-experiment">實驗</span> {#3-6-0}

:::info 實驗
Shield Update 處於實驗階段：在 3.6.0 正式推出之前，它為 [Premium](/zh-TW/premium) 伺服器提供公開測試版。其內容仍可能變動。
:::

- 新增 [**DISCON**](./features/discon.md)：分為五級的伺服器危險等級，可透過 `/discon` 指令或[團隊專用面板](./features/discon.md#panel)一鍵調整。每個等級都會自動強化伺服器（驗證、驗證碼、私訊鎖定、突襲模式、鎖定），且[語音頻道](./features/discon.md#voice)會顯示目前的等級。
- 新增[預防性慢速模式](./features/slowmode.md)（**Premium**）：所選頻道的慢速模式會自動調整，以維持您所設定的訊息流量。
- [HoneyPot](./features/honeypot.md)：新增[處罰前延遲](./features/honeypot.md#grace)，讓出於善意的成員有時間表示自己搞錯了。
- 新增驗證碼的[智慧觸發方式](./features/captcha.md#trigger)：除了突襲之外，它也會驗證帳號看起來可疑的新加入者。
- [Automod](./features/automod.md) 新增[其他伺服器](./features/automod.md#servers)過濾器：其他伺服器的邀請、轉發訊息、頻道連結與標籤，支援黑名單或白名單。
- 新增**隔離**處罰，與 [Discord 的隔離](./features/sanctions.mdx#discord-quarantine)同步。
- [ScamLens](./features/scam-images.md)：[圖片目錄](./features/scam-images.md#catalog)（**Premium**），用於封鎖您自己的詐騙圖片。
- 每則被 Discord AutoMod 攔截的訊息，都會以「Discord Automod」的名義建立一個靜默的[警告](./features/sanctions.mdx)。
- 新的[安裝精靈](./setup.md#wizard)：逐區段的引導式流程、依您的伺服器提議的防護，並以稽核預覽作結。
- [Antispam](./features/anti-spam.mdx) V3，自 3.5.0 起已對所有人啟用：
  - 新的偵測引擎：近似重複、重複連結、表情符號與亂碼、洗版，以及散布在多個頻道的垃圾訊息。
  - [預設組合](./features/anti-spam.mdx#presets)與依類別設定的處罰，並提供[進階模式](./features/anti-spam.mdx#advanced)來設定每個觸發器及其[時長](./features/anti-spam.mdx#duration)。

## 3.5.0 Onboarding Update (2026/10/19) {#3-5-0}

- [**`/settings`**](./setup.md#settings) 全面改版：五個分頁的儀表板（一般、新成員加入、防護、管理、工具），採用 Discord 的新介面（Components V2），需要輸入文字的設定則使用輸入視窗。**新**標記會標示新增的設定。[Premium](/zh-TW/premium) 設定仍然看得到：只有修改時才需要 Premium。 <SuggestionLink id="583" />
- 新成員加入：
  - 新增[歡迎訊息](./features/onboarding.md#welcome-message)，包含印有成員名稱的歡迎卡片、變數與按鈕。只要突襲模式或加入鎖定處於啟用狀態，就不會發送，以免歡迎突襲的帳號。 <SuggestionLink id="110" />
  - [自動身分組](./features/onboarding.md#autorole)現在有獨立的設定，與驗證碼的設定分開，並可接受多個身分組。它們會在驗證通過後授予。 <SuggestionLink id="586" /> <SuggestionLink id="166" />
  - [帳號最短註冊時長](./features/onboarding.md#minage)提供[多種處理方式](./features/onboarding.md#minage-action)：踢出太新的帳號、將其監禁至達到要求的年齡，或將其卡在驗證碼上，直到帳號達到要求的年齡才能解答。 <SuggestionLink id="555" />
  - 您可以選擇 [Auto RaidMode](./features/raid-mode.md#action) 在突襲期間的處理方式：封鎖邀請、踢出新加入的成員（**Premium**）、將他們送往驗證碼，或讓他們在驗證碼等候，直到突襲結束。只有封鎖邀請仍需要伺服器啟用 Discord 社群。
  - [驗證碼](./features/captcha.md)新增面板[顯示模式](./features/captcha.md#display-mode)，以及自動或始終的[觸發方式](./features/captcha.md#trigger)。其設定會提示可繞過驗證的頻道與角色，並附有修正按鈕。
  - 在面板模式下，驗證碼[不必離開 Discord 即可開啟](./features/captcha.md#activity)：對自動程式更困難的謎題，採用您伺服器的色調。若結果有疑慮，您的團隊會收到報告，並決定是否讓該成員進入。
  - 新增[測試模式](./features/captcha.md#test-mode)：您的團隊可以親自完成驗證碼來試用，而不會套用任何處置。
- 防護：
  - [Authentification Manager](./features/authentication-manager.mdx) 現在於 `/settings` 中設定，其驗證頁面已翻譯。
  - [私訊鎖定](./features/dm-lock.mdx)可在輸入視窗中設定。
- 管理：
  - 新增 [`/onduty`](./features/moderation.mdx#onduty) 指令與在勤角色，用以標示有空的管理人員。
  - 新增 [`/display staff`](./features/display.mdx#staff) 面板，可發布在您的管理團隊頻道：領取身分組、進入在勤狀態、常用指令提醒。
  - 未指定使用者時，`/discord-sanctions` 會顯示全球統計。
- 工具：
  - 新增 [`/inviteinfo`](./features/utilities.mdx#inviteinfo) 指令。`/userinfo` 與 `/inviteinfo` 也可安裝到您的帳號，讓您隨處使用。
  - 新增 [`/privacy`](./features/utilities.mdx#privacy) 指令，以及新的**訊息快取**設定，[`/snipe`](./guides/malfunctions.md#snipe) 需要它才能找回已刪除的訊息。
  - 當您回報 Antispam 問題時，[`/feedback`](./features/utilities.mdx#feedback) 會提供診斷。
- 一般：
  - RaidProtect 現在支援 [11 種語言](./language.md)，新增了義大利文、土耳其文、越南文、日文以及簡體與繁體中文。預設會[跟隨伺服器語言](./language.md#follow)。 <SuggestionLink id="575" /> <SuggestionLink id="585" />
  - 新增伺服器的[時區](./setup.md#timezone)，供透明度彙總使用。
  - [訊息指令](./guides/prefix.md)與其[權限](./guides/prefix.md#permissions)在兩個獨立的畫面中設定。在 Discord 中設定的指令權限（整合）也會套用到「處罰使用者」選單中的處罰（在成員上按右鍵）。
  - [機器人自訂](./setup.md#customize)（**Premium**）現在於 `/settings` 中設定。
- 各項修正與翻譯修正。

## 3.4.0 Antispam Update (2026/07/18) {#3-4-0}

- [Antispam](./features/anti-spam.mdx) V2：
  - **多頻道垃圾訊息**：當垃圾訊息擴散到多個頻道時，會有專屬的處罰（預設為監禁，最低為超時）。
  - 新增**附件垃圾訊息**[觸發器](./features/anti-spam.mdx#triggers)（預設停用）。
  - [模擬](./features/anti-spam.mdx#simulation)功能，用以理解垃圾訊息為何被處罰或未被處罰。
  - 垃圾訊息現在**無論採用何種處罰**（停權、監禁、禁言、踢出或超時）都會被**刪除**。
  - **反詐騙處罰可以設定**，位於 [Antispam 的處罰選單](./features/anti-spam.mdx#triggers)，預設沿用 [HoneyPot 的處罰](./features/honeypot.md#sanction)；反詐騙事件會被即時處罰並記錄。 <SuggestionLink id="573" />
  - 每個觸發器現在都可以透過新的**停用**選項個別停用，且敏感度等級已由簡單的開關取代。
  - 當未設定對應的角色時，**禁言**與**監禁**處罰會改用有上限的超時。
  - 能偵測傳送 rich embed 的 selfbot，且被 ScamLens 攔截的詐騙會計入 [HoneyPot](./features/honeypot.md) 的被檢舉帳號計數器。
- [**檢舉**](./features/reports.md)系統全面改版： <SuggestionLink id="503" />
  - 檢舉現在會歸入**事件**：針對同一成員的多個檢舉會合併為單一事件，並提供[可設定的分組模式](./features/reports.md#group)。
  - 檢舉指令現在會開啟**原因視窗**，在個人檔案檢舉中有「您檢舉的是什麼」清單（包含語音與私訊活動）。
  - 每個事件現在都會在檢舉下方開啟一個**討論串**：被檢舉成員的個人檔案卡、各訊息的原因標題、處理的管理人員名稱，以及駁回備註。
  - 新增[檢舉者通知](./features/reports.md#notify)：檢舉被處理時，可透過私訊通知檢舉者，詳細程度可設定（最詳細可到受理／駁回的結果）。 <SuggestionLink id="550" />
  - 新增[信任角色](./features/reports.md#trusted-role)（**Premium**）：受信任的成員在檢舉時可施加**24 小時的預防性超時**，且其緊急檢舉會再次提及管理角色。
  - 新增[防範惡意檢舉者](./features/reports.md#bad-reporters)的保護：屢次提出虛假檢舉的人可以被發現、封鎖或自動處罰（閾值、時間範圍與模式皆可設定）。
  - 當成員受到處罰時，進行中的事件會自動關閉。
  - 當檢舉被受理時，預防性處罰會被改寫；當檢舉被駁回時，則會被取消。
- 全新的[**透明度**](./features/transparency.md)系統：
  - 伺服器管理活動的[定期彙總](./features/transparency.md#recaps)，依可設定的排程自動發布。
  - 新增[公開管理紀錄](./features/transparency.md#modlog)：處罰可以發布在公開頻道中，依類型與來源篩選，並可一鍵建立唯讀的 #public-modlog 頻道。
  - 新增 [`/transparency` 指令](./features/transparency.md#command)，隨時顯示最近一個結束期間的彙總。
- 新增 [`/audit` 指令](./features/audit.md)：對伺服器進行完整的**安全稽核**，包含整體評分、[詳細檢查](./features/audit.md#checks)（驗證等級、權限、頻道）與[一鍵修復](./features/audit.md#fix)。管理員角色可以直接從稽核整合到 Authentification Manager。
- 新增突襲模式與加入鎖定的[踢出模式](./features/raid-mode.md#kick-mode)（**Premium**）：新加入者會被踢出，並收到說明用的私訊與可返回的邀請按鈕，而不是 Discord 原生的邀請暫停。新的 [`/bypass raid` 指令](./features/raid-mode.md#bypass-raid)可在其啟用期間讓特定使用者進入。 <SuggestionLink id="144" />
- [訊息指令](./guides/prefix.md#permissions)現在可以透過 `/settings` 的新選項，遵循 **Discord 指令權限**（整合分頁）。 <SuggestionLink id="369" />
- 當[私訊鎖定](./features/dm-lock.mdx)引發 **Discord 安全警示**時，RaidProtect 現在會在警示下方回應，引用該警示並說明該在哪裡調整設定。
- [帳號最短註冊時長](./features/raid-mode.md#minage)的踢出紀錄現在會以時間戳記顯示所需的門檻。
- 設定與安裝：
  - `/settings` 主選單重新整理為邏輯分行。
  - 安裝訊息現在直接連結指令，並提供按鈕以變更紀錄頻道。
  - 當驗證碼頻道被刪除時，會提供**停用驗證碼**按鈕。
- 將 Discord 層內部遷移至共用函式庫（`@fca.gg/discord`），以加快後續更新。
- 修正：
  - 更清楚的錯誤訊息，區分**超時**與**禁言**，並將管理員對象與角色階層封鎖區分開來。
  - 修正 Discord AutoMod 超時的自動轉換。
  - 修正 `/serverinfo`：自訂 URL 的存取、規則與統計。
  - 修正 `/discord-sanctions` 別名以及訊息指令前綴的使用。
  - 修正在取代角色模式下，監禁被套用到管理員的問題。
  - 加強 Webhook URL 的驗證。
  - 各項修正：處罰紀錄、驗證碼、私訊鎖定訊息、管理備註、Premium 偵測。
  - 各項翻譯修正。

  - `/clear` 的大量刪除紀錄。
  - Anti-Scam 與 Auto RaidMode 設定變更的紀錄。
