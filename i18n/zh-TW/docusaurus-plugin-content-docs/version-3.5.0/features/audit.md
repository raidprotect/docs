`/audit` 指令會分析您 Discord 伺服器的設定並找出安全漏洞：過於寬鬆的權限、驗證等級不足、[未受保護的管理員角色](/zh-TW/learn/least-privilege)等。接著它會提議一鍵修復大部分的問題。

使用指令：```/audit```

:::info
此指令僅限擁有 `管理員` 權限的成員使用。報告只有您看得到（臨時回覆）。
:::

## ❓ 稽核的運作方式 {#working}

RaidProtect 會為您的伺服器給出一個**滿分 100 的整體評分**，並附上等級（從 **S** 到 **E**）及評語：**優秀**（90 分以上）、**良好**（70 分以上）、**有待改進**（40 分以上）或**危急**（低於 40 分）。

報告分為三個類別，每個類別各有自己的評分：

- **伺服器設定**
- **角色**
- **頻道**

點擊某個類別的「**詳情**」按鈕可查看每項檢查的結果，再點擊「**返回**」即可回到報告。「**重新整理**」按鈕會在您修改後重新執行分析。

### 執行的檢查項目 {#checks}

| 類別 | 檢查項目 |
|---|---|
| 伺服器設定 | **驗證等級** |
| 伺服器設定 | **不當內容過濾器** |
| 伺服器設定 | **管理操作的雙重驗證（2FA）** |
| 伺服器設定 | **預設通知設定** |
| 伺服器設定 | **突襲警報** |
| 伺服器設定 | **私訊鎖定（公開伺服器）** * |
| 伺服器設定 | **機器人數量** * |
| 角色 | **@everyone 的權限** |
| 角色 | **可自助取得的角色** |
| 角色 | **由邀請授予的角色** |
| 角色 | **管理員角色** |
| 角色 | **管理員機器人** * |
| 頻道 | **@everyone 的頻道權限** |
| 頻道 | **冗餘的頻道權限** |
| 頻道 | **管理團隊身分組的發言允許設定** * |
| 頻道 | **陳舊的 Webhook** * |

標有 `*` 的檢查項目僅供**參考**：它們會出現在報告中，但不影響評分。**私訊鎖定（公開伺服器）**只會出現在社群伺服器或公開伺服器上。

關於這些檢查的一些補充說明：

- **可自助取得的角色**：指成員無需管理人員即可取得的角色，並附上其來源：Discord 新成員引導、RaidProtect 的[自動身分組](./onboarding.md#autorole)、加成、訂閱、整合或連結的角色。
- **管理團隊身分組的發言允許設定**：指帶有管理權限的角色，在某些頻道上擁有已在其他地方涵蓋的發言允許設定（寫入、發言……）。我們會保留它們，因為它們能讓團隊在 [`/lock`](./channel-lock.md) 期間或 [DISCON](./discon.md) 第 1 級時保有發言權。請確認所列的每個角色確實是團隊角色：否則它將逃過鎖定。

如果 RaidProtect 缺少正常運作所需的權限，除了評分之外還會顯示專屬警告。需要缺少權限的檢查（例如管理 Webhook）會被標示為未評估。

:::info
如果 RaidProtect 看不到您伺服器中的某些頻道，報告會顯示「**分析不完整**」提示區塊：這些頻道不會被分析，評分僅針對其餘部分。
:::

## 🔧 一鍵修復漏洞 {#fix}

可自動修復的檢查項目會顯示「**修復**」按鈕：

| 檢查項目 | 套用的修復 |
|---|---|
| 驗證等級 | 將伺服器的驗證等級設為**中等**（「中等」或以上為通過，「低」會給予警告，「無」則為失敗） |
| 不當內容過濾器 | 對**所有成員**啟用過濾器 |
| 預設通知設定 | 將預設通知設為**僅限 @提及** |
| @everyone 的權限 | 移除 @everyone 角色的敏感權限 |
| 冗餘的頻道權限 | 開啟需要清理的頻道清單，然後點擊「**全部修復**」 |

對於**管理員角色**，沒有自動修復：稽核會提議您使用「**整合**」或「**全部整合**」按鈕來保護它們，這些按鈕會把它們加入 [Authentification Manager](./authentication-manager.mdx)。

:::warning
要套用修復，RaidProtect 必須擁有 `管理伺服器` 和 `管理角色` 權限。
:::

### 冗餘的頻道權限 {#redundant}

當頻道權限**沒有任何實際作用**時，就是**冗餘**：它已在伺服器層級被授予、已由該頻道的 @everyone 權限授予，或是一個沒有作用的拒絕設定。這時必須在多處修改才能真正生效，因而產生盲點。

清單會逐一頻道列出每項權限，以及其冗餘的原因：

- 頻道的「**忽略**」按鈕會將該頻道從清單、評分和「**全部修復**」中移除。您可以從「**已忽略的項目**」中將其恢復。
- 修復一個分類，也會一併修復與其同步的頻道。
- **管理員**角色的權限會另外列在「**對管理員角色無效**」中：Discord 會忽略它們，而我們絕不會移除它們，因為若該角色失去管理員權限，它們就會生效。

分析會考量目前進行中的鎖定，包括由 [`/lock`](./channel-lock.md) 或 [DISCON](./discon.md) 產生的鎖定。

## ✅ 排除刻意設定的警示 {#ignore}

有些警示對應的是您有意為之的選擇：受信任的管理員角色、有意留給 `@everyone` 的權限等。在類別詳情中提供的「**標記為正常**」按鈕，讓您選擇一個項目後再「**忽略**」它。

被忽略的警示會從報告中消失，不再影響您的評分。您隨時可以查看已忽略項目的清單（「**已忽略的項目**」按鈕），並透過「**恢復**」或「**全部恢復**」來恢復其中任何一項。

## 常見問題 {#faq}

### 為什麼驗證等級「中等」就足夠了？

「中等」等級已經會排除建立不到 5 分鐘的帳號，從而擋下大多數的拋棄式帳號。因此這是「**修復**」按鈕所套用的等級。

### 為什麼稽核不會移除我管理員角色的頻道權限？

Discord 會忽略擁有管理員權限之角色的頻道權限。我們將它們另外列出而不移除：若該角色失去管理員權限，它們就會重新生效。

### 我可以將某個頻道排除在冗餘權限的分析之外嗎？

可以：在冗餘權限清單中，點擊該頻道旁的「**忽略**」。它將不再計入評分，您也可以從已忽略的項目中將其恢復。
