有時需要暫時鎖定某個頻道，以禁止使用者在其中發送訊息。有了鎖定指令，這件事變得輕而易舉！

## 🔒 鎖定頻道 {#lock}

使用指令：```/lock [#channel] [duration] [reason]```

此指令會移除 **@everyone** 角色在目標頻道中「傳送訊息」與「在討論串中傳送訊息」的權限，讓所有使用者都無法在其中發文。

- 將 `[#channel]` 替換為要鎖定的頻道的提及或 [ID](../guides/id.mdx)。若未指定頻道，我們會鎖定您執行指令的頻道。支援文字頻道、公告頻道、語音頻道、論壇、媒體頻道、舞台頻道以及分類；不支援討論串。
- 將 `[reason]` 替換為頻道被鎖定的理由（例如：*清理聊天室*、*重要公告* 等）。

:::info
同一個頻道每 10 分鐘只能被鎖定一次。
:::

### 暫時鎖定 {#lock-duration}

`[duration]` 參數可讓頻道在指定的時間後**自動解除鎖定**（例如 `15m`、`1h`、`2d`）。適合快速讓場面冷靜下來，不必記得手動解除鎖定。時長上限為處罰的最長時長。

## 🔓 解除頻道鎖定 {#unlock}

使用指令：```/unlock [#channel] [reason]```

此指令會將 **@everyone** 角色傳送訊息的權限恢復為鎖定前的狀態，讓使用者再次能夠在其中發文。將 `[reason]` 替換為頻道解除鎖定的理由（例如：*討論重新開放*、*公告結束* 等）。

:::warning
為使鎖定正常運作，任何對所有人開放的角色都不應在該頻道中擁有明確的發言權限。否則，擁有這些角色的成員仍然可以聊天。至於為您的團隊角色設定的允許，則很有用：它們讓工作人員在 `/lock` 期間保有發言權，而且[稽核](./audit.md)也不會再將它們標示為冗餘。
:::
:::info
`lock` 和 `unlock` 指令[可使用前綴執行](../guides/prefix.md)。它們需要「**管理訊息**」權限。RaidProtect 需要「**管理頻道**」和「**管理角色**」權限才能修改頻道的權限。
:::

## ✏️ 掛鎖設定 {#config}

您可以選擇是否在被鎖定的頻道名稱前加上掛鎖：此時 `/lock` 會將頻道重新命名為 `🔒-頻道名稱`，而 `/unlock` 會移除該前綴。如此一來，在頻道清單中就能直接看出頻道的狀態。此選項**預設為停用**。

啟用或停用掛鎖：
1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**工具**」分頁。
3. 點擊「**頻道鎖定**」旁的「**啟用**」（或「**停用**」）。此按鈕如同開關，點一下即可切換。

## 常見問題 {#faq}

### 可以鎖定自己所在頻道以外的頻道嗎？

可以，將頻道作為第一個參數：`/lock #一般 30m 突襲進行中`。

### 為什麼有些成員在被鎖定的頻道中仍然可以發言？

鎖定只會移除 @everyone 角色的發言權。在該頻道中擁有明確發言權限的角色會保留該權限。

### 如何在被鎖定頻道的名稱前加上掛鎖？

在 `/settings` 的「工具」分頁中，啟用「頻道鎖定」。此選項預設為停用。
