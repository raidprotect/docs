## 🚀 開始使用 RaidProtect {#start}

要開始使用 RaidProtect，只需透過以下連結將它邀請到您的伺服器即可。

<DocCard item={{ type: 'link', href: 'https://raidprotect.bot/invite', label: '邀請 RaidProtect' }} />
<br />

:::danger
請注意，市面上流傳著**盜用 RaidProtect 名稱**的**機器人仿冒品**，請務必只從我們的官方網站邀請它。
:::

### 先決條件 {#requirement}

為確保 RaidProtect 正常運作：
1. **授予 RaidProtect 管理員權限**。這能讓它自動管理您所有的頻道。
2. **將它的角色放在與伺服器管理員相同的層級**。權限系統不允許 RaidProtect 處罰角色位階高於它的使用者。

### 安裝 {#install}

將 RaidProtect 加入伺服器後，請執行 [`/setup`](./setup.md#install) 指令。
