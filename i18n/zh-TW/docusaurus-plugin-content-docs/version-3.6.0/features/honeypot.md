RaidProtect 的 **HoneyPot**（陷阱頻道）是一項 Antispam 功能：這是一個[**任何人都不該發言**](/zh-TW/learn/honeypot-warming)的頻道。由於真正的成員都知道要避開這個頻道，因此會在其中發文的只有[**被盜帳號**](/zh-TW/learn/token-grabber)或垃圾訊息機器人：RaidProtect 會自動處罰它們。

:::info
**您預設已經有 ScamLens。**[ScamLens](./scam-images.md) 反詐騙功能在您的伺服器上無需任何設定就已啟用：它專門處理**詐騙圖片**，能以極高的可靠度偵測並刪除它們，同時處罰被入侵的帳號。因此對於以圖片進行的詐騙，ScamLens 就綽綽有餘。如果您想要最高等級的安全性，並阻擋**其他類型的垃圾訊息**：連結垃圾訊息、文字突襲、機器人，那麼 HoneyPot 就特別有用。
:::

## ❓ 運作方式 {#working}

當您啟用 HoneyPot 時，RaidProtect 會在您伺服器的**最上方**建立一個文字頻道，並隨機取一個清楚的名稱。這個頻道有三個特點：
- **所有人都能在其中發言**，包括尚未通過驗證碼的成員，以及擁有[監禁角色](./sanctions.mdx#jail)的成員。這是刻意的：被盜帳號或機器人不應能避開陷阱。
- 建立頻道時會發布**一則警告訊息**（「請勿在此發送任何訊息」），並附有「**Translate**」按鈕，讓每個人都能以自己的語言閱讀。
- 一旦抓到第一個帳號，「**Translate**」旁就會出現一個按鈕形式的**被檢舉帳號計數器**。

只要有成員在這個頻道發文：
- RaidProtect 會套用**您所選擇的處罰**（停權、軟停權、踢出、超時、監禁或禁言），且不會傳私訊給他。
- 該成員**在過去 10 分鐘內發送的訊息**會在整個伺服器上被刪除，以便在垃圾訊息已蔓延到其他頻道時加以制止。
- 此動作會加入自動管理紀錄中（原因：*透過被盜使用者帳號發送垃圾訊息*）。

如果您選擇了[處罰前延遲](#grace)，成員會先有機會表示這是誤會。

## 🛠️ 設定 HoneyPot {#config}

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**防護**」分頁。
3. 點擊「**HoneyPot**」旁的「**設定**」。
4. 點擊右上角的「**啟用**」：RaidProtect 會建立頻道、設定權限並發布警告訊息。

<Settings start="honeypot" />

頻道建立後，您可以：
- **重新產生頻道**（「**HoneyPot 頻道**」旁的按鈕）：刪除舊頻道，並以新名稱建立新頻道。如果您認為有成員洩漏了陷阱頻道的名稱，好讓其他帳號避開它，這項功能就很有用。
- **停用**（右上角的開關）：刪除頻道並停止此功能。

:::warning 所需權限
RaidProtect 需要 `管理頻道` 和 `停權成員` 權限。沒有這些權限時，會顯示錯誤提示區塊，且按鈕會呈現灰色。
:::

### 選擇處罰 {#sanction}

預設情況下，HoneyPot 會套用**軟停權**。「**套用的處罰**」選單中提供多種[處罰](/zh-TW/learn/discord-sanctions)：

| 處罰 | 效果 | 可用性 |
|---|---|---|
| **停權** | 將成員逐出伺服器並刪除其近期訊息。為暫時性（預設 1 天）。 | 免費 |
| **軟停權** | 先停權再解除停權：刪除訊息，但成員可以回來 | 免費 |
| **踢出（Kick）** | 將成員逐出，成員可自由回來 | Premium |
| **超時** | 在選定的時間內禁止成員發言（最長 28 天） | Premium |
| **監禁** | 授予您伺服器上已設定的[監禁角色](./sanctions.mdx#jail) | Premium |
| **禁言** | 授予您伺服器上已設定的[禁言角色](./sanctions.mdx#mute) | Premium |

對於有時長的處罰（停權、超時、監禁、禁言），請在「**時長**」選單中選擇時長（預設 1 天），或選擇「**自訂值**」輸入您自己的時長（例如 `5m`、`1h`、`2d`；最短 1 分鐘）。軟停權和踢出沒有時長，因此該選單會呈現灰色。

選單提供的選項依處罰而定：

| 處罰 | 提供的選項 |
|---|---|
| **停權** | 永久、1 天、7 天、30 天 |
| **監禁** | 永久、1 小時、1 天、7 天 |
| **禁言** | 5 分鐘、1 小時、1 天、7 天 |
| **超時** | 5 分鐘、1 小時、1 天、28 天 |

停權和監禁可以是**永久**的：處罰不會自行解除。更換處罰時，若所選時長仍然可行就會保留（永久不會沿用到超時或禁言，而超時則維持在 28 天以內）。

:::tip
**軟停權**是個不錯的折衷方案：它會清除訊息並將被盜帳號逐出，但合法的擁有者在帳號恢復安全後可以回來。
:::

:::info
只有**停權**和**軟停權**能讓 Discord 一次性在**整個伺服器**原生刪除被盜帳號的訊息。
對於其他處罰（踢出、超時、監禁、禁言），RaidProtect 需要自行刪除訊息：它們僅限 [Premium](/zh-TW/premium) 伺服器使用。
:::

:::info
- 未設定角色的**監禁**或**禁言**會變成**超時**。選單會在處罰下方註明。
- 如果您的伺服器失去 Premium，Premium 處罰會在下次觸發時自動恢復為**軟停權**。
:::

### 處罰前延遲 {#grace}

出於善意的成員可能會誤在 HoneyPot 中發言。**處罰前延遲**讓他有時間在受罰前表示這是誤會。

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**防護**」分頁。
3. 點擊「**HoneyPot**」旁的「**設定**」。
4. 在「**處罰前延遲**」中，選擇「**立即處罰**」（預設），或「**先詢問，30 秒後處罰**」（另有 1 分鐘、2 分鐘、5 分鐘後處罰可選）。

啟用延遲時：
- 訊息會被**移除**，且該成員會在陷阱頻道中被**提及**，並附上「**這是誤會**」按鈕；
- 只有該成員可以點擊按鈕。如果他及時點擊，就不會施加任何處罰；
- 若在延遲結束前沒有點擊，處罰就會生效。

:::info
垃圾訊息機器人通常會在各處發布相同的文字。在其他地方發布**相同訊息**的帳號會被**立即**處罰，不必等待。
:::

### 忽略的成員 {#ignore}

您可以在「**忽略的成員**」選單中，選擇在 HoneyPot 中發文時**誰不會被處罰**：
- 「**無人（無法處罰的成員除外）**」*（預設）*：所有人都會被處罰，包括工作人員。只有機器人無法管理的成員（角色位階高於 RaidProtect）會被自動排除。
- 「**工作人員（管理員 / 管理伺服器 / 管理頻道）**」：擁有 `管理員`、`管理伺服器` 或 `管理頻道` 權限的成員不會被處罰。
- 「**Antispam 忽略的成員**」：RaidProtect 沿用 [Antispam](./anti-spam.mdx#ignore) 所忽略的角色和成員。如果該清單為空，則擁有 `管理員`、`管理伺服器` 或 `管理訊息` 權限的成員會被忽略。

:::info
無論如何，RaidProtect **絕不會處罰自己或其他機器人**。機器人不會觸發 HoneyPot。
:::

## ℹ️ /honeypot 指令 {#command}

`/honeypot` 指令會直接開啟 HoneyPot 的設定畫面，無需經過 `/settings`。它需要 `管理伺服器` 權限。

使用指令：```/honeypot```

## 🤝 HoneyPot 與 ScamLens，搭配更強大 {#scamlens-combo}

RaidProtect 已內建 [**ScamLens**](./scam-images.md)，它會分析圖片並刪除已知的詐騙圖片（加密貨幣、假贈品活動、假賭場促銷）。

兩者攜手合作：
- **ScamLens 優先**。如果在 HoneyPot 中發布的圖片已被辨識，就由 ScamLens 刪除訊息並處罰被入侵的帳號；HoneyPot 的處罰不會重複套用。
- **HoneyPot 接手**處理其餘所有情況：尚未被辨識的新圖片、連結垃圾訊息、大量提及、文字突襲、機器人。
- **每張被 HoneyPot 抓到的新圖片都會豐富 ScamLens**，之後它就能在所有受保護的伺服器上封鎖這張圖片。
- **ScamLens 跟隨您的 HoneyPot**：只要您沒有為它設定專屬的設定，它就會套用您 HoneyPot 的[處罰與時長](./scam-images.md#config)。

ScamLens 在您的伺服器上已預設啟用。**啟用 HoneyPot 不會破壞任何東西**：它只是補足現有的防護，並幫助 RaidProtect 更好地保護整個社群。

## 常見問題 {#faq}

### 如果我已經有 ScamLens，HoneyPot 還有用嗎？

對於圖片詐騙，ScamLens 就綽綽有餘：它預設啟用，能自行偵測、刪除並處罰。HoneyPot 主要用於阻擋其他類型的垃圾訊息，例如連結垃圾訊息、文字突襲和機器人。

### HoneyPot 會套用哪種處罰？

預設為軟停權。您可以選擇其他處罰：停權和軟停權免費，而踢出、超時、監禁和禁言僅限 Premium 伺服器使用。HoneyPot 的停權預設持續 1 天，您可以修改此時長。

### 有成員誤在 HoneyPot 中發言，該怎麼辦？

啟用處罰前延遲：訊息會被移除，該成員會被提及，並有 30 秒至 5 分鐘的時間點擊「這是誤會」。如果他及時點擊，就不會受罰。不過，在其他地方發布相同訊息的帳號則會被立即處罰。

### 工作人員在 HoneyPot 中發言會被處罰嗎？

這取決於「忽略的成員」選項。預設情況下，所有人都會被處罰，包括工作人員。RaidProtect 絕不會處罰自己，而機器人也絕不會觸發陷阱。

### 被 HoneyPot 抓到的帳號，其訊息會怎麼處理？

除了處罰之外，該成員在過去 10 分鐘內發送的訊息也會在整個伺服器上被刪除，以便在垃圾訊息已蔓延到其他頻道時加以制止。
