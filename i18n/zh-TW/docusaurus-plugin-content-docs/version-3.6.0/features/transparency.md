透明度讓您向成員展示伺服器是如何被管理的。它由三個互補的部分組成：**定期管理彙總**、**公開管理紀錄**以及 **`/transparency` 指令**。

## 🛠️ 設定透明度 {#config}

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**管理**」分頁。
3. 點擊「**透明度**」旁的「**設定**」。

此畫面可讓您進入「**定期彙總**」、「**公開管理紀錄**」，以及「**/transparency 指令**」的切換開關。

<Settings start="transparency" />

## 📊 定期彙總 {#recaps}

彙總是管理動作的整合摘要，會依您選擇的頻率自動發布到頻道中。

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**管理**」分頁。
3. 點擊「**透明度**」旁的「**設定**」。
4. 點擊「**定期彙總**」旁的「**設定**」。
5. 點擊空位旁的「**新增**」。
6. 新彙總的畫面會開啟：設定其**頻率**、發布的**頻道**，以及（選用）要**提及**的角色，然後點擊標題右側的「**啟用**」。

之後若要回頭修改某個彙總，請點擊清單中它旁邊的「**編輯**」。

<Settings start="recaps" />

新建立的彙總預設為停用、每週一次，約於 08:00 發布到公開管理紀錄的頻道。可用的頻率有：**每週**（預設）、**每兩週**、**每月**、**每季**和**每年**。兩個頻率相同的彙總不能發布在同一個頻道。

在彙總的畫面中，您還可以：

- 「**重新命名**」彙總（將欄位留空即可沿用頻率名稱）；
- 設定其發布的「**時間安排**」（見下文）；
- 點擊「**作為 /transparency 的資料來源**」，使其成為 [`/transparency` 指令](#command)的來源；
- 「**刪除**」它。

彙總包含：
- 該期間內**管理動作的總數**；
- 依處罰類型的明細（停權、軟停權、踢出、超時、禁言、監禁、警告及其他動作）；
- **被 [ScamLens](./scam-images.md) 攔截的詐騙**數量；
- **自動**動作與**管理團隊**動作的比例。

**限制**：免費版 1 個彙總，[Premium](/zh-TW/premium) 版 5 個彙總（例如團隊用的每週彙總，以及公開的每月彙總）。

### 發布時間 {#recap-schedule}

1. 在彙總的畫面中，點擊「**時間安排**」。
2. 在視窗中選擇「**發布時間**」（當地時間，從 `00:00` 到 `23:00`）。

<SettingsModal name="recapSchedule" />

| 版本 | 發布時間點 |
|---|---|
| 免費 | 在所選時間起算的 12 小時區間內 |
| [Premium](/zh-TW/premium) | 約在所選時間，誤差 1 小時內 |

所選的時間遵循**伺服器的時區**，並顯示在「**時間安排**」那一行下方。時區只需為整個伺服器設定一次，位於「**一般**」分頁：

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**一般**」分頁。
3. 點擊「**時區**」旁的「**編輯**」。
4. 在「**時區（UTC）**」中選擇您的時差，或輸入「**自訂時區**」，例如 `Europe/Paris`，其優先順序較高，並會自動處理夏令時間。

## 📢 公開管理紀錄 {#modlog}

公開管理紀錄會將**每一項管理動作**發布到成員可見的頻道中，且只顯示您選擇要顯示的資訊。

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 開啟「**管理**」分頁。
3. 點擊「**透明度**」旁的「**設定**」。
4. 點擊「**公開管理紀錄**」旁的「**設定**」。
5. 選擇一個頻道，或點擊「**幫我建立一個**」（RaidProtect 會建立 `public-modlog` 頻道，對 @everyone 唯讀）。
6. 在「**顯示的資訊**」中選擇：「**原因**」、「**管理人員**」、「**時長**」、「**被處罰成員**」（預設：原因與時長）。
7. 在「**公開的處罰**」中選擇：「**手動（管理團隊）**」和／或「**自動（RaidProtect）**」（預設：兩者皆是）。
8. 點擊畫面標題右側的「**啟用**」。

<Settings start="modlog" />

當動作為自動執行，且已啟用顯示管理人員時，管理紀錄會以「RaidProtect」取代管理人員的名稱。

## 📜 `/transparency` 指令 {#command}

使用指令：```/transparency```

任何成員都能用它查看已結束期間的**最新透明度報告**（臨時回覆，僅該成員可見）。

- 必須透過透明度畫面中「**/transparency 指令**」的切換開關啟用此指令。
- 若您有多個彙總，彙總上的「**作為 /transparency 的資料來源**」按鈕會將其指定為該指令使用的來源。該彙總在清單中會以 ⭐ 標示。

## 常見問題 {#faq}

### 我可以排程多少個彙總？

免費版只能 1 個，使用 [Premium](/zh-TW/premium) 最多可達 5 個。

### 彙總在幾點發布？

在您選擇的時間，並依據 `/settings`「**一般**」分頁中設定的伺服器時區。免費版的發布會在該時間起算的 12 小時區間內進行；使用 Premium 則誤差在一小時內。

### 我的成員能看到是誰處罰了他們嗎？

只有在您於公開管理紀錄的顯示資訊中勾選「**管理人員**」時才看得到。對於自動動作，管理紀錄會顯示 RaidProtect。
