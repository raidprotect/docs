---
title: 啟用社群
description: "啟用 Discord 伺服器的社群功能，解鎖 RaidProtect 所需的安全設定：私訊鎖定、突襲模式等。"
---

啟用社群後，會開放 Discord 的多項進階安全設定，RaidProtect 的部分功能需要它們：
- [私訊鎖定](../features/dm-lock.mdx)（**DM Lock**）；
- [突襲模式](../features/raid-mode.md)與[加入鎖定](../features/join-lock.mdx)，**僅限**突襲期間的處理方式為「**封鎖邀請**」時（預設值）。

[驗證碼](../features/captcha.md)以及突襲模式的其他處理方式（「**踢出新加入的成員**」、「**傳送驗證碼**」、「**突襲期間凍結驗證碼**」）無需啟用社群即可運作。

## 🚦 先決條件 {#requirement}

- 必須是 Discord 伺服器的管理員。

## 🚩 啟用社群功能 {#steps}

1. **開啟伺服器設定**
   - 點擊左上角的伺服器名稱 > 「伺服器設定」。

2. **前往「社群」區段**
   - 在側邊欄中，前往「**啟用社群**」分頁，然後點擊「**開始使用**」。

:::note
如果您的伺服器已啟用社群，該區段會顯示為「**社群總覽**」。
:::

3. **依照啟用精靈操作**
   - 為所有成員啟用電子郵件驗證。
   - 啟用不當內容過濾器。
   - 設定規則頻道和公告頻道。
   - 同意社群伺服器使用規範。

4. **完成設定**
   - 點擊「完成設定」。啟用完成後，您的伺服器上會顯示「社群」徽章。

![Discord 啟用社群的截圖](../../../../en/docusaurus-plugin-content-docs/current/assets/rp-enable-community.webp)

## 💡 啟用後使用 DM Lock 與突襲模式模組 {#use}

1. 使用 [`/settings` 指令](../setup.md#settings)。
2. 若要設定[私訊鎖定](../features/dm-lock.mdx)，請開啟「**防護**」分頁，點擊「**私訊鎖定**」旁的「**編輯**」。
3. 若要設定[突襲模式](../features/raid-mode.md#config)，請開啟「**新成員加入**」分頁，點擊「**Auto RaidMode**」旁的「**設定**」。

如果出現提示要求您啟用社群的區塊，請點擊「**重新整理**」：啟用社群後，該區塊就會消失。
